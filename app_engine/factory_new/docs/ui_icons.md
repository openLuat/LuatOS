# TabOS 图标资源清单（tablet_home）

所有图标平铺放在本工程 `res/` 目录本身（**没有** `res/ui/` 这一层），烧录后路径为 `/luadb/<name>.png`。
代码里 `ui_theme.icon("name")` 会自动查找该目录；**找不到时自动回退旧资源或绘制占位色块，页面不会报错**。

> AirUI 不支持图片着色（只有透明度），因此图标颜色需要**直接烘焙进 PNG**。

## 五、天气图标（桌面天气卡）

放在 `res/` 下，烧录后路径 `/luadb/<name>.png`；代码侧由
`ui/idle_win.lua` 的 `WEATHER_STYLES` 表把「状况名」映射到「图标名 + 强调色」。

| 文件名 | 对应状况 | 尺寸 | 色彩建议 |
|--------|---------|------|---------|
| `weather_sunny.png` | 晴 | 96×96 | 金色 `#FFB454` 日轮 + 短光芒 |
| `weather_cloudy.png` | 多云 | 96×96 | 浅蓝 `#5CC9E8` 云 + 露出半轮日 |
| `weather_overcast.png` | 阴 | 96×96 | 中性灰 `#95A0AE` 实心云 |
| `weather_rain.png` | 雨 | 96×96 | 青色 `#5CC9E8` 云 + 雨丝 |
| `weather_snow.png` | 雪 | 96×96 | 近白 `#EDF1F7` 雪花 |

- 透明底 PNG，**不要自带底色块和阴影**（AirUI 无阴影能力），卡片会透过来。
- 桌面天气卡里的实际显示尺寸是 24~40px（随卡片高度），所以 96×96 足够；
  线条别太细，缩到 24px 时会糊。
- 文件缺失时不会留白：晴天降级为「自绘日轮」（光晕 + 四向光芒 + 日面），
  其余状况降级为「色调圆角块 + 状况首字」。
- 要新增状况（如「雷阵雨」）：在 `WEATHER_STYLES` 里加一行
  `["雷阵雨"] = { icon = "weather_thunder", tint = theme.C.violet },`，
  再放一张同名 PNG 即可，天气卡不用改。
