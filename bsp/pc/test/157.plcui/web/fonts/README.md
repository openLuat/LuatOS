# Browser fonts

`montserrat-latin-400-normal.woff` and `montserrat-latin-600-normal.woff` are the Latin subsets distributed by `@fontsource/montserrat` 5.3.0. They are included locally for repeatable browser screenshots without a remote font service. See `OFL.txt` for the SIL Open Font License.

The device renderer uses the existing LVGL Montserrat fonts. Browser and LVGL font rasterization may differ slightly.
