## 演示模块概述

1、main.lua：主程序入口；

2、test_adc.lua：ADC测量功能模块；

## 演示功能概述

使用Air1601开发板测试ADC功能。

## 演示硬件环境

1、Air1601开发板一块

2、TYPE-C USB数据线一根

3、杜邦线若干

4、直流稳压电源（暂时不能使用合宙Air9000P电源，可能有倒灌电流）

直流稳压电源输出 1.8V 电压，通过鳄鱼夹和杜邦线连接到 Air1601 开发板的 ADC1 和 ADC5 通道。

## 功能说明

本模块演示ADC多通道数据采集与处理：

1. **Air1601 支持通道**：ADC1、ADC2、ADC5、ADC6（通过修改 `CHANNELS` 表配置）
2. **Air1602 支持通道**：ADC1-7、ADC9-15
3. 每个通道采集14次样本
4. 每次采集前先做5次 dummy read（丢弃），让ADC采样电路稳定，避免第一次测量不准
5. 剔除2个最高值和2个最低值（去极值）
6. 取中间10个值求平均并打印处理过程
7. 量程 0-3.3V，无需分压处理
8. **ADC打开后延时**：打开ADC通道后延迟一段时间再开始正式采集。当外部供电电压越低，需适当增加延时（1.8V时建议1200ms以上）

通道在程序启动时统一打开，持续循环采集，不再重复打开/关闭通道。

## 注意事项

1. **外部供电电压越低，ADC启动后需要的稳定时间越长**。1.8V供电时建议延时1200ms以上；若供电电压更低（如1.5V），需进一步增加 `sys.wait` 延时值，避免第一次采集数据偏高。
2. **第一次测量不准**：解决方法是在每次正式采集前先做几次 dummy read（丢弃不用的读数），让ADC采样电路充分稳定后再采入真实样本。
3. **测量通道配置**：直接修改 `test_adc.lua` 中的 `CHANNELS` 表即可，填写要测量的ADC通道编号。
