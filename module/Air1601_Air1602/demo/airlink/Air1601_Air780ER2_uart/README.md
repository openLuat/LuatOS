## 功能模块介绍

**Air1601**

1、main.lua：主程序入口，负责项目版本定义、看门狗初始化（超时9秒，每3秒喂狗）、加载 network_airlink 模块并启动系统调度

2、network_airlink.lua：AirLink 多网融合模块，核心功能包括：

   - 通过 UART3（波特率2M）初始化 AirLink 连接，使 Air1601 外挂 Air780ER2 实现 4G 联网
   - 定时发送设备信息（BSP型号、当前时间）给对端 Air780ER2 模块
   - 定时获取并打印 Air780ER2 从机端的网络信息（IMEI、IMSI、ICCID、CSQ）
   - 通过 HTTP GET 请求（间隔10秒）测试网络连通性
   - 订阅 AIRLINK_SDATA 事件接收对端数据

**Air780ER2**

该模块不支持二次开发，需要烧录[量产固件](https://docs.openluat.com/air780er2/product/firmware/780er2_version/)。

## 演示功能概述

本 demo 演示 Air1601 通过 AirLink over UART 模式外挂 Air780ER2 4G 模块实现联网功能。

Air1601 相关资料参考：[Air1601/Air1602简介](https://docs.openluat.com/air1601/)

AirLink 通信协议说明参考：[Air780ER2/ER3简介 - AirLink 概述](https://docs.openluat.com/air780er2/product/#airlink) 和 [AirLink协议介绍](https://docs.openluat.com/protocols/airlink/)

Air780ER2 相关资料参考：[Air780ER2/ER3简介](https://docs.openluat.com/air780er2/product/)
