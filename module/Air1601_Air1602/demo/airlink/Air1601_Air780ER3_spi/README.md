## 功能模块介绍

**Air1601**

1、main.lua：主程序入口，负责项目版本定义、看门狗初始化（超时9秒，每3秒喂狗）、加载 network_airlink 模块并启动系统调度

2、network_airlink.lua：AirLink 多网融合模块，核心功能包括：

   - 通过 SPI1（波特率8M）初始化 AirLink 连接，使 Air1601 外挂 Air780ER3 实现 4G 联网
   - 定时发送设备信息（BSP型号、当前时间）给对端 Air780ER3 模块
   - 定时获取并打印 Air780ER3 从机端的网络信息（IMEI、IMSI、ICCID、CSQ）
   - 通过 HTTP GET 请求（间隔10秒）测试网络连通性
   - 订阅 AIRLINK_SDATA 事件接收对端数据

**Air780ER3**

该模块不支持二次开发，需要烧录[量产固件](https://docs.openluat.com/air780er2/product/firmware/780er3_version/)。

## 演示功能概述

本 demo 演示 Air1601 通过 AirLink over SPI 模式外挂 Air780ER3 4G 模块实现联网功能。

Air1601 相关资料参考：[Air1601/Air1602简介](https://docs.openluat.com/air1601/)

AirLink 通信协议说明参考：[Air780ER2/ER3简介 - AirLink 概述](https://docs.openluat.com/air780er2/product/#airlink) 和 [AirLink协议介绍](https://docs.openluat.com/protocols/airlink/)

Air780ER3 相关资料参考：[Air780ER2/ER3简介](https://docs.openluat.com/air780er2/product/)

Air1601 搭配 Air780ER3 参考设计文件：[Air780ER3 模组资料](https://docs.openluat.com/air780er2/product/shouce/#air780er3)

## 演示硬件环境

1、1、Air1601 + Air780ER3 搭配设计的开发板

3、TYPE-C USB 数据线两根（一根用于 Air1601 烧录程序和日志打印，另一根用于 Air780ER3 烧录程序和日志打印）

Air1601 与 Air780ER3 AirLink over SPI 连接方式如下：

| Air1601 | Air780ER3    |
| ------- | ------------ |
| GND     | GND          |
| CS0     | 30/SPI0_CS   |
| CLK1    | 33/SPI0_CLK  |
| MISO1   | 31/SPI0_MISO |
| MOSI1   | 32/SPI0_MOSI |
| GPIO12  | 26/GPIO25    |
