# 86盒深色部件仪表盘 demo

86盒（BOE 3.95 寸 480×480 in-cell，ST7102 TDDI）的深色部件式仪表盘 demo。整屏铺纯黑底，界面上排一个大表盘加一圈虚线点环和一组日期，下排音乐、月历、家庭三个部件卡片，整体是一块可以随手点的深色屏。

ST7102 这颗屏的初始化不在本目录里，走的是 `exd_st7102_rgb` 显示IC初始化扩展库（仓库 `script/libs/display/exd_st7102_rgb.lua`）。同一块面板上的触摸测试、显示与颜色测试、airui 控件全家桶、智能家居中控、HomeKit 面板等几套界面共用这一个扩展库，本 demo 只负责界面上的东西。

---

## 1. demo 功能

1. 用 `exd_st7102_rgb` 显示IC初始化扩展库初始化 ST7102 屏幕，分辨率 480×480，显示数据走 RGB 接口，寄存器初始化走 SPI；
2. 初始化 airui 控件库并加载 hzfont 矢量字库，整套界面只加载一次字库；
3. 初始化 ST7102 触摸并绑定给 airui，绑上之后点击由 airui 自己处理；
4. 整屏铺纯黑底，界面横向两列、纵向三段排成部件式仪表盘；
5. 左上一块大表盘，时间外面套一圈虚线点环，右上是日期，星期与月小字、日数字 72 大字号；
6. 下半左边是音乐部件，封面、歌名歌手和一个播放暂停按钮，点按钮翻转播放状态；
7. 下半右上是月历部件，当月 6 行 7 列日期网格，今天那格垫品红实心圆；
8. 下半右下是家庭部件，3 行配件带类型图标圆底和小开关，点一行翻转开关；
9. 表盘时间走设备实时时刻，每秒刷新一次时间、日期和日数字。

## 2. 硬件环境与接线

- 主控：Air1602 引擎
- 屏幕：BOE 3.95 寸 480×480 in-cell，显示与触摸集成在 ST7102 一颗 TDDI 上
- 显示：RGB 接口送像素，SPI 发寄存器初始化序列
- 触摸：单独走 I2C

显示侧的引脚在 `exd_st7102_rgb` 扩展库的 `M.defaults` 里（`pin_rst = 1`、`pin_clk = 41`、`pin_sda = 40`、`pin_cs = 42`），换板子时调用 `exd_st7102_rgb.setup({ pin_rst = 20 })` 覆盖即可，不用改扩展库。

触摸侧的引脚在 `home_dash_ui_main.lua` 顶部：

| 信号 | 接线 | 说明 |
| --- | --- | --- |
| 触摸 I2C SCL / SDA | I2C1 | 触摸总线，脚本里 `TP_I2C_PORT = 1` |
| 触摸复位 | GPIO46 | 脚本里 `TP_PIN_RST = 46` |
| 触摸中断 | GPIO51 | 下降沿触发，脚本里 `TP_PIN_INT = 51` |

引脚改到别的板子上时，改 `home_dash_ui_main.lua` 里的 `TP_I2C_PORT`、`TP_PIN_RST`、`TP_PIN_INT` 三个常量即可。

屏幕底层在扩展库里，不在本目录：

```

```

模块依赖是单向的，不会出现互相 require：

```
main.lua
 └── home_dash_ui_main.lua
      ├── exd_st7102_rgb.lua（script/libs/display 下）
      ├── dash_theme.lua  ──► exd_st7102_rgb.lua
      └── dash_page.lua
           ├── dash_theme.lua
           ├── dash_data.lua
           ├── dash_widget_music.lua    ──► dash_theme / dash_data
           ├── dash_widget_calendar.lua ──► dash_theme / dash_data
           └── dash_widget_home.lua     ──► dash_theme / dash_data
```

`require` 一律只写文件名，不带目录路径。LuatOS 固件把所有 `.lua` 打成扁平命名空间，带路径会加载不到。文件名连 `.lua` 一共不超过 24 字节，最长的 `dash_widget_calendar.lua` 正好 24 字节。

## 4. 关键实现

### 4.1 颜色换算（最重要）

这块屏的显存吃不了 0xRRGGBB，直接把 `0xRRGGBB` 传给 airui 的 `color` 会被拆错位，画面颜色不对。实测换算方向是：

- airui 拿到值 `P` 之后，屏上显示的红 = `((P & 0xFF) & 0x1F) * 8`
- 显示的绿 = `(((P >> 8) & 0xFF) & 0x3F) * 4`
- 显示的蓝 = `(((P >> 16) & 0xFF) & 0x1F) * 8`

也就是低字节才是红、中间字节是绿、高字节是蓝，并且只用每字节的低位段。所以要这样反着写：

```lua
to_panel_color(0xRRGGBB) = (B >> 3) << 16 | (G >> 2) << 8 | (R >> 3)
```

`exd_st7102_rgb` 扩展库里的 `to_panel_color()` 就是干这个的。`dash_theme.lua` 在模块加载时把整张配色表过一遍换算，界面上其它地方一律写 0xRRGGBB，不许绕过 `dash_theme.COLOR` 直接给 airui 传颜色。

真机核对过的两行：

| 写进去的值 | 换算后传给 airui | 屏上实测 RGB |
| --- | --- | --- |
| `0xFFFFFF` | `0x1F3F1F` | (248, 252, 248) |
| `0xE5E5EA` | `0x1D391C` | (224, 228, 232) |

`0xE5E5EA` 这一行，源色 R=229 G=229 B=234，换算后低字节 `0x1C` 是红的 5 位码、中间 `0x39` 是绿的 6 位码、高字节 `0x1D` 是蓝的 5 位码，屏上还原出来正好是 (224, 228, 232)，和源色只差各通道的截位误差。

深色底（`0x000000`、`0x1C1C1E`）走同一套换算，实测正常。

> **注意**：`exd_st7102_rgb` 扩展库里的寄存器 `0x3A = 0x77`、`0x36 = 0x08` 是厂商自己给的值，不要动。

### 4.2 字号下限与抗锯齿

hzfont 的 `antialias` 不是「开不开抗锯齿」，是**采样档位**：小于 0 自动，小于等于 1 是 2×2，等于 2 是 3×3，其它是 4×4。demo 里传 `antialias = 3`，取最锐的 4×4，小字和白色描边才不会发糊。

字号实测下限是 16：再小会渲染成方框而不是笔画。所以 `dash_theme.FONT_SIZE` 里最小档就是 16（`BODY` / `MINI`），表盘 44、日数字 72、标题 20，全都在下限以上。文字框高度按「字号 + 3」留行高，给足余量。

### 4.3 虚线点环

`airui.shape` 的 `items` 里画 36 个实心小圆，均匀摆在一个半径 64 的圆周上，就是图二那种虚线弧的观感。shape 的图元坐标是**相对 shape 自己方框**的，所以 shape 方框按「圆心 + 半径 + 点半径」给足 134×134，每个点的圆心取方框正中 `(67, 67)` 再沿角度偏移，不会被裁掉。

LVGL 同层兄弟按**创建顺序**绘制，所以先建点环 shape、后建时间文字，文字才压在点环上面。

### 4.4 月历网格

月历不调 `os.time`。`os.time` 带时区换算，设备时区和 RTC 没同步时会算出错的星期几。改用今天自己的 `wday` 和 `day` 倒推 1 号是星期几：

```lua
first_wday = (now_table.wday - 1 - (now_table.day - 1)) % 7 + 1
```

当月天数查表 + 平闰年规则。6 行 7 列的格子统一铺满，1 号之前和月末之后的格子文字留空。今天那格先垫一个品红实心圆、再压数字，创建顺序决定层级。高亮圆直径 20，压在一格 21 的高度里，不会溢到相邻行。

### 4.5 开关不用 `airui.switch`

`airui_switch_apply_style` 内部直接写 `lv_color_hex(0x1A73E8 / 0xD93025 / 0x188038)` 这些固定色值，绕过了 4.1 的换算，在这块屏上必然是错的颜色。所以开关用两个 `airui.container` 拼：一个当轨道、一个当滑块，滑块位置由 `dash_theme.knob_pos()` 算出来再 `set_pos` 过去。

### 4.6 点击回调与 sender 身份

airui 回调里的 `sender` 是**每次回调新建的 userdata**，拿它跟控件对象做 `==` 恒为假，认不出是哪一行。所以：

- 每行/每个槽位各写一个具名回调函数，行号写死在函数体里；
- 共用回调时用 `get_text()` 反查标识；
- 全程不写闭包和匿名函数（demo 规范禁止，也降低了学习门槛）。

另外 shape 控件在创建时被移掉了 `LV_OBJ_FLAG_CLICKABLE`，本身收不到点击，事件会落到父容器上。所以家庭部件里每行要把点击绑到圆底、配件名、开关轨道、开关滑块四个可点控件上，图标图元不用绑。

### 4.7 布局尺寸

480×480，左右各留 20 边距，横向两列：

| 区块 | x | y | 宽 | 高 |
| --- | --- | --- | --- | --- |
| 虚线点环 + 时间 | 20 | 16 | 252 | 136 |
| 日期（星期月 + 日数字） | 284 | 16 | 176 | 136 |
| 音乐部件 | 20 | 164 | 440 | 92 |
| 月历部件 | 20 | 268 | 252 | 194 |
| 家庭部件 | 284 | 268 | 176 | 194 |

点环圆心 (146, 84)、半径 64、点半径 3、36 个点。时间文字 `x=66, y=58, w=160, h=52`，44 号居中。日期小字 `x=290, y=42`，20 号品红；日数字 `x=290, y=72, h=80`，72 号白色。

三个部件的内部排布写死在各自文件顶部的常量里，改部件尺寸要同步改那一段常量。

## 6. 运行步骤

1. 用 Luatools 烧录带 ST7102 触摸驱动的固件（Air1601 / 160X_102 号）；
2. 把本目录下所有 `.lua` 下载进模组，另外把仓库 `script/libs/display/exd_st7102_rgb.lua` 一起下载进去（Luatools 按 `require` 的文件名找文件，缺了会加载不到）；
3. 重启，屏幕上会直接出纯黑底的仪表盘；
4. 点右下家庭部件任意一行、点中部胶囊按钮，确认触摸生效。

日志里会依次看到 `exd_st7102_rgb 显示初始化完成`、`home_dash_ui_main airui初始化完成`、`触摸绑定完成`、`界面搭建完成`、`dash_page 仪表盘创建完成`。

## 8. 常见问题

**颜色发灰、红蓝对调**
颜色没过 `to_panel_color()`。所有颜色都从 `dash_theme.COLOR` / `dash_theme.TYPE_COLOR` 取，不要直传 0xRRGGBB。

**小字渲染成方框**
字号小于 16。`dash_theme.FONT_SIZE` 的最小档就是 16，别往下调。

**文字边缘发糊**
`antialias` 传小了。档位 1 是 2×2、2 是 3×3、3 是 4×4，demo 传的是 3。

**点环、今天高亮圆不显示**
shape 的 `items` 坐标是相对 shape 自己方框的，方框给 0×0 或给小了会被裁掉。方框要按「圆心 + 半径」给足，圆心取方框正中。

**点配件行没反应**
shape 控件本身不收点击，要绑到它的父圆底上；一行里的圆底、名字、轨道、滑块都要绑。

**点开关颜色不对**
`airui.switch` 的配色过不了这块屏的颜色换算，必须用两个 container 拼开关。

**时间停在 21:41**
设备没 RTC 或时钟没同步，`dash_data.get_now()` 退回演示时刻。NTP 对时后即为实时。

**报 `module 'exd_st7102_rgb' not found`**
`exd_st7102_rgb.lua` 没一起下载进模组。它在仓库 `script/libs/display/` 下，不在本 demo 目录里。
