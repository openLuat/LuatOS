# U盘FOTA升级demo（有UI界面版）

## 一、功能概述

开机后屏幕显示**待机页**，USB 常驻**主机模式**（开机先主动检查一次 U 盘是否已插好，兼容开机前就插着的情况，未插入才等枚举事件）：

1. 插入 U 盘 → 自动枚举、挂载 → **自动弹出树形文件浏览器**（仿电脑资源管理器：根节点=升级U盘，
   点文件夹**箭头**原地展开/收起（子项缩进），点文件夹**行**进入该目录（顶部出现"返回上一级"），
   点箭头展开与点行进入两种操作并存；文件夹/文件带图标（纯容器绘制），`~$xx`/`Thumbs.db` 等
   Windows 垃圾文件自动过滤；内容超出可滚动（scrollable）；仅 `*.bin` 行可选，选中整行高亮"已选"）；
2. 用户**点选**某个升级包（行高亮"已选"角标）→ 点右下角 **[确认升级]** → **二次确认弹窗**；
3. 确认后进入**进度页**：文件名、阶段文字、进度条、百分比、字节数实时显示；
4. fota 分块写入 + 底层 MD5 校验通过 → 提示"1 秒后重启" → 自动重启，bootloader 应用升级；
5. **失败不用重新上电**：写入/校验失败后自动重新挂载扫描，换包直接重试；
6. 点选择页右上角 **X** 可关闭回待机页（unmount；重新插拔 U 盘可再次进入）。

升级链路（fota.init/wait → fd:fill → buff:used → fota.run → isDone → finish → reboot）
与同级无 UI 版 `fota_usb_disk(无UI界面U盘升级)` **完全一致**，已在 Air8603W 上实测通过：
无 UI 版差分包（1.0.0 → 001.999.001）、有 UI 版整包（V1030+脚本1.0.1 → 包内 V1028+脚本1.0.0，
bootloader 完整应用后正常运行，证明整包/跨内核版本也可用），详见 §十一 实测记录。

## 二、适用模块与板型切换

| 板型 | `conf.lua` 中 `M.board` | 屏 | 触摸 | 参数来源 |
|---|---|---|---|---|
| Air8603 系列 (W1~W5/M1~M5) | `"air8603"` | RGB 10寸 1024x600 | GT911 I2C1, TP_RST=GPIO14, TP_INT=GPIO51 | `module/Air8603/factory/config/eng_8603x_10i_v0.lua` |
| Air8605 系列 | `"air8605"` | RGB 10寸 1024x600 | GT911 I2C1, TP_RST=GPIO72, TP_INT=GPIO51 | `module/Air8605/project/jq_weather_clock` |

换板只改 `conf.lua` 里 `M.board = "air8603"` 一行（Air8607A 已不在交付范围，profile 已移除）。

注意两点：
- **TP_RST 批次差异（14 / 72）**：8603 用 GPIO14、8605 用 GPIO72，`eng_8603x` 配置文件头部注释
  还写错成 72（以 `hw.tp` 实际值为准）。**`lcd_tp.lua` 已做双复位脚自动探测**：先按 profile 试，
  无应答自动换 14/72 再试——即使板型选错也能摸到（2026.11.12 两板实测），但仍建议 `M.board` 选对
  （上电时序不参与自动探测）。
- **U 盘座供电**：Air8603/8605 的 USB-A 座 +5.5V 由 JW5357 升压产生，EN 接 UVC_EN=**GPIO58**
  （两板实测均有效）；自研板按原理图改 `M.usb.pwr_pin`。

## 三、固件要求

- 带 **LUAT_USE_DISPLAY + LUAT_USE_AIRUI + LUAT_USE_TP** 的固件；
- 带 **usb 库（主机模式 MSC）+ fatfs 库（fatfs.USB 挂载）** 的固件。
  实测满足以上全部条件的固件（双板验证，详见 §十一）：
  - **Air8603W + LuatOS-SoC_V1030_Air1603_102**（2026.11.05 编译）与
    **V1028_Air1603**（2026.10.15 编译，经 U 盘整包升级刷入后同样全功能）；
  - **Air8605 + LuatOS-SoC_V1030_Air1602**（2026.11.05 编译，升级与触摸滑动均正常）。
  公开固件若缺 U 盘 MSC 或 airui，需用合宙提供的带对应库的固件。

## 四、U盘与升级包要求（无UI版实测结论，同样适用）

- U 盘必须 **FAT32 单分区**；exFAT/NTFS 不识别；
- **不要用多合一读卡器/PSSD**：USB3 桥接芯片端点数超过固件驱动上限，枚举会报
  `Endpoint num 4 overflow`（T.Pssd 实测）；普通品牌 U 盘（SanDisk 3.2Gen1 实测 OK）没问题；
- 升级包（后缀 `.bin`，可在 `conf.lua` 的 `M.usb.suffix` 改）放 U 盘**任意目录**——选择页是文件夹浏览器，可逐级进入选择；
- 升级包用 Luatools 制作：luatOS → 固件工具 → 差分包/整包升级包制作；
  **实测整包可以把固件刷回更旧的内核版本**（V1030 → V1028 成功），做验收时注意别拿错新旧文件；
- 文件浏览器单次最多渲染 **200 行**（树形展开摊平后的可见行数上限，超出截断不崩溃）。

## 五、文件结构与启动顺序

```
fota_usb_disk(有UI界面U盘升级)/
├── main.lua             入口: PROJECT/VERSION, 看门狗, require各模块(不含业务逻辑)
├── conf.lua             唯一配置入口: 板型profile/USB参数/配色/字号
├── lcd_tp.lua           上电时序->display.init->airui.init->hzfont->GT911->绑定触摸
├── ui.lua               待机页/选择页/进度页 + msgbox弹窗, 订阅业务事件
├── fota_usb_disk_ui.lua 业务核心: 常驻HOST/挂载/扫描/升级/失败重试
└── readme.md            本文件
```

启动顺序（`fota_usb_disk_ui.lua` 模块自启动，main.lua 只负责 require，写法同 fota2 demo 的
`require "update"`）：`lcd_tp.init()`（含供电轨、背光压灭、显示、AirUI、字体、触摸）
→ `ui.build()` → 常驻主机模式任务 → `lcd_tp.backlight_on()`。

## 六、UI 页面一览（1024x600）

| 页面 | 内容 | 进入条件 |
|---|---|---|
| 待机页 | "请插入升级 U 盘"卡片 + 当前版本号 | 开机默认 / U盘拔出后 |
| 选择页 | 树形文件浏览器: 顶栏[刷新]+右上角X + 列表(根节点=升级U盘, 点箭头展开/收起, 点行进入文件夹, 文件夹/文件带图标, 仅*.bin可选) + 底部[确认升级], 内容多可滚动 | U盘挂载成功自动弹出 |
| 进度页 | 文件名 + 阶段 + 进度条 + 百分比 + 字节数 + 警告 | 用户二次确认后 |
| 弹窗 | 二次确认 / 无选中提示 / 成功 / 失败(附原因) | 对应操作触发 |

配色为深色系（`conf.lua` 的 `M.ui`），字号统一走 `M.font_sizes`
（hzfont 每字号一份实例，漏加载只会显示方框且不报错）。

## 七、事件消息约定（ui.lua ↔ fota_usb_disk_ui.lua）

| 消息 | 方向 | 参数 | 含义 |
|---|---|---|---|
| `USB_MSC_CONNECT` | 核心→核心 | - | U盘枚举成功 |
| `UDISK_LIST` | 核心→UI | dir, items 表 {name,path,size,is_dir} | 列目录完成，UI重建浏览器并弹选择页 |
| `UDISK_LIST_REQ` | UI→核心 | dir | 展开/进入文件夹时请求列目录（懒加载，路径限挂载点内） |
| `UDISK_REMOVED` | 双向 | - | U盘拔出，UI回待机页 |
| `UDISK_RESCAN` | UI→核心 | - | 用户点[刷新]，重新挂载并回根目录 |
| `UDISK_CLOSE` | UI→核心 | - | **点 ✕**：unmount 并回待机页（重新插拔 U 盘可再次进入） |
| `FOTA_UPGRADE_START` | UI→核心 | path | 用户二次确认，开始升级 |
| `FOTA_PROGRESS` | 核心→UI | done,total,text | 进度（约1%节流） |
| `FOTA_RESULT` | 核心→UI | ok,msg | 升级结果；失败回选择页 |

UI 的所有事件处理均经 `defer()`（`sys.timerStart` 10ms）挪出回调上下文，
避免在触摸回调里做耗时操作（写法与 `Air8607/demo/servo_drv/code/ui.lua` 一致）。

## 八、操作步骤

1. `conf.lua` 选好 `M.board`；脚本 + 带 MSC 的固件烧录到模块；
2. 接好屏（RGB 排线）与触摸（I2C 排线），UART 日志串口接 luatools；
3. 上电：屏幕亮出待机页，日志出现 `USB已进入HOST主机模式`；
4. 插入带 `*.bin` 升级包的 U 盘（FAT32）→ 选择页自动弹出；
5. 点选升级包 → [确认升级] → 弹窗[确定] → 进度页走条；
   （任意时刻点右上角 ✕ 可关闭选择页回待机页，重新插拔 U 盘可再次进入；
     重新上电/重启后同样自动回到主机模式待机状态）
6. 校验通过 → 提示 1 秒后重启 → 重启期间 bootloader 应用升级（日志出现 `soc ota done!`）；
7. 重启后版本号变为新版本即升级成功。

## 九、错误场景与处理

| 场景 | UI 表现 | 处理方式 |
|---|---|---|
| U 盘非 FAT32 | 弹窗"挂载失败" | 拔出重新插入可重试（保持主机模式） |
| U 盘中无 .bin 文件 | 选择页空列表提示 | 拷入升级包后点[刷新] |
| 升级中拔出 U 盘 | 弹窗"读取失败" | 自动回选择页，重新插入后重选 |
| MD5 校验失败 | 弹窗提示版本不匹配 | 换正确升级包重试 |
| 写入失败 | 弹窗提示写入出错 | 自动重新扫描，直接换包重试 |
| 触摸无反应 | - | `lcd_tp.lua` 会自动换 TP_RST 14/72 重试；仍无反应查触摸排线/供电 |

## 十、与无UI版对照

| | 无UI版 | 有UI版 |
|---|---|---|
| 触发方式 | 开机5秒自动进入 | 开机即主机模式，插U盘自动弹窗 |
| 升级包 | 固定 `/udisk/update.bin` | 用户在文件浏览器中逐级进入点选 *.bin |

## 十一、真机实测记录（2026.11.12，Air8603W + Air8605 双板）

以下结论全部来自真机实测，非推测。

**硬件/环境验证通过的项：**

| 项 | Air8603W | Air8605 |
|---|---|---|
| 固件 | V1030（2026.11.05）与 V1028（2026.10.15）**均全功能可用** | V1030_Air1602（2026.11.05）全功能可用 |
| 触摸 | GT911，`TP_RST=GPIO14`，I2C1 100kHz | GT911，`TP_RST=GPIO72`（**双复位脚自动探测已覆盖**，profile 选错也能摸到） |
| 屏幕 | RGB 1024x600，时序 H(20/140/1024/160) V(3/20/600/12) @50MHz pclk，背光 PWM3 | 同左（两板 RGB 屏时序参数一致） |
| U 盘 | SanDisk 3.2Gen1（FAT32）枚举/挂载/读写正常；多合一读卡器报 `Endpoint num 4 overflow` 不可用 | 同左 |
| 升级 | 差分包（无UI版）与整包（有UI版，含跨内核版本 V1030→V1028）都能被 bootloader 正确应用 | 树形浏览器选包升级 + 滑动浏览实测正常 |
| 板型互换 | — | 8603 profile 未改直接跑也能亮屏+U盘正常（供电轨脚位重合），触摸靠自动探测命中，属侥幸兼容，仍建议选对 M.board |

**airui 实测的三个坑（本 demo 代码已按此规避，写自己的界面时注意）：**

1. `airui.msgbox` **必须显式传 `w`/`h`**（建议再加 `style={text_font_size=20}`）：
   不传时默认文本区极窄，中文一字一行竖排（真机截图踩坑确认）；
2. `airui.button` **不返回控件对象**（返回 nil）：不能对按钮做 `set_hidden` 等操作；
   需要显隐按钮时，把按钮包进一个同色 `airui.container`，对容器做显隐（`[◀返回]` 的做法）；
3. 长文件名直接拼进 label 会**折行溢出**：进度页文件名用"中间截断保头保尾"（最多32字符），
   弹窗里用"截尾"（最多40字符）；
4. **`airui.container` 的 `on_click` 在 `scrollable` 容器内触摸无响应**（V1030 实测，8603 factory
   file_manager 同款写法在本固件上也不触发）：列表行要用 `airui.button` 做底座才能点（本 demo
   树形浏览器的做法：可点行用 button，纯显示行用 container 省手势判定开销）；
5. **`airui.container` 支持 `scrollable = true`**：内容超出高度自带滚动条，但为"跟手拖动"式，
   **无惯性甩动**（手指离开即停），脚本层无法改变；
6. **hzfont 字形覆盖有限**（ASCII+常用汉字，约 7600 字形）：`▶ ▼ ✕ ·` 等符号均无字形，
   渲染成空方框且日志刷 `hzfont get bitmap failed`——特殊符号一律用 ASCII 替代
   （本 demo 用 `>`/`v` 做展开箭头、`X` 做关闭钮、`|` 做分隔）。

**日志里的无害打印（不要误判为故障）：**

| 打印 | 含义 |
|---|---|
| `E/pwm setup ch 3`（后跟 `channel 3, period...`） | pwm 库配置背光通道时的正常输出，背光实际已点亮 |
| `i2c1 wait free CR 1, SR 68`（触摸操作时刷屏） | GT911 轮询期间 I2C 总线等待重试，触摸功能正常 |
| `luat_timer_start: no free timer, create new` | 动态扩充定时器池的提示 |
| `luat_gpio_set: pin 255 disable use`（V1028 上成串出现） | V1028 display 初始化 RGB 脚表的打印，V1030 已无 |
| `soc_flash_lfs_init: mount fail=-84` | 文件系统区首启格式化前的正常提示 |

**烧录/联调要点：**

- 脚本运行后 USB 切主机模式，Type-C CDC 日志断开属正常，联调日志走 J10 UART
  （Luatools 自动识别 6M 波特率）；
- 烧录用 USB2 口，U 盘插 USB1（U盘座），两者别接反。
