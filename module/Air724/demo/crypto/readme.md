## 功能模块介绍

1、main.lua：主程序入口；

2、crypto_app.lua：演示有关加解密的各个 API 的功能，包含 MD5、SHA 等哈希算法，AES、DES、3DES 对称加解密，CRC、checksum 校验和等；

3、logo.jpg：待加密文件，用于演示计算文件的 hash 值（md5/sha1/sha256 及 hmac 形式）；

## 演示功能概述

1、创建一个task；

2、在task中的任务处理函数中，依次演示 MD5、HMAC-MD5、SHA1、HMAC-SHA1、SHA256、HMAC-SHA256、SHA512、HMAC-SHA512 哈希计算，AES-128-ECB、AES-128-CBC 对称加解密，DES-ECB、3DES-ECB 对称加解密，CRC16、CRC16_MODBUS、CRC32、CRC8、CRC7 校验计算，真随机数、TOTP 动态码、Base64 编解码，文件 hash 值、流式 hash、checksum 校验和等功能；

3、全部演示完成后，任务等待100秒后结束；

## 演示硬件环境

1、Air724UG 核心板一块（或 EVB_Air724UG_A14 开发板）

2、TYPE-C USB 数据线一根（使用核心板时）；开发板（EVB_Air724UG_A14）为 Micro-USB 接口，需使用 Micro-USB 数据线

3、Air724UG 核心板/开发板和数据线的硬件接线方式为

- Air724UG 核心板通过 TYPE-C USB 口（开发板通过 Micro-USB 口）连接 USB 数据线，数据线的另外一端连接电脑的 USB 口；

- Air724UG 核心板/开发板通过 USB 口供电，同时用于烧录固件和查看日志；

更详细的硬件环境说明参考：[Air724UG 硬件环境清单](https://docs.openluat.com/air724_soc/luatos/common/hwenv/)。

Air724UG 核心板购买链接：[合宙官方淘宝店铺](https://luat.taobao.com/)
