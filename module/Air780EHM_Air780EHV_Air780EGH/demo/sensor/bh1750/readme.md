# BH1750 数字环境光传感器应用功能演示

## 一、功能模块介绍

### 1.1 核心主程序模块

1. **main.lua** - 主程序入口，负责项目初始化、版本定义和任务调度
2. **bh1750_demo** - BH1750 功能演示模块，包含连续测量测试、单次测量测试、分辨率切换测试、电源管理测试功能的演示用例

### 1.2 扩展库模块

1. **exs_bh1750** - BH1750 扩展库，提供 I2C 初始化、测量模式设置、照度读取、原始数据读取、测量时间调整、电源管理等 10 个 API

## 二、演示流程介绍

本 demo 按顺序演示 exs_bh1750 扩展库的 4 项功能：连续测量测试、单次测量测试、分辨率切换测试、电源管理测试

### 2.1 功能演示项说明

1. 连续测量测试（[1/4]）- 连续 H 分辨率模式，每秒读取一次照度，共 5 次，观察光照变化趋势
2. 单次测量测试（[2/4]）- 单次 H 分辨率模式，每次触发测量后读取，共 3 次，演示低功耗测量流程
3. 分辨率切换测试（[3/4]）- H/H2/L 三种分辨率切换，对比 lux 读数差异（1 lux / 0.5 lux / 4 lux）
4. 电源管理测试（[4/4]）- MTreg 调整 / 断电 / 上电 / 复位功能演示

#### 3.2.2 传感器安装说明

- 传感器应安装在能接收环境光的位置，避免被外壳、胶体遮挡
- 透光窗口需朝上或朝向被测光源方向
- 若安装在深色玻璃下方，光照会被明显衰减，需评估是否满足量程要求

### 5.4 演示效果观察

1. **[1/4] 连续测量演示**：每秒打印一次照度 lux 值，共 5 次。用手遮挡传感器或改变光源方向，可观察到读数实时变化
2. **[2/4] 单次测量演示**：每次触发测量后读取一次，共 3 次。单次模式测量完成后自动断电，适合低功耗场景
3. **[3/4] 分辨率切换演示**：H（1 lux）/ H2（0.5 lux）/ L（4 lux）三种分辨率切换，H2 分辨率最高、读数最精细
4. **[4/4] 电源管理演示**：MTreg=31 时灵敏度降低、读数偏小；MTreg=254 时灵敏度提高、读数偏大；断电后读取返回 nil（符合预期），上电/复位后恢复正常

## 六、常见问题

### 6.1 初始化失败，日志提示"指定从设备地址无响应"

1. 检查 SCL/SDA 接线是否正确（67=I2C1_SCL、66=I2C1_SDA）
2. 检查 VCC 是否供电（3.3V），GND 是否共地
3. 检查 ADDR 引脚接线与代码地址是否一致（接地为 0x23，接 VCC 为 0x5C，可在 init 中指定地址）

### 6.2 读数始终为 0 或偏小

1. 检查传感器透光窗口是否被遮挡，是否紧贴不透光外壳
2. 检查安装位置是否能正常接收环境光
3. 深色玻璃下方安装时光照衰减明显，需评估量程是否满足

### 6.3 读数波动大

1. 检查供电是否稳定（建议使用 3V3 供电，避免使用电池直接供电时电压波动）
2. 检查 I2C 走线是否过长或与强干扰源并行（建议杜邦线长度不超过 20cm）
3. 若在 50Hz/60Hz 交流光源环境下读数波动，可适当增大 MTreg 延长测量时间以平滑波动
