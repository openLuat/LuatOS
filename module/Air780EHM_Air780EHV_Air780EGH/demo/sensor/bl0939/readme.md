> <font color="red"><b>声明：
> 
>严禁带电操作！ 进行任何连接或拆卸前，务必断开电源。

>高压危险！ 测试220V时，请确保所有接线可靠，并使用隔离变压器及漏电保护器。

>本介绍为技术支持页面，操作人员需具备电气安全知识，否则请勿尝试，操作风险由使用者自行承担</b></font>

## 项目简介
**Air780EHV**：通过 UART1（MAIN_UART）或 SPI0 读取上海贝岭 BL0939 双路电能计量芯片，持续循环读取 + 失联自动重连，内置实机校准系数。Air780EHV 与 Air780EPM 共用同一张 GPIO 复用表，UART1 引脚定义一致。

## 文件结构
- `user/main.lua`：脚本入口
- `user/bl0939_app.lua`：业务逻辑（循环读取/换算/断线重连；`MODE` 变量切换 uart/spi）
- `lib/exs_bl0939.lua`：BL0939 驱动扩展库（SPI/UART 双模式）

## 一、软件环境
1. LuaTools 中下载 Air780EHV 最新 core 固件 `LuatOS-SoC_Vxxxx_Air780EHV.soc`；
2. Air780EHV IO 电平**固定 3.3V**（**Air780EHV-1.8V 型号固定 1.8V**，需加电平转换）；耐压上限 3.6V。

## 二、硬件接线（UART 模式，接 220V 市电后使用 P2 光耦隔离口）

| 功能 | Air780EHV | BL0939 板 |
|---|---|---|
| 光耦次级供电 | 3.3V | P2-1 (V) |
| 地 | GND | P2-4 (G) |
| UART1 发送 | **GPIO18 (PIN18) = UART1_TXD** | P2-2 (RXD) |
| UART1 接收 | **GPIO17 (PIN17) = UART1_RXD** | P2-3 (TXD) |
| A 路负载 | — | L 与 P1-1 (N1) 之间 |
| B 路负载 | — | L 与 P1-3 (N2) 之间 |

注意事项：
- UART 固定 **4800bps / 8 / N / 1.5**；BL0939 器件地址=0（SSOP20L，A4~A1 悬空）；
- Air780EHV 调试口为 **PIN38/39（UART0）**，本 demo 用 UART1 与 BL0939 通信；
- 冷态自测（不接市电）：外部 3.3V 供 P3-1/P3-2，日志应见温度读数、RAW 全 0 但 TPS1 非 0；
- 安全：接市电后 P2 为光耦隔离接口；切勿在 SPI/直连方式下与热侧共地操作。

## 三、SPI 模式（实验性，仅冷态测试）
`lib/exs_bl0939.lua` 内置完整 SPI 驱动（从机、半双工、无片选、Mode1、500kHz、8bit MSB first、6 字节帧 + 校验、软复位 0xFF*6），与 UART 共用全部业务逻辑（循环读取/失联重连/换算系数）。

切换方式：`user/bl0939_app.lua` 中 `MODE = "spi"`（默认 `"uart"`）。

| 功能 | Air780EHV（SPI0） | BL0939 板 |
|---|---|---|
| SCLK | **PIN86 / GPIO11 (SPI0_SCLK)** | U1-17 SCLK |
| MOSI | **PIN85 / GPIO9 (SPI0_MOSI)** | U1-18 RX/SDI |
| MISO | **PIN84 / GPIO10 (SPI0_MISO)** | U1-19 TX/SDO（外部 10K 上拉 3.3V）|
| 片选 | PIN83 / GPIO8 占位 | 无 CS，不接 |
| 模式选择 | — | U1-16 SEL 拉高到 3.3V |
| 地址引脚 | — | U1-9/11 (A1/A3) 拉高 3.3V，U1-10/12 (A2/A4) 悬空 |

⚠️ 安全警告：SPI 信号与 BL0939 热侧直连、无光耦隔离，**只能在断开市电的冷态下测试**（外部 3.3V 供 P3-1/P3-2，GND 共地）。如需市电下 SPI 计量，必须另加 4 路光耦/磁隔离。

冷态验证预期：日志出现 `写保护解锁成功` + `初始化完成，模式：spi` + 温度≈28°C、RAW 全 0 但 TPS1≠0，即 SPI 通信正常。

注：Air780EHV 因内置 ES8311 Audio Codec 占用 I2C0，**不支持 SPI1**，本 demo 使用 **SPI0**（PIN83/84/85/86）。

## 四、校准系数（内置，基于 227V/698R 实机基准）
- `KU=16560`（电压）、`KI=275447`（电流）、`KPA=KPB=712.7`（有功）、`KW=6118`（电能）；
- 系数标定的是 BL0939 板（采样电阻/分压网络），与主机模组无关，UART/SPI 通用；
- 电能建议带载长测 ≥10 分钟对比电表精调 KW。

## 六、失联自动恢复
芯片掉电/接线接触不良时：连续 3 次读取异常 → 自动 `close()+setup()` 重连 → 数据自动恢复，无需人工干预（日志可见 `读取异常(1/3)…重新初始化 BL0939…重新连接成功`）。

## 七、故障排查
| 现象 | 处理 |
|---|---|
| 初始化失败 / 写保护解锁失败 | 检查 3.3V/GND；确认 SEL 悬空（UART 模式）；核对 UART1 引脚 |
| 数据全 0 且 TPS1=0 | BL0939 板未供电（检查市电或 P3 外部供电） |
| 电压=0 但温度正常 | 冷态（未接市电）正常现象 |
| 持续超时刷屏 | 检查 P2 信号线/负载接触；失联重连会自动恢复 |
| SPI 模式读不到数据 | 确认 SEL/A1/A3 已拉高、SDO 已上拉、SPI0 引脚正确；SPI 仅限冷态测试 |

## 八、实测验证结论（2026-08-21）
负载 698R（500R+200R 串联）接 A 路，市电约 222.7V，UART 模式实机测试：

|---|---|---|---|
| 电压 | 222.7V（V_RMS≈3,688,000） | 市电约 222~223V | 一致 |
| A 路电流 | 0.318A（IA_RMS≈87,750） | 222.7/698=0.3191A | -0.35% |
| A 路有功 | 70.9W（A_WATT≈50,500） | 222.7²/698=71.1W | -0.2% |
| 相角 | ≈0° | 纯阻性 | ✅ |
| 电能 | W1=2 → 0.0003kWh | 2×0.0001635=0.00033kWh | ✅ |
| 温度 | 29.2~29.4°C | 正常 | ✅ |
| B 路 | 全 0 | 未接 | ✅ |
| 通信 | 全包校验零超时 | — | ✅ |

**结论**：Air780EHV 移植验证通过（UART1=GPIO17/18 接线正确）；校准系数与 780EPM 完全一致，无需调整；SPI 模式待冷态验证。
