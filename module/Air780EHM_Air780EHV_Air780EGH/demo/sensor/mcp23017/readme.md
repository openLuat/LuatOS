# MCP23017 GPIO 扩展应用功能演示

## 一、功能模块介绍

### 1.1 核心主程序模块

1. **main.lua** - 主程序入口，负责项目初始化、版本定义和任务调度
2. **mcp23017_demo** - MCP23017 功能演示模块，包含 GPIO 输出测试、输入测试、GPIO 中断测试、上拉电阻测试功能的演示用例

### 1.2 扩展库模块

1. **exs_mcp23017** - MCP23017 扩展库，提供 I2C 初始化、配置扩展 GPIO 管脚功能、设置输出电平、读取输入电平、上拉电阻配置等 API

## 二、演示流程介绍

本 demo 按顺序演示 exs_mcp23017 扩展库的 4 项功能：GPIO 输出测试、GPIO 输入测试、GPIO 中断测试、上拉电阻测试

### 2.1 功能演示项说明

1. MCP23017 扩展 GPIO 输出测试
2. MCP23017 扩展 GPIO 输入测试
3. MCP23017 扩展 GPIO 中断测试
4. MCP23017 内部上拉电阻测试

## 五、演示核心步骤

### 5.1 硬件准备

1. 按照接线表将 MCP23017 模块连接到核心板
2. 确保电源连接正确，通过 TYPE-C USB 口供电
3. 检查所有接线无误，避免短路

### 5.2 软件配置

在 `main.lua` 中加载对应的演示模块：

```lua
-- 加载 mcp23017_demo.lua 演示模块
require "mcp23017_demo"
```

### 5.3 软件烧录

1. 使用 Luatools 选择最新内核固件
2. 下载本项目所有脚本文件
3. 将固件和脚本一起烧录到设备
4. 烧录成功后设备自动重启后开始运行

### 5.4 功能测试

#### 5.4.1 MCP23017 扩展 GPIO 输出演示

- 扩展 GPIO 输出演示时，无需接线；通过万用表或者示波器检测 MCP23017 板上的 PA0 电平即可

#### 5.4.2 MCP23017 扩展 GPIO 输入演示

- 扩展 GPIO 输入演示时，将 MCP23017 板上的 PA1 和 PA2 两个引脚通过杜邦线短接
- 软件上会将 PA1 配置为输出（第一秒输出低电平，第二秒输出高电平，如此循环输出）
- 将 PA2 配置为输入，通过检测 PA2 引脚输入电平的状态来演示

#### 5.4.3 MCP23017 扩展 GPIO 中断演示

- 扩展 GPIO 中断演示时，将 MCP23017 板上的 PA3 和 PA4 两个引脚通过杜邦线短接
- 将 MCP23017 板上的 PB3 和 PB4 两个引脚通过杜邦线短接
- 软件上会将 PA3 和 PB3 配置为输出（第一秒输出低电平，第二秒输出高电平，如此循环输出）
- 将 PA4 和 PB4 配置为中断，通过检测中断函数的触发状态来演示

#### 5.4.4 MCP23017 内部上拉电阻演示

- 上拉电阻演示时，PA5 启用内部上拉电阻，PB5 禁用内部上拉电阻
- 观察两者读取的电平差异（启用上拉的引脚在悬空时读取为高电平）

### 5.5 预期效果

- 通过万用表或者示波器检测 MCP23017 板上的 PA0 电平，持续 1 秒输出 0V 的低电平，持续 1 秒输出 3.3V 的高电平，循环输出，表示 GPIO 输出测试正常；
- 通过观察 Luatools 的运行日志，首先打印 `mcp23017.get(0x02) 0`，再隔一秒打印 `mcp23017.get(0x02) 1`，再隔一秒打印 `mcp23017.get(0x02) 0`，如此循环输出，表示 GPIO 输入测试正常；
- 通过观察 Luatools 的运行日志，首先打印 `PA4_int_cbfunc 4 0 PB4_int_cbfunc 20 0`，再隔一秒打印 `PA4_int_cbfunc 4 1 PB4_int_cbfunc 20 1`，再隔一秒打印 `PA4_int_cbfunc 4 0 PB4_int_cbfunc 20 0`，如此循环输出，表示 GPIO 中断测试正常；
- 通过观察 Luatools 的运行日志，打印 `PA5(上拉):1  PB5(无上拉):0`，表示上拉电阻测试正常；
