# PCA9555 GPIO 扩展应用功能演示

## 一、功能模块介绍

### 1.1 核心主程序模块

1. **main.lua** - 主程序入口，负责项目初始化、版本定义和任务调度
2. **pca9555_demo** - PCA9555 功能演示模块，包含GPIO 输出测试、输入测试、GPIO 中断测试功能的演示用例

### 1.2 扩展库模块

1. **exs_pca955** - PCA9555 扩展库，提供 I2C 初始化、配置扩展 GPIO 管脚功能、设置输出电平、读取输入电平等 API

## 二、演示流程介绍

本 demo 按顺序演示 exs_pca9555 扩展库的 3 项功能：GPIO 输出测试、GPIO 输入测试、GPIO 中断测试

### 2.1 功能演示项说明

1. PCA9555 扩展 GPIO 输出测试
2. PCA9555 扩展 GPIO 输入测试
3. PCA9555 扩展 GPIO 中断测试

## 五、演示核心步骤

### 5.1 硬件准备

1. 按照接线表将 PCA9555模块连接到核心板
2. 确保电源连接正确，通过 TYPE-C USB 口供电
3. 首次上电请将设备水平放置，以便自动校准
4. 检查所有接线无误，避免短路

### 5.2 软件配置

在 `main.lua` 中加载对应的演示模块：

```lua
-- 加载 pca9555_demo.lua 演示模块
require "pca9555_demo"

```

### 5.3 软件烧录

1. 使用 Luatools 选择最新内核固件
2. 下载本项目所有脚本文件
3. 将固件和脚本一起烧录到设备
4. 烧录成功后设备自动重启后开始运行

### 5.4 功能测试

#### 5.4.1 PCA9555 扩展 GPIO 输出演示

- 扩展GPIO输出演示时，无需接线；通过万用表或者示波器检测pca9555板上的P00电平即可

#### 5.4.2 PCA9555 扩展 GPIO 输入演示

- 扩展GPIO输入演示时，将pca9555板上的P10和P11两个引脚通过杜邦线短接
- 软件上会将P10配置为输出（第一秒输出低电平，第二秒输出高电平，如此循环输出）
- 将P11配置为输入，通过检测P11引脚输入电平的状态来演示

#### 5.4.3 PCA9555 扩展 GPIO 中断演示

- 扩展GPIO中断演示时，将pca9555板上的P03和P04两个引脚通过杜邦线短接
- 将pca9555板上的P13和P14两个引脚通过杜邦线短接
- 软件上会将P03和P13配置为输出（第一秒输出低电平，第二秒输出高电平，如此循环输出）
- 将P04和P14配置为中断，通过检测中断函数的触发状态来演示

### 5.5 预期效果

- 通过万用表或者示波器检测pca9555板上的P00电平，持续1秒输出0V的低电平，持续1秒输出3.3V的高电平，循环输出，表示GPIO输出测试正常；
- 通过观察Luatools的运行日志，首先打印 air_gpio.get(0x11) 0， 再隔一秒打印 air_gpio.get(0x11) 1，再隔一秒打印 air_gpio.get(0x11) 0，如此循环输出，表示GPIO输入测试正常；
