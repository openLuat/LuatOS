

# PCF8574 GPIO 扩展应用功能演示

## 一、功能模块介绍

### 1.1 核心主程序模块

1. **main.lua** - 主程序入口，负责项目初始化、版本定义和任务调度
2. **pcf8574_demo** - PCF8574 功能演示模块，包含 GPIO 输出测试、输入测试、GPIO 中断测试、批量读写测试功能的演示用例

### 1.2 扩展库模块

1. **exs_pcf8574** - PCF8574 扩展库，提供 I2C 初始化、配置扩展 GPIO 管脚功能、设置输出电平、读取输入电平、批量读写端口数据等 API

## 二、演示流程介绍

本 demo 按顺序演示 exs_pcf8574 扩展库的 4 项功能：GPIO 输出测试、GPIO 输入测试、GPIO 中断测试、批量读写测试

### 2.1 功能演示项说明

1. PCF8574 扩展 GPIO 输出测试
2. PCF8574 扩展 GPIO 输入测试
3. PCF8574 扩展 GPIO 中断测试
4. PCF8574 批量读写测试

## 五、演示核心步骤

### 5.1 硬件准备

1. 按照接线表将 PCF8574 模块连接到核心板
2. 确保电源连接正确，通过 TYPE-C USB 口供电
3. 检查所有接线无误，避免短路

### 5.2 软件配置

在 `main.lua` 中加载对应的演示模块：

```lua
-- 加载 pcf8574_demo.lua 演示模块
require "pcf8574_demo"
```

### 5.3 软件烧录

1. 使用 Luatools 选择最新内核固件
2. 下载本项目所有脚本文件
3. 将固件和脚本一起烧录到设备
4. 烧录成功后设备自动重启后开始运行

### 5.4 功能测试

#### 5.4.1 PCF8574 扩展 GPIO 输出演示

- 扩展 GPIO 输出演示时，无需接线；通过万用表或者示波器检测 PCF8574 板上的 P0 电平即可

#### 5.4.2 PCF8574 扩展 GPIO 输入演示

- 扩展 GPIO 输入演示时，将 PCF8574 板上的 P1 和 P2 两个引脚通过杜邦线短接
- 软件上会将 P1 配置为输出（第一秒输出低电平，第二秒输出高电平，如此循环输出）
- 将 P2 配置为输入，通过检测 P2 引脚输入电平的状态来演示

#### 5.4.3 PCF8574 扩展 GPIO 中断演示

- 扩展 GPIO 中断演示时，将 PCF8574 板上的 P3 和 P4 两个引脚通过杜邦线短接
- 将 PCF8574 板上的 P5 和 P6 两个引脚通过杜邦线短接
- 软件上会将 P3 和 P5 配置为输出（第一秒输出低电平，第二秒输出高电平，如此循环输出）
- 将 P4 和 P6 配置为中断，通过检测中断函数的触发状态来演示

#### 5.4.4 PCF8574 批量读写演示

- 批量读写演示无需额外接线
- 软件会循环调用 write_all() 和 read_all() 接口
- 演示 PCF8574 的批量端口操作能力

### 5.5 预期效果

- 通过万用表或者示波器检测 PCF8574 板上的 P0 电平，持续 1 秒输出 0V 的低电平，持续 1 秒输出 3.3V 的高电平，循环输出，表示 GPIO 输出测试正常；
