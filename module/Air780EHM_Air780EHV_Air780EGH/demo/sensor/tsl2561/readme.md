# TSL2561 数字环境光传感器应用功能演示

## 一、功能模块介绍

### 1.1 核心主程序模块

1. **main.lua** - 主程序入口，负责项目初始化、版本定义和任务调度
2. **tsl2561_demo** - TSL2561 功能演示模块，包含基础读取测试、积分时间切换测试、增益切换测试、中断与电源管理测试功能的演示用例

### 1.2 扩展库模块

1. **exs_tsl2561** - TSL2561 扩展库，提供 I2C 初始化、增益/积分时间配置、双通道原始数据读取、照度 lux 计算、阈值中断、手动积分、电源管理等 14 个 API

## 二、演示流程介绍

本 demo 按顺序演示 exs_tsl2561 扩展库的 4 项功能：基础读取测试、积分时间切换测试、增益切换测试、中断与电源管理测试

### 2.1 功能演示项说明

1. 基础读取测试（[1/4]）- 默认配置（1x 增益 + 402ms 积分），每秒读取一次 CH0/CH1 原始值与 lux 照度，共 5 次，观察光照变化趋势
2. 积分时间切换测试（[2/4]）- 13.7ms / 101ms / 402ms 三种积分时间切换，lux 已自动归一化，对比读数差异
3. 增益切换测试（[3/4]）- 1x / 16x 增益切换，低照度用 16x 提高灵敏度，强光用 1x 避免饱和
4. 中断与电源管理测试（[4/4]）- 阈值中断设置/清除、手动积分、断电/上电/复位功能演示

> 说明：
>
> - **ADDR SEL 地址选择**：TSL2561 从机地址由 ADDR SEL 引脚决定——接地为 0x29、悬空为 0x39（默认）、接 VDD 为 0x49。本 demo 使用 ADDR SEL 接地（地址 0x29），如模块地址不同，可在 `tsl2561.init(1, 0x39)` 或 `tsl2561.init(1, 0x49)` 中指定。
>
> - **I2C 上拉电阻**：TSL2561 模块通常已集成 I2C 上拉电阻（如 GY-2561 内置 10kΩ 上拉），可直接连接；若使用裸芯片需在 SCL/SDA 上外接 4.7kΩ~10kΩ 上拉电阻到 3V3。
>
> - **INT 中断引脚**：TSL2561 的 INT 引脚为开漏输出（低有效），需外接上拉电阻（模块一般已集成）。本 demo 通过 I2C 寄存器配置阈值中断并清除中断，未使用 GPIO 监控 INT 引脚；如需硬件中断通知，可将 INT 连接到主控 GPIO 并配合 `set_interrupt` 使用。
>
> - 具体引脚以模块实际丝印为准。

#### 3.2.2 传感器安装说明

- 传感器应安装在能接收环境光的位置，避免被外壳、胶体遮挡
- 透光窗口需朝上或朝向被测光源方向
- 若安装在深色玻璃下方，光照会被明显衰减，需评估是否满足量程要求
- TSL2561 内置 50/60Hz 光噪声抑制电路，交流光源下读数稳定

### 5.4 演示效果观察

1. **[1/4] 基础读取演示**：每秒打印一次 CH0/CH1 原始值与 lux 照度，共 5 次。用手遮挡传感器或改变光源方向，可观察到读数实时变化
2. **[2/4] 积分时间切换演示**：13.7ms（快速采样）/ 101ms（均衡）/ 402ms（高精度）三种积分时间切换，lux 已按 (402/积分时间) 自动归一化，三种配置读数应基本一致
3. **[3/4] 增益切换演示**：低增益 1x 适合明亮环境；高增益 16x 灵敏度提高 16 倍，适合低照度环境。强光下 16x 可能饱和（CH0=0xFFFF，lux 记为 0）
4. **[4/4] 中断与电源管理演示**：阈值取当前 CH0 的 ±20% 设置电平中断并清除；手动积分 100ms 后读取；断电后读取返回 nil（符合预期），上电/复位后恢复正常

## 六、常见问题

### 6.1 初始化失败，日志提示"指定从设备地址无响应"

1. 检查 SCL/SDA 接线是否正确（67=I2C1_SCL、66=I2C1_SDA）
2. 检查 VCC 是否供电（3.3V），GND 是否共地
3. 检查 ADDR SEL 引脚接线与代码地址是否一致（接地为 0x29、悬空为 0x39、接 VDD 为 0x49，可在 init 中指定地址）
4. 若使用裸芯片，检查 SCL/SDA 是否缺少上拉电阻（需 4.7kΩ~10kΩ 上拉到 3V3）

### 6.2 初始化失败，日志提示"芯片型号不匹配"

1. 读取到的 ID 寄存器 PARTNO 字段不是 0001（TSL2561）
2. 确认芯片是否为 TSL2561（而非 TSL2560，PARTNO=0000），本扩展库仅支持 TSL2561

### 6.3 读数始终为 0 或偏小

1. 检查传感器透光窗口是否被遮挡，是否紧贴不透光外壳
2. 检查安装位置是否能正常接收环境光
3. 深色玻璃下方安装时光照衰减明显，需评估量程是否满足
4. 低照度环境建议切换为高增益 16x（set_timing(GAIN_16X, INTEG_402MS)）提高灵敏度

### 6.4 强光下读数异常或为 0

1. 强光下 16x 增益会导致 ADC 饱和（CH0=0xFFFF），lux 记为 0，属正常现象
2. 建议切换为低增益 1x 或缩短积分时间（13.7ms）避免饱和

### 6.5 读数波动大

1. 检查供电是否稳定（建议使用 3V3 供电，避免使用电池直接供电时电压波动）
2. 检查 I2C 走线是否过长或与强干扰源并行（建议杜邦线长度不超过 20cm）
3. TSL2561 内置 50/60Hz 光噪声抑制电路，若交流光源下读数仍有波动，可适当增大积分时间平滑波动
