# VEML3328 RGBW 颜色传感器应用功能演示

## 一、功能模块介绍

### 1.1 核心主程序模块

1. **main.lua** - 主程序入口，负责项目初始化、版本定义和任务调度
2. **veml3328_app.lua** - VEML3328 功能演示模块，包含基础颜色检测、增益配置、集成时间测试、低光检测等演示用例

### 1.2 扩展库模块

1. **exs_veml3328** - VEML3328 扩展库，提供 I2C 初始化、RGBW+IR 数据读取、增益设置、集成时间配置等 API

### 1.3 I2C 模式说明

本 demo 支持软件 I2C 和硬件 I2C 两种模式切换，通过 `veml3328_app.lua` 中的 `MODE` 变量配置：

- `MODE = 1`：软件 I2C 模式（推荐），VEML3328 要求 Repeated Start 读取，硬件 I2C 会发 STOP 导致读取失败
- `MODE = 2`：硬件 I2C 模式（不推荐），Air780EHM/Air780EHV/Air780EGH 的 I2C1 默认引脚为 SCL=引脚67、SDA=引脚66

软件 I2C 模式引脚配置（Air780EHV）：
- SCL：引脚 28 / GPIO12
- SDA：引脚 29 / GPIO13

## 二、演示流程介绍

本 demo 按顺序演示 exs_veml3328 扩展库的 4 项功能：

### 2.1 功能演示项说明

1. **[1/4] 基础颜色检测** - 读取 5 次 RGBW+IR 原始数据，验证传感器正常工作
2. **[2/4] 增益配置测试** - 测试 1x、2x、4x 增益下的测量数据
3. **[3/4] 集成时间与灵敏度测试** - 测试 100ms、200ms 集成时间的测量精度
4. **[4/4] 低光检测与颜色分析** - 高灵敏度模式下的颜色比例分析

> **注意**：VEML3328 需要使用软件 I2C 模式（MODE=1），硬件 I2C 模式无法正确读取数据。

> **SDA/SCL 上拉电阻**：VEML3328 的 SDA 和 SCL 需要外接 4.7kΩ~10kΩ 上拉电阻到 VCC。大多数 VEML3328 模块已集成上拉电阻。

> **硬件 I2C 说明**：VEML3328 要求 I2C 读取时使用 Repeated Start（通信过程中不能发送 STOP 信号），Air780EHM/Air780EHV/Air780EGH 的硬件 I2C 在通信结束后一定会发送 STOP 信号，因此无法使用硬件 I2C 模式，必须使用软件 I2C 模式。

## 五、演示核心步骤

### 5.1 硬件准备

1. 按照接线表将 VEML3328 模块连接到 Air780EHM/Air780EHV/Air780EGH 核心板
2. 确保电源连接正确，通过 TYPE-C USB 口供电
3. 检查 SDA/SCL 上拉电阻是否存在
4. 检查所有接线无误，避免短路

### 5.2 软件配置

在 `veml3328_app.lua` 中确认 `MODE` 变量设置为 1（软件 I2C 模式）：

```lua
local MODE = 1  -- 1=软件 I2C（推荐），2=硬件 I2C（不推荐）
```

### 5.3 软件烧录

1. 使用 Luatools 选择 Air780EHM/Air780EHV/Air780EGH 对应内核固件
2. 下载本项目所有脚本文件
3. 将固件和脚本一起烧录到设备
4. 烧录成功后设备自动重启开始运行

### 5.4 功能测试

#### 5.4.1 [1/4] 基础颜色检测测试

- 传感器默认配置：增益 1x、集成时间 100ms
- 连续读取 5 次 RGBW+IR 原始数据
- 观察日志中 R/G/B/C/IR 数值是否在正常范围内

#### 5.4.2 [2/4] 增益配置测试

- 依次测试 1x、2x、4x 增益配置
- 观察不同增益下数据值的变化（增益越高，数值越大）
- 注意：高增益下易饱和，不适合强光环境

#### 5.4.3 [3/4] 集成时间与灵敏度测试

- 依次测试 100ms、200ms 集成时间
- 对比不同集成时间下的测量精度
- 集成时间越长，数据越稳定，但响应速度越慢

#### 5.4.4 [4/4] 低光检测与颜色分析

- 切换到高灵敏度模式（集成时间 400ms、增益 4x）
- 在低光环境下读取数据
- 分析 RGB 比例，判断主色调

### 5.6 故障排除

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 初始化失败 | 接线错误或传感器损坏 | 检查 SDA/SCL 接线，确认供电正常 |
| 数据全为 0xFFFF | 使用了硬件 I2C 模式 | 改为软件 I2C 模式（MODE=1） |
| 数据全为 0 | 传感器未正常工作 | 检查供电，确认传感器窗口无遮挡 |
| 数据不稳定 | I2C 信号干扰 | 添加上拉电阻，缩短接线长度 |
| 增益设置无效 | 参数超出范围 | 使用支持的增益值：1/2/4/12 |
