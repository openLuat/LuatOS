# Air8000 / EC718HM：USB 日志口通用设备文件管理

这个示例通过模组的 USB SoC 日志接口连接 Luatools 的“设备文件管理”，提供挂载点枚举、目录浏览、文件上传和下载。服务不依赖 TTS、字体、外置资源部署包或网络。

## 烧录和操作

1. 使用包含 EC718 USB 用户指令桥接的底层固件。SDK 的 `project/luatos/inc/luat_conf_bsp_types_ec718hm.h` 已启用 `LUAT_USE_LOG_USER_CMD`；构建还需配套 USB 输入／输出 wrap 和 `luat_log_usercmd_*` 平台源文件。
2. 在 Luatools 项目中加入本目录的 `main.lua` 和 `script/libs/hzadb.lua`。脚本编译位宽匹配固件：15号为32位，115号为64位。
3. 正常执行“下载底层和脚本”。这个方案使用普通 SOC，不添加外置资源声明和资源下载流程。
4. 启动后看到 `filemgr ready`。打开 Luatools 日志连接，选择实际的 **SoC LOG PORT**，例如 COM10，然后打开“设备文件管理”窗口。
5. 窗口自动握手并枚举挂载点。可以在内部可写文件系统或 `/ram/` 中创建目录、上传文件、下载回电脑，并核对文件内容。

COM10 是 Windows 的枚举结果，不是固件配置。应选择 SoC 日志接口，不能选择 AT／下载接口。文件管理器复用 Luatools 已打开的日志连接，不需要另开物理 UART，也不需要串口助手发送裸字节。

## 文件系统与目录范围

- `hzadb.fs()` 默认提供标准文件操作，不使用资源服务的候选目录限制。
- 内部可写文件系统可以持久保存普通文件；`/ram/` 的内容在重启后消失。
- 已由业务程序挂载的外置文件系统也会出现在挂载点列表中。外置 Flash 的供电、型号识别和挂载由原业务负责，本示例不硬编码 NAND／NOR 型号或 GPIO。
- `/luadb` 的文件内容读取继续沿用 hzadb 原有的禁止策略；只读文件系统本身也不支持上传、删除。其目录和元信息仍可按文件系统能力枚举。
- hzadb 路径上限是127字节。中文路径按 UTF-8 字节计数。

建议先在 `/ram/` 上传包含 `00 / A5 / A6` 的二进制文件并下载回读，再在内部持久文件系统测试重启后的文件。文件管理操作会改变所选目录，请使用独立的测试目录。

## 接入已有业务

在已有业务完成文件系统挂载后执行一次：

```lua
local hzadb = require "hzadb"
hzadb.fs()
hzadb.mem()
assert(hzadb.start({deferred = true}))
```

原有业务可以继续运行，文件服务不要求进入资源维护模式。业务与电脑同时访问同一个文件时，由业务决定何时允许修改；可通过 `hzadb.fs({path_guard = function(path, write) ... end})` 限制特定目录，未安装守卫时不额外限制普通目录。

`log.set_usercmd_cb()` 是单一回调入口。启动 hzadb 后，不要再用另一个回调覆盖它；自定义数据可以注册独立子指令，与标准文件指令共用同一个通道：

```lua
hzadb.reg_op(0x40, function(body)
    return hzadb.E_OK, body -- 二进制回显；电脑端仍须使用 usercmd 帧格式。
end)
```

标准文件指令号保持不变，自定义号段为 `0x40..0x7F`。HELLO 开始新会话时会关闭上次连接遗留的文件句柄；关闭或落盘失败会报告错误。文件读片长最多4096字节，写片长通过握手协商，EC718上限为1024字节。

## 当前实现边界

本示例不加载 `resource_service`，不操作 TTS／字体版本目录。若业务仍运行外置资源部署服务，应在该服务的同一个 hzadb 实例内设计目录权限，不能在旁边再启动这个示例覆盖它的回调。

`hzadb` 的通用操作可以枚举、上传和下载已挂载文件系统中的普通文件；具体 Flash 的可靠性、容量和坏块处理仍由相应存储驱动负责。自动协议回归和固件构建不能代替实际板子的 USB／Flash 验证。
