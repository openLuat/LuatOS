# epd墨水屏演示系统

## 一、功能模块介绍

### 1.1 核心主程序模块

1. **main.lua** - 主程序入口，负责系统初始化和任务调度
2. **ui_main.lua** - 用户界面主控模块，管理页面切换和事件分发

### 1.2 显示页面模块

3. **home_page.lua** - 主页模块，提供应用入口和导航功能
4. **epd_page.lua** - epd核心库图形演示模块
5. **info_page.lua** - 动态信息演示模块（电池/温度/时间）
6. **time_page.lua** - 时间显示演示模块

### 1.3 驱动模块

7. **epd_drv.lua** - epd显示驱动模块，基于epd核心库
8. **key_drv.lua** - 按键驱动模块，管理BOOT键和PWR键

## 二、按键功能说明

### 2.1 按键消息

- **"KEY_EVENT"** - 按键事件消息，包含按键类型和状态
  - boot键事件：`boot_down`（按下）、`boot_up`（释放）
  - pwr键事件：`pwr_down`（按下）、`pwr_up`（释放）

### 2.2 按键功能定义

- **主页页面**：
  - BOOT键：切换选项（图形演示 ↔ 动态信息 ↔ 时间显示）
  - PWR键：确认进入选中的页面

- **epd演示页面**：
  - PWR键：返回主页

- **动态信息页面**：
  - PWR键：返回主页

- **时间显示页面**：
  - PWR键：返回主页

## 三、显示效果

- **主页**：标题 + 三个功能选项（图形演示/动态信息/时间显示），BOOT切换、PWR确认
- **epd演示页**：圆形、矩形、线条等图形 + hzfont矢量字体 + 二维码
- **动态信息页**：电池图标+电量、CPU温度、实时时间，局部刷新只更新信息区
- **时间显示页**：6种时间格式，可切换

### 4.2 接线方式

| Air8000核心板 | 墨水屏引脚 |

| SPI1_CS   | CS        |

## 六、演示操作步骤

### 6.1 硬件准备

1. 按照接线表连接2.13寸墨水屏
2. 通过TYPE-C USB口给开发板供电
3. 打开Luatools工具，选择对应固件和脚本烧录

### 6.2 上电演示

1. 上电后屏幕显示主页，三个功能选项
2. 按BOOT键切换选项，PWR键确认进入
3. 进入图形演示页查看epd核心库绘图能力
4. 进入动态信息页查看电池/温度/时间，每5秒自动局部刷新
5. 进入时间显示页查看6种时间格式
6. 任意子页面按PWR键返回主页

## 七、注意事项

1. 屏幕使用epd库**custom模式**驱动，需对照官方`EPD_2in13_V4.c`命令序列
2. 屏幕物理方向122x250竖屏，demo中通过`panel:setRotation(90)`旋转为250x122横屏
3. 墨水屏刷新速度较慢（全刷约1-2秒），页面切换需稍作等待
4. 动态信息页使用局部刷新（PARTIAL），只更新信息区，速度较快
5. hzfont矢量字体需固件内置ttf（14/114号固件），否则文字不显示但图形功能正常
6. 接线务必核对SPI1引脚复用（CLK/MOSI），避免与其他外设冲突
7. 本demo内所演示的图形显示接口均可在epd核心库内找到，更丰富和详细的使用说明可以点击进入[epd核心库](https://docs.openluat.com/osapi/core/epd/)
