# Air8101 + BL0939 双路免校准电能计量 Demo

> <font color="red"><b>声明：
> 
>严禁带电操作！ 进行任何连接或拆卸前，务必断开电源。

>高压危险！ 测试220V时，请确保所有接线可靠，并使用隔离变压器及漏电保护器。

>本介绍为技术支持页面，操作人员需具备电气安全知识，否则请勿尝试，操作风险由使用者自行承担</b></font>

## 项目简介
**Air8101**：通过 UART1（MAIN_UART）或 SPI0 读取上海贝岭 BL0939 双路电能计量芯片，持续循环读取 + 失联自动重连，内置实机校准系数。

## 文件结构
- `user/main.lua`：脚本入口
- `user/bl0939_app.lua`：业务逻辑（循环读取/换算/断线重连；`MODE` 变量切换 uart/spi）
- `lib/exs_bl0939.lua`：BL0939 驱动扩展库（SPI/UART 双模式，与已验证工程完全一致）

## 一、软件环境
1. LuaTools 中下载 Air8101 最新 core 固件 `LuatOS-SoC_Vxxxx_Air8101_1xx.soc`；
   - V2002 起固件按功能拆分编号：**101** 摄像头为主（USB/DVP 拍照录像 + TF 卡 + BLE/airlink）、**102** UI(exeasyui) 为主、**104** 含 airUI、**105** 畅玩板精简、**106** Air8101B/C 专用（16MB Flash）；本 demo 仅用基础库（sys/log/uart/spi），**任选编号均可**，默认按 101；
   - **Air8101/Air8101A 共用同一套固件**；Air8101B/C 使用 106 号；
3. IO 电平：由 **VDD_GPIO 电源域**决定——VBAT ≥3.5V 时固定 **3.3V**；VBAT 3.0~3.5V 时 2.8~3.3V；VBAT <3.0V 时高电平会降到 2.3V 左右，与 3.3V 设备对接需注意电平匹配。

## 二、硬件接线（UART 模式，接 220V 市电后使用 P2 光耦隔离口）

| 功能 | Air8101 | BL0939 板 |
|---|---|---|
| 光耦次级供电 | 3.3V | P2-1 (V) |
| 地 | GND | P2-4 (G) |
| UART1 发送 | **U1TX (PIN12 / GPIO0)** | P2-2 (RXD) |
| UART1 接收 | **U1RX (PIN11 / GPIO1)** | P2-3 (TXD) |
| A 路负载 | — | L 与 P1-1 (N1) 之间 |
| B 路负载 | — | L 与 P1-3 (N2) 之间 |

注意事项：
- UART 固定 **4800bps / 8 / N / 1.5**；BL0939 器件地址=0（SSOP20L，A4~A1 悬空）；
- Air8101 调试口为 **PIN26/27（DBG_UART0）**：固定 **2Mbps**（需支持 2Mbps 的 USB 转串口，如 CH340N），专用于**下载烧录和抓取日志**，不能当普通 UART 使用；下载时可将 CH340 的 RTS 接 CEN(PIN23) 实现自动复位；
- 冷态自测（不接市电）：外部 3.3V 供 P3-1/P3-2，日志应见温度读数、RAW 全 0 但 TPS1 非 0；
- 安全：接市电后 P2 为光耦隔离接口；切勿在 SPI/直连方式下与热侧共地操作。

## 三、SPI 模式（实验性，仅冷态测试）
`lib/exs_bl0939.lua` 内置完整 SPI 驱动（从机、半双工、无片选、Mode1、500kHz、8bit MSB first、6 字节帧 + 校验、软复位 0xFF*6），与 UART 共用全部业务逻辑。

切换方式：`user/bl0939_app.lua` 中 `MODE = "spi"`（默认 `"uart"`）。

| 功能 | Air8101（SPI0 默认组） | BL0939 板 |
|---|---|---|
| SCLK | **PIN28 (SPI0_CLK)** | U1-17 SCLK |
| MOSI | **PIN57 (SPI0_MOSI)** | U1-18 RX/SDI |
| MISO | **PIN55 (SPI0_MISO)** | U1-19 TX/SDO（外部 10K 上拉 3.3V）|
| 片选 | PIN54 (SPI0_CS) 占位 | 无 CS，不接 |
| 模式选择 | — | U1-16 SEL 拉高到 3.3V |
| 地址引脚 | — | U1-9/11 (A1/A3) 拉高 3.3V，U1-10/12 (A2/A4) 悬空 |

备选 SPI1（改 `SPI_ID=1`、`SPI_CS=66`）：SCLK=PIN65、CS=PIN66、MOSI=PIN67、MISO=PIN8。

[警告] SPI 信号与 BL0939 热侧直连、无光耦隔离，**只能在断开市电的冷态下测试**（外部 3.3V 供 P3-1/P3-2，GND 共地）。如需市电下 SPI 计量，必须另加 4 路光耦/磁隔离。

冷态验证预期：日志出现 `写保护解锁成功` + `初始化完成，模式：spi` + 温度≈28°C、RAW 全 0 但 TPS1≠0，即 SPI 通信正常。

## 四、校准系数（内置，基于 227V/698R 实机基准）
- `KU=16560`（电压）、`KI=275447`（电流）、`KPA=KPB=712.7`（有功）、`KW=6118`（电能）；
- 系数标定的是 BL0939 板（采样电阻/分压网络），与主机模组无关，UART/SPI 通用；
- 电能建议带载长测 ≥10 分钟对比电表精调 KW。

## 六、失联自动恢复
芯片掉电/接线接触不良时：连续 3 次读取异常 → 自动 `close()+setup()` 重连 → 数据自动恢复，无需人工干预（日志可见 `读取异常(1/3)…重新初始化 BL0939…重新连接成功`）。

## 七、故障排查
| 现象 | 处理 |
|---|---|
| 初始化失败 / 写保护解锁失败 | 检查 3.3V/GND；确认 SEL 悬空（UART 模式）；核对 UART1 引脚（PIN11/12）|
| 数据全 0 且 TPS1=0 | BL0939 板未供电（检查市电或 P3 外部供电）|
| 电压=0 但温度正常 | 冷态（未接市电）正常现象 |
| 持续超时刷屏 | 检查 P2 信号线/负载接触；失联重连会自动恢复 |
| SPI 模式读不到数据 | 确认 SEL/A1/A3 已拉高、SDO 已上拉、SPI0 默认组（PIN28/54/55/57）正确；SPI 仅限冷态测试 |

## 八、实测验证结论（2026-08-21，UART 模式，负载 698Ω 接 A 路）
Air8101（UART1=PIN11/12）已实机连接 BL0939 板验证通过，校准系数沿用 227V/698R 基准**零调整**：

| 项目 | 实测（4 组均值） | 理论基准（222.4V） | 偏差 |
|---|---|---|---|
| 电压 | 222.4V（V_RMS≈3,684,000） | 市电实测波动（EPM/EHV/8000 同期同值） | ✅ |
| A 路电流 | 0.318A（IA_RMS≈87,530） | 222.4/698=0.3186A | **-0.2%** |
| A 路有功 | 70.7W（PA≈50,370） | 222.4²/698=70.86W | **-0.3%** |
| 相角 | ≈0°（0.1~1.9°） | 纯阻性 | ✅ |
| 电能 | W1=1→2 → 0.0002→0.0003kWh | 2×0.0001635=0.00033kWh | ✅ |
| 温度 | 29.6°C | 正常 | ✅ |
| B 路 / 通信 | 全 0 / 全包校验零错误 | 未接 / 正常 | ✅ |

结论：**四平台（Air780EPM / Air8000 / Air780EHV / Air8101）UART 计量全部实测通过**，同一套校准系数通用、误差均 <±1%，无需分别校准。SPI 模式仍为实验性，待硬件飞线后冷态验证。
