# LuatOS-Air8201

## 介绍

本目录为合宙 Air8201 模组的代码中心。

Air8201 包含如下两款型号, 分别基于不同的模组:

* Air8201H 使用 Air780EHM 模组
* Air8201G 使用 Air780EGH 模组

## 目录说明

* demo  [演示代码](demo/)
* core  [底层固件](core/)
* 
如需查阅文档, 请访问合宙文档中心的[文档中心](https://docs.openluat.com/)
