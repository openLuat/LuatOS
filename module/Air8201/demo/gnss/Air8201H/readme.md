
## 演示功能概述

使用Air8201H，利用libgnss核心库如何实现定位功能

主要操作为：

打开GNSS，使用AGPS辅助定位

定位成功之后，获取经纬度信息

## 演示硬件环境

1、Air8201H板子一个

2、TYPE-C USB数据线一根

3、gnss天线一根


## 演示软件环境

1、Luatools下载调试工具

2、[Air8201H最新版本固件](https://docs.openluat.com/air780epm/luatos/firmware/version/)

1、搭建好硬件环境
