## Air8201 DA267 三轴加速度传感器 demo 说明

Air8201 包含两款型号, 分别基于不同的模组:

* Air8201H 基于 Air780EHM 模组
* Air8201G 基于 Air780EGH 模组

本 demo 基于 DA267 三轴加速度传感器（I2C 接口），演示以下功能：

1. DA267 传感器 I2C 初始化与通信（I2C1, 地址 0x26）
2. GPIO39 中断触发读取三轴加速度数据（X/Y/Z）
3. 计步器数据读取
4. 基于中断的运动/静止状态智能检测
5. 传感器异常自动复位重连

## 硬件连接

| DA267 功能 | Air8201H 引脚 | 说明 |
|-----------|:----------:|------|
| SDA       | I2C1 SDA   | I2C 数据线 |
| SCL       | I2C1 SCL   | I2C 时钟线 |
| INT1      | GPIO39     | 中断引脚 |
| VDD       | GPIO24     | 传感器供电控制 |

## 文件说明

| 文件 | 说明 |
|------|------|
| main.lua | 主入口，初始化传感器供电和加载模块 |
| da267.lua | DA267 传感器底层驱动（I2C 读写、中断回调） |
| manage.lua | 运动/静止状态检测管理模块 |

## 注意事项

1. DA267 芯片型号 ID 为 `0x13`（寄存器 0x01），程序会定时轮询确认传感器健康状态
2. **不能使用 exvib 扩展库**，exvib 专为 DA221（I2C 地址 0x27）设计，DA267 寄存器配置不同
3. 传感器量程配置为 ±2g，可根据实际需求修改 `da267.lua` 中寄存器 0x0F/0x10/0x11 的值
4. 中断阈值（寄存器 0x39/0x3A/0x3B）当前设置为 0x06，对应约 23.4mg 的加速度变化
5. manage.lua 中 `gtime=64` 秒的历史窗口可调整，影响静止检测的灵敏度
