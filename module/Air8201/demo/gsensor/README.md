## 功能模块介绍

1、main.lua：主程序入口；

2、da267_app.lua：全接口测试脚本，初始化传感器后进入每秒1次的持续读取循环，打印三轴加速度数据、步数和运动状态；

3、exs_da267.lua：DA267加速度传感器扩展库驱动文件（位于libs目录）；


## 演示功能概述

DA267是一款I2C接口的数字加速度传感器（Air8201主板板载），支持三轴加速度测量、计步和运动状态检测。

本demo分两阶段运行：
- **第一阶段**：传感器上电并初始化，启用运动检测和计步器功能
- **第二阶段**：进入持续读取循环，每秒读取一次三轴加速度数据、步数和运动状态


## 演示硬件环境

1、合宙 Air8201H / Air8201G-BLMQ / Air8201G-BQ / Air8201G-LM 板子一块

**DA267为Air8201主板板载，无需额外接线。**

DA267板载引脚：
- VCC：GPIO24 控制供电
- SDA：I2C1_SDA
- SCL：I2C1_SCL
- INT：GPIO39（中断引脚）
- I2C地址：0x26
