## Air8201 I2C demo 说明

Air8201 包含两款型号, 分别基于不同的模组:

* Air8201H 基于 Air780EHM 模组，引出了I2C, 可以挂载I2C设备测试.
* Air8201G 基于 Air780EGH 模组，引出了I2C, 可以挂载I2C设备测试.


## Air8201 I2C 功能参考

Air8201 的 I2C 接口可挂载多种外设，详细 demo 请查看：

1. **I2C 接口挂载 AirGPIO_1000**：[AirGPIO_1000](https://gitee.com/openLuat/LuatOS/tree/master/module/Air8201/demo/accessory_board/AirGPIO_1000)
   

2. **I2C 接口挂载 AirSHT30_1000**：[AirSHT30_1000](https://gitee.com/openLuat/LuatOS/tree/master/module/Air8201/demo/accessory_board/AirSHT30_1000)
   

3. **I2C 接口挂载 AirVOC_1000**：[AirVOC_1000](https://gitee.com/openLuat/LuatOS/tree/master/module/Air8201/demo/accessory_board/AirVOC_1000)
