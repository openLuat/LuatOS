## Air8201 I2C demo 说明

Air8201 包含两款型号, 分别基于不同的模组:

* Air8201H 基于 Air780EHM 模组，引出了I2C, 可以挂载I2C设备测试.
* Air8201G 基于 Air780EGH 模组，引出了I2C, 可以挂载I2C设备测试.

Air8201 的 I2C demo 可直接复用Air780EHM_Air780EHV_Air780EGH 系列的 demo。


## 完整代码与说明请参考
