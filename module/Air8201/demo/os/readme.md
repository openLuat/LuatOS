## Air8201 os demo 说明

Air8201 包含两款型号, 分别基于不同的模组:

* Air8201H 基于 Air780EHM 模组
* Air8201G 基于 Air780EGH 模组

由于这两款模组均属于 Air780EHM_Air780EHV_Air780EGH 系列, os 功能与用法完全一致, 因此 Air8201 的 os demo 可直接复用该系列的 demo。

## 完整代码与说明请参考

[Air780EHM_Air780EHV_Air780EGH/demo/os](https://gitee.com/openLuat/LuatOS/tree/master/module/Air780EHM_Air780EHV_Air780EGH/demo/os)
