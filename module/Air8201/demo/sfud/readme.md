## Air8201 sfud demo 说明

Air8201 包含两款型号, 分别基于不同的模组:

* Air8201H 基于 Air780EHM 模组，未引出SPI, 所以无法挂载sfud设备测试.
* Air8201G 基于 Air780EGH 模组，引出了SPI, 所以可以挂载sfud设备测试.


## Air8201G sfud 功能参考

Air8201G 使用 sfud 核心库挂载 nor flash 功能，详细 demo 请查看：
