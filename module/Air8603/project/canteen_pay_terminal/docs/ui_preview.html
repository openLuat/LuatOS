Air8603 W 系列 1024 x 600 LuatOS / AirUI
这是 ui/ui.lua 的 1:1 静态预览，可点击数字键与「确认」体验交互流程。 本文件仅用于电脑预览，不参与烧录；真实语音、扫码、左侧收款成功弹窗由设备端 Lua 代码执行（本预览不模拟弹窗）。

食堂收费终端
网络：已连接
本次金额
￥ 0.00
扫饭卡二维码
请将饭卡二维码对准摄像头（10~20cm）
识别后自动收款并播报结果
请输入金额，然后点确认
确认后播报金额 → 扫码 → 收款成功
1 · 输入金额并播报数字键盘输入，点「确认」后 exaudio 离线中文 TTS 播报「本次消费…」。
2 · 扫到任意码即收款本地判成功，左侧弹出「收款成功 + 输入金额」，播报「收款成功十二元五角」；按任意键关弹窗，语音不中断。
3 · 后端对接开关C.pay.enable 示例默认 false 不发 HTTP；填完 config.lua 占位符后改成 true 才走扣费与回传，只上报必要字段，不含图像与日志。

金额字号由 C.ui.amount_font_size 控制（当前 100），货币符号由 C.ui.currency 控制（默认全角「￥」，固件内置中文字库不含半角「¥」）。 工程目录：canteen_pay_terminal/code　|　烧录前需按上级目录 README §5.0 修改 code/config/config.lua 中的 WiFi 账号密码、后端地址与凭据占位符。要改的位置清单见上级目录 README.md §0.3，代码里全文搜「【必改」可逐条定位；详细接线与接口协议见上级目录 README.md。
