# 双路温度监控

两个 T100 温度探头接 PLC 的 AD0 / AD1，屏上实时显示两路温度、画一小时趋势曲线、
超温报警并播报，报警记录留最近 8 条。

## 画面

- 左右两张温度卡：仪表弧 + 大数字 + 预警值/报警值/实时值
- 右上：双通道趋势曲线（1 小时，每秒采样）
- 右下：报警记录 8 条
- 底部：采样状态、消音、复位、参数设置

参数页可改两路的预警值、报警值、回差、确认延时，掉电保存。

## 数据来源

| 通道 | 地址 | 说明 |
|---|---|---|
| CH1 | 6700（2 个寄存器） | CDAB 浮点，已是 ℃ |
| CH2 | 6702（2 个寄存器） | 同上 |

一次读 4 个寄存器把两路都取回来，500 ms 一次。

## 两个实现

| 目录 | UI 框架 | 状态 |
|---|---|---|
| `airui/` | AirUI（`airui.*` 接口，Lua 画控件） | 已完成，真机验证通过 |
| `plcui/` | PLCUI | 待做 |

同一套业务逻辑（取数、报警、播报），只换界面层。写 plcui 版时，把 `airui/code/` 里的
`drv_modbus.lua`、`app_data.lua`、`app_alarm.lua`、`app_sound.lua`、`app_store.lua`、`conf.lua`
原样带过去，只重写 `ui.lua` 和 `main.lua` 里跟界面有关的部分。

## 怎么改

| 想改什么 | 改哪里 |
|---|---|
| 温度上下限、采样周期 | `conf.lua` 的 `conf.trend`、`conf.sample_ms` |
| 报警门限默认值 | `conf.lua` 的 `conf.chs[n].warn/alarm` |
| 回差、确认延时 | `conf.lua` 的 `conf.alarm` |
| 音量、语音开关 | `conf.lua` 的 `conf.board.audio`、`conf.alarm.speech` |
| 画面布局 | `ui.lua` |
| 取数逻辑 | `app_data.lua` |
