# 桌面天气时钟（weather_clock）

Air8605（Air1602 主控）+ 10.1 寸 RGB 1024x600 的桌面摆件：顶部时间/日期/温度区间，
左下定位城市，右下房间温湿度，中间是一个一直在蹬车前进的骑行者（可切成小猫/小狗），
整片天空随时钟从天亮走到天黑再走回天亮，左滑是一屏七天天气预报。

## 提示词（需求原文）

> 在 `D:\Air\Git_Project\LuatOS\module\Air8605\project` 的一个新建目录，生成一个桌面天气和
> 时钟显示的 UI，画风参考图片，屏幕上方是今日时间和天气，左下角有当前定位城市，右下角显示
> 房间温度湿度，中间区域的主体可以是这样骑自行车一直前进的人，也可以切换成小猫小狗，如果
> 切换成了可爱的小动物，下雨或者天黑就会躲在小窝里，整体画面会随时间从天亮变到天黑再变到
> 天亮；屏幕左滑可以看到最近七天该城市的天气预报。

## 角色行为

- **骑行的人**：车轮按角速度转、腿跟着曲柄踩踏板，**草地、树、石子一起按
  「车轮周长 × 转速」后退（147 px/秒）**，看起来就是一直在往前骑，而不是原地踩。
  这个场景里**没有小窝** —— 人一直向前，画面里挂一栋始终不动的房子就自相矛盾了。
- **小猫 / 小狗**：在 `conf.actor.pet_min_x ~ pet_max_x` 之间慢慢晃，**整片地面静止**
  （草、树、远山、小窝都不动），只有小动物自己走来走去，小窝立在右边不会漂。
  **下雨、下雪、或天黑（18:30 之后 / 06:30 之前）** 会自己走回小窝；
  进窝后本体隐藏，只在亮着灯的窗户里露个小脑袋。天气转晴且天亮了再自己出来。
- 骑行的人不受天气影响，夜里也照骑（参考图就是 23:30 还在骑）。

| 形象 | 地面 | 小窝 |
| --- | --- | --- |
| 骑行的人 | 后退（147px/s，与车轮对齐） | 不出现 |
| 小猫 / 小狗 | 静止 | 出现，雨雪/夜里亮灯 |

## 日夜变化

`ui/scene.lua` 里一张 `SKY` 关键帧表（0 点 → 24 点，每帧给天空顶部/中部/地平线三个颜色），
按当前小时线性插值；`daylight` 因子同时控制地面亮度、星星透明度、云的亮度。
改配色只改这张表，绘制代码不用动。

想几分钟看完一整天：`conf.lua` 里

```lua
M.time.demo_day_seconds = 120   -- 24 小时压缩成 120 秒
```

真机部署改回 `0`（跟随 RTC）。

## 画面细节约定（改之前先看）

| 约束 | 为什么 |
| --- | --- |
| 云的顶端必须 ≥ 130px | 顶部 0..140 是时间/日期/温度的领地。白云压白字，日期直接消失。云顶 = `y - 34*s`，见 `scene.lua` 的 `clouds` 表 |
| 顶部渐晕必须是 24 档以上 | 档数少了每条之间有肉眼可见的 alpha 台阶，整片天空变成百叶窗；每档 5.8px、alpha 只差 2 才看不出接缝 |
| 半透明色块一律用 `P:box` / `P:dot` | 这两个接口会把边框 opacity 压成 0。手写 rect 忘了压，半透明填充外面会多一圈 100% 不透明的 1px 边 —— 层叠渐变会变成条纹，云和光晕会有硬描边 |
| 温度单位用 `℃` | GB2312 A1 区符号，hzfont 带得出来。若换成精简字库缺字形，显示成空白就改回 `C`（`hud.lua` 两处、`forecast.lua` 两处） |
| 预报页背景要重画一遍天空 | 页面是独立容器。不重画就与桌面两个底色；做成全透明又会让桌面的时间/城市文字从卡片缝里露出来，与预报文字叠在一起 |

## 天气数据

`net/weather.lua`，全部免 key：

1. 定位：ip-api → vore → ipinfo → ip.sb，任一成功即用；
2. 没有经纬度或城市名是英文 → open-meteo geocoding 补中文城市名；
3. 天气：open-meteo `forecast_days=8`，取「今天 + 未来 7 天」；
4. `sys.publish("WEATHER_UPDATED", data)` → HUD 温度区间、预报页、雨雪特效一起刷新。

断网也会立刻有一份 `conf.weather.fallback`（西安 / 晴 / 1~10℃），联网成功后整体替换；
最近一次结果写进 fskv，下次开机先显示缓存。

## 房间温湿度

Air8605 底板没有板载温湿度传感器，`conf.sensor.model = "none"` 时用
「室外温度 + 室内外温差 + 一段日周期」算一个稳定的演示值（右下角不会是 `--`）。
现场装了传感器：

```lua
-- conf.lua
M.sensor = { model = "aht20", i2c_id = 0, addr = 0x38 }
-- 或者任意读数函数
require("room_sensor").reader = function() return 24.6, 55.2 end
```

## 渲染与性能

- 全部图形用 `airui.shape` 图元画，**零图片素材**：不进图片解码缓存、换配色只改常量。
- 分两层提交：
  - `sky` 层（天空 30 条渐变 + 地面 + 远山 + 40 根草）只在配色变化时重画（约 5 分钟一次）；
  - `fx` 层（星星 26 + 云 3 朵 + 地面参照物 10 + 雨雪 32~40 + 小窝 + 角色）按 10fps 重建。
- 每帧动态层图元数：晴天约 50，夜间下雨约 150（自检脚本里有 260 的上限断言）。
- 主循环 `sys.timerLoopStart(tick, 100)`；滑动动画单独 20ms 一步，只改容器位置，不重画图元。
- 预报页展开时暂停场景刷新（整页盖住桌面，省一半 CPU）。

## 硬件配置

都在 `conf.lua`，与 `factory/config/eng_8605m_10i_v0.lua` 对齐：

| 项 | 值 |
| --- | --- |
| 屏 | RGB 1024x600，`pin_rst` = GPIO15（LCD_DISP） |
| 时序 | hbp 140 / hspw 20 / hfp 160 / vbp 20 / vspw 3 / vfp 12，50MHz |
| 触摸 | GT911，I2C1，RST GPIO72，INT GPIO51（轮询模式） |
| 背光 | PWM3 1kHz |
| 上电 | 12V/5V/9V/SD_EN → 4G 复位 → 485 供电（顺序见 `conf.power_on`） |

背光故意在首帧画完才点亮：RGB 帧缓冲跨热复位不清屏，提前开背光会把上一帧残留闪出来。
