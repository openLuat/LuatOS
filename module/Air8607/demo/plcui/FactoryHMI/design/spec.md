## 五、交互清单（第④环逐条搬成 Lua）

| 交互 | 触发 | 行为 | PLCUI 对应 |
|---|---|---|---|
| 页面切换 | 底部 4 个 tab | 切页 + tab 高亮 + 关键盘 | `xml:show` |
| 模式切换 | 点顶栏状态胶囊 | 自动 ⇄ 手动；手动才可点设备 | `set_text` + 状态图 |
| 设备操作 | 手动模式下点泵/阀 | 泵启停、调节阀 0/65%、灌装阀开关 | `set_checked` / `set_src` |
| 自动模式拦截 | 自动模式下点设备 | 提示「自动模式不可手动操作」 | `set_text`（提示条） |
| 整线启动 / 停止 | 底栏按钮 | 泵、阀、流动光点、输送线同步；按钮进选中态 | `set_hidden` / `set_checked` |
| 急停 | 底栏红色按钮 | 全线停机、顶栏转红、红色横幅、生成 A-000 报警 | `set_hidden` + `set_text` |
| 报警复位 | 报警页按钮 | 清空记录、解除急停，需重新启动 | `table` 清空 + `set_text` |
| 参数修改 | 点参数行「修改」或 KPI 数值 | 弹软键盘 → 范围校验 → 生效/取消 | `textarea` + `keyboard` |
| 配方应用 | 选配方 + 应用 | 灌装量 / 温度 / 速度写入参数 | `set_text` |
| 报警确认 | 报警页单条 / 全部 | 行变已确认，顶栏角标与 tab 徽标同步 | `table` 刷新 |
| 数据刷新 | 每 900ms | 温度/压力/流量/液位/产量/时长刷新，超温生成报警 | `chart` / `label` |

> 原型的 `:active`、`transition` 只用于本地观感；设备端按下态、流动光点、输送带纹理都用「两张预烘图交替 `set_hidden`」实现。
