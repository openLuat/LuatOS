# 降级清单（PLCUI 能力边界）

本工程没有外部的图 / 视频 / HTML 参考资料，需求是一句话文字描述，
因此按 `SKILL.md` 0.2 全默认补齐（1024×600、3 页、浅蓝工业、工业拟物）。

**前提：目标机刷的是 PLCUI 1.0.1**（仓库 `components/plcui` 是 1.0.2）。
1.0.1 只有 7 种控件、image 只认 `src` 系列与 `hidden`，
Lua 侧没有 `set_pos` / `set_size` / `set_crop` / `play`。
2026-11-17 因为用了 1.0.2 的 `fit` 属性，真机整份 `main.xml` 加载失败、**屏幕全黑**，
所以下面所有方案都按 1.0.1 的现实来。

| # | 原本想要 | 为什么做不到 | 实际落法 | 影响 |
|---|---|---|---|---|
| 1 | 面板渐变 + 内阴影 + 外发光 | 1.0.1 的 container 只有 `background` / `border-color` / `border-width` / `radius`，其余靠图片 | 面板渐变、内阴影、绿色标题条、地面阴影全部烘进每页 1024×600 背景 JPG | 面板不能运行时改色，改版面必须重烘背景 |
| 2 | 按钮 4 态（普通/按下/禁用/选中） | 图片只有 `src` / `src-pressed` / `src-checked` / `src-disabled` 四槽，禁用态与选中态本交互用不到 | 只烘普通 + 按下两种，凸起凹陷做在图里；急停后按钮**不做禁用**（变灰后看不出原因），一律可点，由 `vp_app` 拒绝并打日志 | 少两套图；急停期间点启动类按钮会被告知"急停未复位" |
| 3 | 步进滑块连续平滑运动 | 1.0.1 **没有 `set_pos`**（1.0.2 才加） | 11 个预置位置的 image（每档 11 mm）共用同一张 `im_car`，运行时切 `hidden` | 11 mm 一档的阶梯运动，不是丝滑补间 |
| 4 | 液位柱连续伸缩 + 液面波动 | 1.0.1 **没有 `set_size`、没有 `animimg`** | 11 张整块液位素材（0%、10%…100%），液面小波纹直接烘在图里，运行时按 10% 一档切 `src`；不做 5%（21 张）是因为 21 张解码 3.42 MiB，加背景会顶满 6 MiB 图片缓存 | 液位分级跳变；"流动感"来自液位变化本身，没有独立动画帧 |
| 5 | 温度与压力同图双曲线 | chart 只有一个 `y-min` / `y-max`，`set_range` 不带 series_id，没有双 Y 轴 | 趋势页已按需求取消；只剩膨胀参数页的「实测 / 拟合」两条同量程曲线（0~120 kPa） | 没有独立的趋势页，实时读数靠运行页工艺图上的压力 / 温度大数字 |
| 6 | 曲线阈值线与图例 | chart 没有阈值线、注释与图例 | 量程写在面板标题里，刻度靠 `hdiv` / `vdiv` + `grid-color`，不画阈值线 | 读数靠标题对照，没有虚线红线 |
| 7 | 急停告警闪烁 | 没有通用闪烁能力（`animimg` 是 1.0.2 才有） | 状态灯切 `im_lamp_alarm` + 同位的红色告警胶囊 `im_alarm`（文字烘在图里，`label` 改不了颜色） | 不闪，但 0.5 秒内能看出告警 |
| 8 | 数值文字随状态变色 | `label` 没有 `set_color`，颜色运行时改不了 | 两个同位 label 互斥（`tb_badge` 灰字 / `tb_alarm` 红字），用 `set_hidden` 切换 | 每多一种状态多一个组件，已计入 512 预算 |
| 9 | 表格里带操作按钮 | `<cell>` 只能放 `text`，不能嵌控件 | 表格只做记录展示，操作按钮全部放在表格外的固定操作带 | 不能行内操作 |
| 10 | 三段式标题栏 + 导航条 | XML 无 include / 继承，每页要复制一份 | 每页复制同一套顶栏与操作带，**同名元素各页用同一个 id**，Lua 里一次刷新逐页生效 | 改顶栏要逐页核对 |
| 11 | 原型 HTML 作为切图源（SKILL 环节①→② 的标准链路） | 本机没有 Playwright，无法从 HTML 稳定截图导出 | **流程降级**：`tools/ui_spec.py` 是唯一事实源，PIL 按 manifest 直接烘图，XML 与 HTML 都由它生成，三者坐标天然一致 | 少了「浏览器截图」一步，版面以 `design/preview_*.png`（排版预览，非验证）与真机为准 |

## 想恢复"连续运动 / 动画"的唯一办法

换 PLCUI **1.0.2** 固件（`fit`、`animimg`、`slider`、`set_pos`、`set_size` 都是 1.0.2 新增）。
换完之后：

1. 液位可以回到"一张图 + `set_size` 改高度"；
2. 滑块可以回到 `set_pos` 连续移动；
3. 液面可以换回 `animimg` 三帧循环。

改法是改 `tools/ui_spec.py` 的 `_plant()` 与 `code/ui_app.lua` 的 `refresh_plant()`，
同时把 `tools/check.py` 里 `FW_102_ATTRS` / `FW_102_TAGS` 与 Lua 方法名扫描放宽。
**在固件确认升级到 1.0.2 之前不要动这几处**，否则又是一次黑屏。

## 未使用的白名单组件

`textarea` / `keyboard` 本工程没有用到：
步进定量移动的步长用三颗固定步长按钮（5 / 10 / 25 mm）代替输入框，
加热恒温目标用「-0.5 / +0.5」两颗按钮在 25.0~60.0℃ 内调整，
比 `textarea` + `keyboard` 少一次弹键盘、少一处输入校验；
需要任意数值输入时再加表单，写法照 `plcui_water_supply` 的 `p_out` 页即可。

`slider` / `animimg` 在 1.0.1 里**根本不存在**（1.0.2 才有），不是"没用到"，是"不能用"。
