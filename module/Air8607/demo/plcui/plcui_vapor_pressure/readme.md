# 蒸气压测定仪 HMI（plcui）

三次膨胀法测定蒸气压的工控界面，使用 **PLCUI**（XML + 图片 + Lua）实现，
目标机型 **Air8607（Air1603）+ 10 寸 RGB 1024×600 + GT911 电容触摸**。

工艺：**进液 → 清洗密闭腔体 → 定量进液 1/4 → 加热恒温 37.5℃ →
三次膨胀（体积比 1 / 0.58 / 0.40，每点稳压后记录温压）→ 拟合求蒸气压**。
支持自动流程、逐环节手动、运行页上的设备操作（阀门 / 步进连续与定量 / 加热控温）、
随时急停与复位排液。

机械模型：**两个电磁阀都接在腔体底部，步进电机在腔体正上方、经活塞杆拖动软塞**。
腔体玻璃内壁本身就是 178mm 的量筒（1mm = 1px），软塞横向填满腔体内壁，
软塞下沿就是液面刻度线：阀1 开、电机上拉时腔底形成负压，储液罐里的液体
经阀1 从**腔体底部**被吸进腔体，液面跟着软塞一起上升；两阀全关后液体进不来
也出不去，液面就定格在关阀时的高度；密闭后软塞继续上拉，液面不动，
中间空出来的是气相，三次膨胀就是把这段气相体积逐次做大。
活塞杆按 11 个档位各烘一张长度，与软塞同档切换，所以杆永远从电机接到软塞、
不会从软塞下方露出来。

> 本工程只交付代码与静态自检：**没有跑 PC 模拟器、没有自动测试**。
> 上机验证请按本文末尾「人工测试步骤」手动执行。

## 视觉风格

浅蓝工业风，对齐同目录的 `plcui_water_supply`：天空蓝渐变底 + 白色圆角面板 +
绿色标题条 + 白色数值框 + 糖果色（绿/蓝/红/白）立体按钮 + 3D 拟物设备
（金属筒体、玻璃腔体、活塞杆、阀门、管路）。

做法：**每页一张 1024×600 背景 JPG**，把静态外观（面板、标题条、
说明文字、设备图形、地面阴影）全部烘进图里；运行时只叠动态件
（数值、单位、指示灯、步骤条、液位图、软塞、活塞杆、曲线、表格）。这样一页只有 30~50 个组件、
一次背景绘制即可成型，避免在真机上逐元素拼版面导致发灰、糊字。

## 固件版本约束（很重要）

目标机刷的是 **PLCUI 1.0.1**（`components/plcui` 仓库里是 1.0.2，两者接口不同）。
1.0.1 只有 7 种控件（image / label / textarea / keyboard / container / table / chart），
且 image 只认 `src` / `src-pressed` / `src-checked` / `src-disabled` / `hidden` / `clickable` / `on-click`。

因此本工程**禁止**使用下列 1.0.2 才有的东西，用了会让整份 `main.xml` 加载失败，
现场表现是**屏幕全黑、日志只有一行 `Unknown attribute: xxx`**（2026-11-17 实际踩过）：

- 属性：`fit`、`zoom`、`rotation`、`pivot-*`、`opacity`、`antialias`、`src-x`、`src-y`、`hit-*`
- 控件：`animimg`、`slider`
- Lua 接口：`widget:set_pos()`、`image:set_size()`、`set_crop()`、`set_zoom()`、`set_rotation()`、
  `set_pivot()`、`set_opacity()`、`play()`、`pause()`

1.0.1 可用的 Lua 接口只有：`set_src` / `set_text` / `set_cell` / `set_values` /
`set_hidden` / `set_disabled` / `set_checked` / `set_font_size` / `set_range` /
`set_column_width` / `set_series_hidden`，以及 xml 实例的 `load` / `show` / `find` / `prepare` / `close`。

`tools/check.py` 已把这条约束写成硬校验（`FW_102_ATTRS` / `FW_102_TAGS` + Lua 方法名扫描），
误用会直接自检失败，不用等上机黑屏。

| 体积比 | 右侧第三行 `pv_xv` 显示 `体积比 x.xxx`，由活塞位置换算，未膨胀时按 1.000 显示 | 1 个 label |

| 趋势曲线 | chart `set_values`（30 点） | — |

**液位、软塞、活塞杆共用同一套档位（每档 11mm）**，不是各自一套百分比：
软塞 pos=0 时下沿与液面零位都在腔底 y=344，每上一档软塞上移 11px、
液位素材加高 11px，所以阀开时"液面顶边 = 软塞下沿"逐档严丝合缝。
定量进液的 44.5mm 落在第 4 档（44mm），液面 44/178 = 24.7%，文字读数仍是精确的 25%。
腔体右侧「液面高度」读数直接取 `level`（0.1mm 精度），与 11 档素材的视觉误差无关。

液面最高只到 110mm = 腔高的 62%，所以 11 张素材不会画到画布顶；
换素材或改行程时同步改 `tools/ui_spec.py` 的 `CH_*` / `CAR_*` / `LIQ_*` / `ROD_*`。
继续细化就把 `LIQ_STEPS` / `CAR_STEPS` 调大再重烘（资源数同步增长）。
液位不宜做到 21 档：11 张解码约 1.85 MiB，21 张就是 3.7 MiB，
再加整页背景 2.34 MiB 会顶到 6 MiB 图片缓存，切级时反复换入换出。

## 清洗气是做什么的（环节 2）

`清洗气` 是接在腔体上部的一路干燥气体（图右上角「清洗气」接管）。环节 2 用它把腔体冲干净：
前 3.2 s 双阀关闭、脉动进气（压力在 6~24 kPa 波动）搅动残液与残气，
后 4.8 s 阀2 开、软塞下行，把残液和残气从腔底排液管吹扫出去。

它在测量原理上是**必要**的，理由三条：

1. 三次膨胀法只测「本次定量进液的样本 + 密闭瞬间的气相」。上一次残留的液体或蒸气
   会把实测蒸气压抬高、把 `P_air0` 压低，三点拟合的截距和斜率同时漂。
2. 腔体初始状态一致，「重复性」（拟合残差）这个数才有意义；不清腔就测，残差会假性变大。
3. 冲刷顺带清掉腔壁挂液，否则液面读数与真实液相容积对不上。

演示里它是**纯准备性环节**：不产生测定点，只影响压力波形与液面动画。
若嫌流程长，可以按需把 `STAGE_DUR[2]`（8 s）改短或并入环节 3 前段；
但不建议整段删除——删掉后步骤条只剩 5 段，工艺上却少了「每次测量前先清腔」这一步，
现场人员会以为腔体不用清洗。

## 工艺时序（演示时长，节拍 200ms）

| 环节 | 时长 | 动作 |
| --- | --- | --- |
| 1 进液 | 10 s | 阀1 开、阀2 关，软塞从腔底上拉到 110 mm，腔底负压把储液罐里的液体从阀1 吸进腔体，液面跟到 110 mm（腔高 62%） |
| 2 清洗密闭腔体 | 8 s | 前 3.2 s 双阀关闭、清洗气脉动冲刷（6~24 kPa 波动），液面定格 110 mm；后 4.8 s 阀2 开、软塞下行到腔底，液面跟着落回腔底并吹扫排空 |
| 3 定量进液 1/4 | 10 s | 阀2 关、阀1 开，软塞 0 → 44.5 mm，液体从腔底进入、液面 0 → 25%，结束时关阀1 |
| 4 加热恒温 | 16 s | 双阀关闭，液面定格 25%，升温到 37.5 ℃ 并保持；稳压后记录第 1 点（体积比 1.0） |
| 5 三次膨胀 | 21 s | 密闭后软塞上拉到 77.25 mm，稳压记录第 2 点（0.58）；再拉到 110 mm，稳压记录第 3 点（0.40）；液面始终停在 25% |
| 6 结果计算 | 3 s | 三点最小二乘拟合，出实测蒸气压与 37.8 ℃ 标准值；结束后**自动复位排液**（设备回位、液体排空，三点记录与拟合结果保留） |

自动流程按 1→6 顺序推进；任一处「停止」都会关闭双阀、停步进、停加热；
急停立即关阀、停电机、停加热，且**液体定格不动**，必须「复位」后才能再次启动。

## 算法（`vp_app.calc`）

腔体容积随活塞行程线性增大，关阀瞬间的液相体积固定为 1/4 腔体（`seal` = 关阀位）。
膨胀过程中液体不参与，只有**气相**在变大：

```
V_gas(pos) = 3/4 · pos/110            气相体积（pos=0 为 0，pos=110 为 3/4 腔体）
x          = V_gas(seal) / V_gas(pos) 体积比：44.5mm 关阀 → 1，77.25mm → 0.58，110mm → 0.40
液位%      = level / 178 · 100        只用于界面显示：阀开时 level 跟活塞，阀关后定格在 25%
P_i        = P_air0 · x_i + P_vap     空气分压随气相体积反比衰减，样本蒸气保持饱和蒸气压
```

体积比是**气相体积之比**（分子是密闭瞬间的气相、分母是当前气相），约简后就是
`seal / pos`——液相那 1/4 在比值里整个约掉了。它由**活塞位置**换算，与界面液面显示
完全解耦：液面只做视觉表现，即使液位素材按 11mm 分档、显示成 24.7%，拟合用的 x 仍是精确值。

对三点 (x_i, P_i) 做最小二乘直线拟合：

- 截距 `a` = 实测蒸气压 `P_vap`（写入界面的「拟合截距」）
- 斜率 `b` = 初始空气分压 `P_air0`（写入「拟合斜率」）
- 残差最大值 = 重复性
- 温度修正：`P_38 = a · (1 + 0.0135 · (37.8 − T_avg))`，即 1.35%/℃ 的经验系数，
  得到 37.8 ℃ 标准温度下的蒸气压（界面「标准温度值」）

仿真模型的真值取 `P_vap(37.8℃) = 46.5 kPa`，恒温 37.5 ℃ 时单点实测带 ±0.25 kPa 噪声，
所以正常情况下截距落在 46.3 附近、标准值 46.5、重复性 < 0.5 kPa。

## 急停与复位

| 操作 | 动作 |
| --- | --- |
| 急停 | 清运行标志、关双阀、停步进、**停加热**、液体与波纹定格；保持 `estop` 直到复位 |
| 停止 | 运行页不再设「停止」键；需要停自动流程时到「膨胀参数」页按「停止测试」，效果同关双阀、停步进、停加热，数据保留（急停状态下也可点，但不会清 `estop`） |
| 复位 | 清 `estop` → 关加热 → **阀1 关、阀2 开** → 步进下行排液，排空后自动关阀2、停电机；手动按复位还会清空三点记录与拟合结果 |
| 自动复位 | 环节 6 拟合成功后引擎自己调一次 `vp_app.reset(true)`：同样排液回位，但**三点记录与拟合结果保留**，跑完仍可在「膨胀参数」页看曲线与四个结果数 |

急停期间启动类按钮**不做禁用**（`set_disabled` 变灰后看不出原因），一直可点，
由 `vp_app` 内部拒绝并在日志里给出原因（`急停未复位，拒绝自动启动`）。
复位按钮在三个页面的操作带上都有，任何状态都可点。

## 部署（Air8607 真机）

1. 固件需开启 `LUAT_USE_PLCUI`、`LUAT_USE_PLCUI_LUATOS`、`LUAT_USE_HZFONT`
   （102 / 103 号固件；104 号已移除 PLCUI），且**固件里的 PLCUI 必须是 1.0.1**
   —— 换固件时用日志里那行 `I/user.boot plcui 就绪 1.0.x` 确认。
   仓库是 1.0.2、机器是 1.0.1 时，1.0.2 的 XML 属性会让整份界面加载失败（黑屏），
   详见上面「固件版本约束」。
2. 把 `code/` 内全部文件**平铺**烧到 `/luadb`：

   ```
   /luadb/main.lua  boot_app.lua  ui_app.lua  ui_vars.lua  vp_app.lua
   /luadb/tp_app.lua  exd_air8607_rgb.lua
   /luadb/main.xml  *.png  *.jpg
   ```

   luadb 不支持子目录，`code/` 本身就是平铺结构，整目录烧即可。
3. 触摸走 `tp_app.lua`（i2c1 + GT911），显示走 `exd_air8607_rgb.lua`
   （display 后端失败自动降级 lcd 后端）。

## 人工测试步骤（上机后手动执行）

1. **上电**：应直接进入「运行总览」，顶栏状态灯灭、徽标「待机」，
   图左侧读数卡片压力 0.0 kPa（30 号蓝）、温度约 25 ℃（26 号橙），
   图右侧三项分别是液面高度 0.0 mm、软塞高度 0.0 mm、体积比 1.000，实时状态六项有值。
2. **自动流程**：按「自动运行」→ 步骤条 1 变蓝、阀1 指示灯转绿、软塞（连带活塞杆）与液面
   同步逐档上移（每档 11 mm，液面顶边始终贴着软塞下沿），约 7.3 s 到 62%；
   进环节 2 后前 3.2 s 双阀全关、压力在 6~24 kPa 波动、液面定格 62%，
   随后阀2 亮、软塞逐档下行、液面跟着落回腔底；
   环节 3 液面再涨到 25%（软塞第 4 档 44 mm）并关阀1；环节 4 温度升到 37.5 ℃ 并保持；
   环节 5 软塞继续上移，**液面停在 25% 不动**（密闭后气相体积变大）：
  右侧「液面高度」保持 44.5 mm 不动，「软塞高度」一路升到 110 mm、体积比从 1.000 降到 0.40；
   全程杆始终从电机接到软塞顶，不会从软塞下方露出来；
   环节 6 后「蒸气压」实时状态出现数值（约 46.3 kPa），步骤条全部转绿；
  随后**自动复位排液**：阀2 亮、软塞与液面同步下行到 0、右侧读数回到 0.0 mm，
  排空后阀2 自动关闭，徽标从「复位排液中」变回「测定完成」，蒸气压数值与三点记录都还在
  （膨胀参数页可复查，不用重新测）。
3. **暂停**：流程中按「暂停」→ 徽标变「已暂停」，计时、步进与液位停止推进；再按一次继续。
4. **设备操作（运行页右列）**：
   电磁阀「阀1开 / 阀1关 / 阀2开 / 阀2关」→ 工艺图上对应阀门灯变色、右侧状态文字同步；
   「上行 / 下行」让软塞连续移动、「步进停」立即停；选 5/10/25 mm 后按「上移 / 下移」，
   软塞按步长定量移动，标题条右侧「步长 10」与实时状态的「步进 x mm」同步；
   **液面只在有阀打开时跟着软塞走**，两阀全关后点动步进，软塞动而液面不动。
5. **加热**：按「加热开」→ 实时状态显示「加热 开 37.5℃」，温度向设定值爬升；
   按「-0.5 / +0.5」→ 标题条左侧「设定 37.5℃」实时变化（限幅 25.0~60.0），
   加热中温度会跟着新的设定值走；按「加热关」→ 温度自然回落。
6. **环节手动**：进「环节手动」，按任意卡片「启动」→ 该环节独立运行、卡片灯转蓝；
   按同卡片「停止」→ 立即停；不同卡片的「停止」不应影响正在运行的环节。
7. **急停**：按任意页的红色「急停」→ 顶栏状态灯转红、徽标位置换成红色告警胶囊、
   双阀全关、步进停、加热停、液位与软塞定格不动；
   此时按「自动运行」应被拒绝（日志 `急停未复位，拒绝自动启动`），设备操作同样被拒。
8. **复位排液**：按任意页的「复位」→ 告警胶囊消失、状态灯转灭、加热停、
   阀1 关、阀2 开、步进下行、液位降到 0；排空后阀2 自动关闭，
   日志 `复位排液完成`，状态文字变「复位完成，已排空」。
   手动复位同时清空三点记录与拟合结果（膨胀参数页回到 `---`），回到可再次测量的待机态；
   自动复位（环节 6 结束）只排液不清数据，两者区别要能看出来。
9. **膨胀参数页**：按「开始测试」跑完整流程，观察表格三行记录逐条出现、
   拟合曲线两条线靠近；跑完看「拟合截距 / 拟合斜率 / 标准温度值 / 重复性」四个数
   （截距约 46.3、斜率约 52、标准值约 46.5、重复性 < 0.5）。
   按「重新计算」在已有数据上重算；无数据时应给出「测定数据不足 3 组」而不是崩。
   该页的「停止测试」是唯一的软件停止入口（运行页已按需求去掉「停止」键）。
10. **切页**：三个页面反复来回切，顶栏时间与状态不许停更（切页三件套是否生效），
    回到运行页时阀门灯、液位、软塞与活塞杆立刻是当前状态。
11. **长时间**：连续跑 30 分钟以上，观察触摸是否卡顿、画面是否冻结
    （每 500ms 只切一两次 `src` / `hidden`，不做几何变更）。

## 已知未验项（本机未验，必须真机确认）

- 触摸响应、手感、真实刷新率与长时间稳定性（未跑真机）。

  （三者同源，每档 11 mm，切档时三件同帧生效）；
  若觉得太跳，把 `tools/ui_spec.py` 的 `LIQ_STEPS`（10）/ `CAR_STEPS`（10）调大再重烘，
  资源数与组件数会同比增加（上限 256 资源、512 组件），液位别超过 12 张以免顶满图片缓存。
- 工艺模型是仿真值（阀门 / 步进 / 加热 / 温压传感器未接真实执行机构）；
  接真机时替换 `vp_app.set_valve` / `vp_app.set_stepper` / `vp_app.set_heater`
  与温度压力取数即可，界面与工艺时序不用改。
