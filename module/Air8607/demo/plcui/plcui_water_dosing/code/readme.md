# 水处理加药间 PLC 控制屏 · PLCUI 工程

## 一、功能

Air8607 / 1024×600 PLCUI 单页工控 HMI，模拟污水处理加药间的监控与操作。系统共 6 态，右上角状态切换器可逐态切换演示：

| 态 | 横幅 | 工艺流程 | 设备徽章 | PID | 操作按钮 | 附加 |
|---|---|---|---|---|---|---|
| 停机 | 灰 | 全灰无流动 | 停止 | PV -- / MV 0 | 全禁用 | — |
| 就地手动 | 黄 | 黄色无流动 | 就地 | PV 4.6 静态 | 全禁用 | 现场控制中 · HMI 只读 |
| 远程手动 | 黄 | 黄色无流动 | 远程/停止随单操 | PV 4.5 静态 | 泵1/泵2/搅拌机/手自动 解锁 | 单操可点，事件追加 |
| 自动运行 | 绿 | 绿色 + 流动虚线 | 自动 | PV/MV 1Hz 波动，输出条动 | 仅手/自动可用 | 液位缓降 |
| 故障 | 红 | 红色无流动 | 故障 + 低液位 | PV -- / MV 0 | 仅故障复位 | 联锁跳车 · 请复位 |
| 维护检修 | 橙 | 橙色 + 挂牌罩 | 锁定 | PV -- / MV 0 | 全禁用 | 禁止一切操作 |

场景：PAC/PAM 计量泵 2 台 + 搅拌机 + 药剂液位罐 + 出水流量计，PID 目标出水浊度 ≤ 5 NTU（页面文案为避开 hzfont 未验证字形写作「目标 5 NTU」）。

## 二、操作步骤

1. 上电后进入「停机」态，全部只读。
2. 点右上角「就地」：模拟现场控制，HMI 只读。
3. 点「远程」：操作区解锁，可点泵1启停 / 泵2启停 / 搅拌机，每次单操追加事件记录。
4. 点「手/自动」（或顶栏「自动」）：**两级按确认**——第 1 次按下进入待确认（横幅提示），5 秒内第 2 次按下才进入自动运行；超时自动解除。自动态下 PV/MV 每秒波动、输出条随之变化、液位缓降、管路虚线 200ms 逐帧流动。
5. 点「故障」：设备变红 + 红色横幅，仅「故障复位」可用；复位回到停机。
6. 点「维护」：橙色罩 + 挂牌，全部锁定。

> 手自动确认弹窗在 PLCUI 上降级为「两级按」，原因见 `design/fallback.md`。

## 三、文件结构

```

├── design/        index.html 单文件可交互原型 + spec.md + fallback.md（事实源）

│   ├── boot_app.lua        启动编排：上电时序、显示/触摸、定时器
│   ├── data_app.lua        业务：6 态状态机、PID 模拟、液位、事件、两级确认
│   ├── ui_app.lua          界面：加载、刷数、事件表、流动帧
│   ├── ui_vars.lua         组件 <- 变量 绑定表
│   ├── exd_air8607_rgb.lua 板级：10 寸 RGB 屏驱动（从基准 demo 复制）
│   ├── tp_app.lua          板级：GT911 触摸 + PLCUI 绑定（从基准 demo 复制）
│   └── res/                main.xml + 47 张 PNG（平铺，无子目录）
└── dist/luadb/             烧录目录：把 code/*.lua 与 code/res/* 复制到同一层
```

## 四、接线 / 烧录

- 屏：Air8607 10 寸 RGB 1024×600，RGB 直驱 + GT911 触摸挂 I2C1（GT911 地址与中断脚见 `tp_app.lua`）。
- 背光：PWM3（占空比 82%），LCD 供电 GPIO17，DISP 复位 GPIO15。
- 烧录：Luatools 选 `dist/luadb/` 目录，或把 `code/` 下全部 `.lua` 和 `res/` 下全部文件铺平到同一层。
- PC 模拟器：把 `code/*.lua` 与 `code/res/*` 复制到同一输出目录，运行 `luatos-lua.exe <输出目录>`（目录路径末尾不带斜杠）。
- 固件：Air1603 平台的 102 / 103 号固件（含 PLCUI）；104 号已移除 PLCUI，不可用。

## 五、自检

```powershell
python tools/check.py
```

输出写入 `build_check.txt`。自检覆盖：Lua 语法、代码规范、XML 骨架与 schema 取值域、字形覆盖、绑定表一致性、交付文档齐备。

## 六、已知未验项（沙箱无法验证，需真机确认）

- HZFont 位图字体在真屏上的实际字宽与可读性（尤其 18 号按钮文字是否换行）。
- 触摸响应与 84×48 按钮手感、4 帧流动是否顺滑。
- 真机刷新率、输出条 `set_size` 与液位换图是否有肉眼卡顿。
- 图片缓存（同屏 6 张流程底图共用 1 个 image 的 `set_src`）在真机上的解码峰值。
- 接入真实 PLC 数据后的联锁逻辑与长时间运行稳定性。

当前数据全部为 mock，接口形态见 `design/spec.md` 第七节；接真数据时 UI 包（`ui_app.lua` / `ui_vars.lua` / `main.xml`）无需改动，只替换 `data_app.lua` 的数据来源。
