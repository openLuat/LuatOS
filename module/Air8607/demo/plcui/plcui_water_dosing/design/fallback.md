# 降级清单 · 水处理加药间 PLC 控制屏

> 参考稿：`design/index.html`（单文件可交互原型，1024×600）
> 目标：Air8607 / 1024×600 / PLCUI（九种组件白名单）
> 原则：**做得到的照原型实现，做不到的显式降级 + 记在这里**，不静默照抄然后在设备上翻车。
> 判据只有一条：**这个东西在设备上会不会随数据变。** 不变的烘成 PNG；会变的必须是活组件。

## 一、无损降级（视觉一致，只是实现路径换了）

| 原参考效果 | PLCUI 为什么做不到 | 改成了什么 | 影响 |
|---|---|---|---|
| 面板白底 + 圆角 + 2px 边框（`border-radius` / `border`） | 容器 `container` 支持 `background`/`border-color`/`border-width`/`radius`，但纯色底色**不必烘图** | 直接用 `container` 填 `#FFFFFF` + 边框，零图片零缓存 | 无，视觉一致且更省 |
| 整页浅灰底 `--bg:#EEF1F5` | page 的 `background` 是颜色不是资源 ID | `<page background="#EEF1F5">` | 无 |
| 状态徽标 / 横幅底色随 6 态变色（CSS 变量） | 运行时改不了 `container.background` 颜色（2.11） | 6 张状态底板 PNG，`set_src` 切换；或底板固定 + 6 个彩色 label `set_hidden` 互斥 | 无，颜色本来就是离散 6 态 |
| 按钮圆角、按下位移 `translateY(1px)` | 无 `transform` 属性 | 四态图里画出凸起/凹陷，位移感烘进图 | 位置不动，靠光影表达，观感一致 |
| 操作按钮禁用态 `disabled`（灰底灰字） | 按钮是 image，没有原生 disabled 配色 | `src-disabled` 指向灰态图 + `set_disabled(true)` | 无 |
| 设备徽章 6 色圆角胶囊 | 无单元素圆角配色切换 | 6 张 `bd_*.png` 状态图 `set_src`，或 6 个 label 互斥 | 无 |
| 数值大字号 40 / 28 / 18 / 16 阶梯 | HZFont 位图字体，浏览器字 ≠ 设备字 | 全部写 `font="hzfont" font_size="..."` 成对，≥16 | 中文字宽以设备为准，框按字数预留 |
| `·` 间隔号、`■`、`▲`、`%`、`℃` | 实测有字形（见 SKILL 2.5 快照） | 直接用 | 无（`≤` 已改写成「目标 5 NTU」避开未验证符号） |

## 二、有损降级（视觉或交互与原型不同）

| 原参考效果 | PLCUI 为什么做不到 | 改成了什么 | 影响 |
|---|---|---|---|
| **手自动切换二次确认弹窗**（`.modal` 模态遮罩 + 确认/取消按钮） | 九种组件没有模态 / 弹层，`container` 不能改变层叠顺序，也无法拦截下层点击 | **两级按**：第一次按「手/自动」进入待确认（按钮切 `src-checked`、横幅文字变「再按一次确认切换」），5 秒内再按一次才执行；超时自动解除 | 交互语义一致（防误触），但没有遮罩和文字弹窗。现场培训要说清「按两下」 |
| **工艺流程 SVG 随状态变色** | 没有 SVG 组件，只有 `image` 吃位图；运行时改不了图片内部颜色 |每个状态各出一张 PNG（`flow_stop`..`flow_maint`），`set_src` 切换 | 颜色是离散 6 态切换， prototyping 里也是离散切换，观感一致 |
| **自动态流动虚线动画**（CSS `@keyframes dashmove`） | 无 CSS 动画；`animimg` 只做整图多帧循环，不能只动虚线局部 | 4 张透明流动帧 PNG（`flow_a0..a3`），200ms/帧 `animimg` 循环；停机/手动/故障态定格或停播 | 虚线是「跳帧」前进，8px 步进下肉眼接近连续；不能变速/暂停定位 |
| **MV 数值缓慢波动 + 输出条动画**（JS `setInterval` + CSS `transition`） | 无过渡动画（补间）；数值波动是数据更新不是几何更新 | `set_text` 以 ~1Hz 刷 PV/MV；输出条用 `set_crop` 或 `set_size` 改可见宽度，每帧只改一个控件 | 数值是 1Hz 跳变而非平滑补间，读数无影响；输出条按 2.10 几何更新节流 ≥200ms |
| **液位随数据缓慢下降**（罐内液面高度连续变化） | `set_pos`/`set_size` 是整页代价，连续改会卡（2.10） | 液位离散成 5 档（100/80/60/40/20%），每档一张图 `set_src` 切换，间隔 ≥1s | 液位是 5 档跳变不是连续液面，读数带 `lv` 文本补偿，工控上完全可接受 |
| **CSS `transition: width 0.7s` 平滑条** | 无过渡 | 直接 `set_size` 到目标宽度，靠 1Hz 更新频率显得在动 | 无平滑补间，读数不受影响 |
| **状态切换器 6 键选中高亮**（`.sw.on` 反色） | `image` 有 `src-checked`，但选中态图要预烘 | 每键普通 + 选中两张图（或复用 `btn_state` 四态 + `set_checked`） | 无 |
| **事件记录追加一行**（DOM `unshift` + 重绘 3 行） | `table` 无滚动、无动态插行；`set_cell` 只写文本 | 固定 3 行 table，新事件从底部行上移覆盖（写 `log_r2`→`r1`→`r0`，或循环 3 行 buffer） | 只在屏上保留最近 3 条，历史不在本屏，符合原型 |
| **橙色半透明罩**（`rgba(238,122,23,0.20)`） | `container.bg-opacity` 是静态属性，运行时改不了显隐以外的样式 | 维护罩做成一张整块半透明 PNG 组件，`set_hidden(false)` 显示；罩内容「挂牌」烘进图 | 罩层是静态图，颜色/透明度在 XML 里定死，维护态显示、其它态隐藏 |

## 三、按能力边界必须改写的结构

| 参考稿写法 | 改成 | 原因 |
|---|---|---|
| 面板 `.panel` 绝对定位 + `border-radius` | 直接 `<container background="#FFFFFF" border-color border-width radius>` | 纯色面板用容器，零图片零缓存（2.7） |
| 内联 SVG `<svg>` 画流程 | 离线栅格化成 6 张状态 PNG + 4 张流动帧，运行时 `image:set_src` / `animimg` | 九种组件无 SVG；SVG 只是中间产物 |
| JS 改 `style.width` 做输出条 | `image:set_crop` 裁出可见段（或 `set_size` 改宽），离散档位更新 | 几何更新整页代价，必须节流 |
| JS 改 SVG `rect.y/height` 做液位 | 液位 5 档状态图 `set_src` + 文本 `lv%` | 同上，离散状态图比每帧挪坐标便宜一个数量级 |
| CSS class 切换 6 态颜色 | 6 态各自的状态底板图 + label 文本 `set_text` | 颜色是样式，运行时改不了，只能换图 / 切 label 显隐（2.11） |
| `.modal` 弹窗 + `.dlg-f button` | 两级按确认：按钮 `src-checked` + 横幅文字提示 + 5 秒超时 | 无模态组件（见二） |
| `<button disabled>` | `image` + `set_disabled(bool)` + `src-disabled` 灰图 | 严格 boolean，只传 `true`/`false` |

## 四、没有降级的部分（原型与设备一模一样）

- 1024×600 布局、4px 栅格、全部坐标按 HTML 显示值 1:1 搬进 XML
- 一主色（`/main` 蓝）+ 五状态色（绿/黄/灰/红/橙）原值搬运
- 6 态切换器 6 个按钮的位置、文案、状态机语义
- 页身份三件套：页名 28 号在 top 14（< 1/6 高）、状态徽标紧邻、固定位置
- 数据分区：左侧设备块 / 主区流程与 PID 块 / 底部事件与操作带，块间留白一致
- 字号阶梯 16/18/24/28/40，全部 ≥16，`font` + `font_size` 成对写
- 每个数值带单位且同行紧邻（NTU / % / m3/h），PV 作全页唯一最大数值（40 号）
- 操作区固定底部带，按钮 84×48 ≥48×48、间距 8px，危险操作「故障复位」用告警色并与主操作错开一格
- 告警态三件齐上：故障态 = 红色横幅 + `▲` 图标 + 「联锁跳车·请复位」文字，不只靠颜色
- 所有文字在 511 字节内，且未用 `—▣⚠▶✓` 等无字形符号
- `plcui.load(路径, {handlers=...})` 签名、`xml:find(页ID, 组件ID)` 两参数、切页三件套在环节④照做

## 五、已知未验项（沙箱内验不了，真机再确认）

- HZFont 位图字体在看板上的实际字宽与可读性（尤其 18 号按钮文字是否换行）
- 触摸响应与 84×48 按钮的手感、`animimg` 4 帧流动是否顺滑
- 真机刷新率、输出条/液位档位切换是否有肉眼可见卡顿
- 图片缓存（当前页 6 张流程底图共用 1 个 image，`set_src` 切换）在真机上的解码峰值
- 长时间运行的稳定性与故障复位联锁逻辑（接真 PLC 数据时）

> 这些项不计入沙箱自检清单的通过项；上真机后再逐条打勾。
