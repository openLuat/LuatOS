# PLCUI 设计说明 · 水处理加药间 PLC 控制屏

> 事实来源：`design/index.html`（单文件可交互原型，1024×600）。本文件逐条登记素材 / 组件 / 绑定变量，供环节②导出、环节③写 main.xml、环节④接 main.lua 对照。**坐标一律取 HTML 显示值（G2），不取 SVG 的 viewBox；改布局回 HTML 改，再重跑导出，不许手改 XML。**

## 一、基础信息

| 项 | 值 |
|---|---|
| 目标平台 | Air8607（Air1603 平台），102 / 103 号固件（含 PLCUI）；104 号已移除 |
| 画布 | 1024×600，1:1 设计，不做响应式，绝对定位整数像素 |
| 页面数 | 1（`id="main"`，`background="#EEF1F5"`） |
| 风格 | 人机浅灰（工控经典），一主色 + 五状态色，统一栅格 4px |
| 状态数 | 6：停机 / 就地手动 / 远程手动 / 自动运行 / 故障 / 维护检修，整屏切换 |
| 组件预算 | 约 96 / 512（单页，留足余量） |
| 资源预算 | 约 20 / 256（按钮四态 + 6 个状态底图 + 灯/徽章，扁平命名 ≤23 字节） |
| 字号阶梯 | 16（标签/次要）、18（小标题/按钮）、24（状态徽标）、28（页名/SP·MV）、40（PV 主值），全部 ≥16 |
| 输入来源 | 一句话需求 + 明确风格关键词（工控浅灰），按 0.2 全默认补齐，无外部参考图 |

## 七、绑定变量总表（`ui_vars.lua` / `data_app` 接口形态）

| 变量 | 来源 | 类型 | 刷新 | 用途 |
|---|---|---|---|---|
| `state` | 本机状态机 | 枚举字符串 | 切换时 | 决定整屏 6 态表达 |
| `state_name` / `state_ico` | 由 `state` 派生 | 文本 | 切换时 | 徽标 + 横幅 |
| `banner_text` / `banner_hint` | 由 `state` 派生 | 文本 | 切换时 | 横幅 |
| `pv` | mock（接真数据时来自出水浊度仪） | 数值 1 位小数 | 自动态 ~1Hz | PV 大数 |
| `sp` | mock | 数值 1 位小数 | 固定 5.0 | SP |
| `mv` | mock（PID 输出） | 整数 0~100 | 自动态 ~1Hz | MV + 输出条 |
| `level` | mock（液位变送器） | 整数 % | 自动态缓慢下降 | 液位罐 + 液位显示 |
| `p1_out` / `p2_out` / `p1_badge` / `p2_badge` / `mx_badge` / `lv_badge` | 由 `state` + 单操派生 | 文本 / 状态图 | 切换/单操时 | 设备列表 |
| `log0` / `log1` / `log2` | 事件队列 | 文本 | 每次事件追加 | 事件记录 3 行 |
| `op_hint` | 由 `state` 派生 | 文本 | 切换时 | 操作区提示 |

> 刷值时按单个标量传：`w:set_text(v[b.var])`，不得把整张变量表塞给 `set_text`。
