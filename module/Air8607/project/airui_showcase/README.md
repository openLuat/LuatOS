# AirUI 视觉特效演示 · Air8607

> Air8607 + 10 寸 RGB 屏（1024x600 免序列）+ GT911 触摸
> **零图片素材**：7 个特效场景全部由 `airui.shape` 的 `line / circle / rect` 图元
> 每帧实时计算生成；顶栏 HUD 实时显示帧率与图元数，底部切换栏可点击切换场景或自动轮播。

## 启动流程

1. `power_on()` —— 供电 / 背光 PWM3 上电占空比 0 / I2C 引脚配置
2. `exd.setup()` —— 显示初始化（复位 + RGB 时序 + 帧缓冲）
3. `airui` 初始化 —— init + 字体加载 + 旋转
4. `ui_main.build()` —— 搭建演示界面（顶栏 HUD + 特效舞台 + 场景切换栏）
5. `touch_init()` —— GT911 触摸初始化 + airui 绑定（可点击切换场景）
6. `ui_main.run()` —— 启动逐帧动画任务（约 30fps），随后 `backlight_on()` 点亮背光

## 特效场景清单

| # | 场景 | 看点 |
|---|---|---|
| 1 | 星系粒子 | 40 颗粒子差速环绕核心（内快外慢形成旋臂拖曳感），近邻自动连线成星座网格，轨道压扁 0.44 倍形成盘面透视 |
| 2 | 频谱律动 | 28 段虚拟频谱：三正弦叠加 + 2Hz 节拍脉冲 + 高频颤动，HSL 流动渐变（低频青 → 高频品红）+ 半透明倒影 + 峰值保持帽 |
| 3 | 雷达扫描 | PPI 雷达 4 圈距离环 + 36 格方位刻度，14 条余晖线堆出扫描扇形，扫过 7 个漂移目标触发回波涟漪 |
| 4 | 环形仪表 | 三层同心环形进度 + 外圈刻度盘，用圆点串逼近粗弧线，中心大号实时读数 + 左下角三环图例 |
| 5 | 3D 晶体 | 立方体 + 对偶八面体线框自转，透视投影近大远小 + 深度着色，下方透视地面网格提供空间参照 |
| 6 | 时空隧道 | 12 层圆角方框按 (进度)² 透视曲线由远及近放大，12 条旋转辐条 + 60 颗向外飞散的流星 |
| 7 | 3D 星球 | 44 点斐波那契点云球体自转（深度调亮度/大小），赤道环 + 倾斜 55° 卫星轨道 |

## 硬件引脚

与 `module/Air8607/project/factory/config/eng_8607_10i_v0.lua` 对齐：

| 功能 | 引脚 |
|---|---|
| LCD 复位 | pin_rst = 15 |
| LCD 供电 | pin_pwr = 17（低有效） |
| 背光 | PWM3 (GPIO13) |
| 触摸 I2C1 (400kHz) | pin_rst = 14，pin_int = 51 |
