# 家庭能源监测面板（home_energy）

一块挂在客厅或配电箱旁的常亮能源看板。用 Air8607 + 10 寸 1024x600 RGB 屏，
把家庭里的**光伏、电网、储能、分路负载**四股能量的走向、大小、钱和碳，
在一屏里讲清楚。

- 平台：Air8607 / 10 寸 RGB 1024x600 / GT911 电容触摸
- 框架：airui（LVGL 9），界面全部矢量图元绘制，**不使用任何图片资源**
- 数据：内置能源仿真引擎（可 15 分钟接上真实电表/逆变器，见文末）

## 交互

| 区域 | 操作 | 效果 |
|------|------|------|
| 分路用电 | 点任意一行 | 开关该路电器（模拟智能断路器），曲线、排行、KPI、电费全部同步重算 |
| 储能节点 | 点电池图标 | 循环切换储能策略：自发自用 → 峰谷套利 → 备电优先 |
| 光伏/电网/家庭节点 | 点节点 | 底部提示行显示该节点详情（功率、今日累计、电价段），同时语音念一遍 |
| 功率曲线 | 点 日 / 周 / 月 | 切换统计粒度（24h 曲线 / 7 天柱状 / 30 天柱状） |
| 右下角语音键 | 点一下 | 开 / 关语音播报（关掉时功放也拉低，夜里没有底噪） |
| 全屏 | 12 秒无人操作 | 曲线自动轮播日 → 周 → 月（展厅模式） |

所有反馈都写在**底部提示行**（4 秒后回落），不用弹窗 ——
这块屏是常亮信息板，浮层遮住数据反而碍事。

## 语音播报（`code/voice.lua`）

面板主体是"看"的，语音只补两件事：**用户刚做的动作有没有生效**、**家里能量状态拐点了**。
所以入口只有两个，语义不同：

| 入口 | 用在哪 | 冲突策略 |
|------|--------|----------|
| `voice.say(text)` | 点分路、切策略、切日/周/月、点节点 | 立即播；正在播就把这句挂起（只留最后一句，不积压） |
| `voice.auto(text)` | 进峰段 / 进谷段、余电开始上网 / 结束 | 忙就丢弃、8 秒冷却、同句 30 秒去抖 |

自动播报走**边沿检测**，不是定时念经：一天里只在电价换段、售电状态翻转时说一句。
仿真 60 倍速下一天只有 6 次换段，不会连珠炮。

后端按固件能力自动降级，PC 模拟器会落到静音模式（界面照常，右下角标"语音不可用"）：

| 优先级 | 后端 | 条件 | 起播方式 |
|--------|------|------|----------|
| 1 | `ex_tts` | `exaudio` + (`audio_v2.tts` 或 `audio.tts`) | `exaudio.play_start{type = 1, content = 文本}` |
| 2 | `av2_tts` | 只有 `audio_v2.tts` | 自己配 DAC + PA，`audio_v2.tts()` |
| 3 | `aud_tts` | 只有旧框架 `audio.tts` | `audio.config` + `setBus(DAC)` + `audio.tts()` |
| 4 | silent | 都没有 | 只打日志，不影响面板 |

两个坑已经写进代码注释，改这块时别删：

1. **起播前重建通路**：`play_stop` → `setup` → 音量 → `pm(RESUME)`。少了这段，第二句起
   `play_start` 可能返回 true 却不出声；
2. **结束回调会丢**，所以每句都挂按字数估算的看门狗，回调带播报代次 `gen`，过期回调直接丢弃 ——
   否则 `busy` 一旦焊死就永久静音。

音量、功放脚、冷却间隔都在 `code/theme.lua` 的 `M.audio` 里，`vol = 15` 是按客厅常亮面板定的
（背景音量，不抢人）；要静音就点右下角，不用改代码。

**屏显和语音是两套文案，不是同一句。** 屏上那行提示是"读"的：只占一行、看的人也知道 kW/kWh，
缩写信息密度更高；语音是"听"的，没有回看机会，术语必须先翻译成大白话，再报数字。
`dashboard.lua` 的 `tell(ui, speech)` 把两种写法摆在一起，改的时候不会只改一边：

| 屏上（缩写） | 念出来（口语） |
|--------------|----------------|
| `家庭负载 2.10kW  在用分路 5/8  今日已用 12.5kWh` | 家里现在用电 2.10 千瓦，8 个电器里开着 5 个，今天一共用了 12.5 千瓦时 |
| `电网 2.86kW  平段 0.56元/度  今日购电 3.2kWh` | 现在从电网取 2.86 千瓦，电价平时段，一度 0.56 元，今天买电 3.2 千瓦时 |
| `储能策略：峰谷套利（再点一次切换下一种）` | 储能现在是峰谷套利，电价便宜的时候充电，电价贵的时候放电 |
| `已进入峰段电价…储能优先放电` | 现在到高峰电价了，一度 0.62 元，电池开始放电，尽量少买电网的电 |

几处术语的翻译对照（改文案时照这个方向走，别再冒出新行话）：
`家庭负载 → 家里现在用电`、`分路 → 电器`、`平段 → 平时段`、`购电 → 买电`、
`余电上网 → 多余的电卖给电网`、`装机 kWp → 光伏板总容量`、`储能 → 电池`。
储能三种策略的解释句存在 `energy_data.BAT_MODE[i].say` 里，和策略名放在一起，改名时不会漏。

`voice.lua` 的 `norm()` 保留作单位兜底（`kWh → 千瓦时`、`kWp → 千瓦峰值`、`kW → 千瓦`、
`元/度 → 元每度`，先长后短），万一哪句漏写口语版，也不会念出"K W H"。

语速调不了（三套 TTS 接口都没有速率参数，见上文），节奏只能靠文案：口语句自带逗号停顿，
比原来一串数字连读听着舒服。

## 仿真模型（`code/energy_data.lua`）

| 量 | 模型 |
|----|------|
| 光伏 | 装机 8.6 kWp × 高斯日照包络（中心 12:24，半宽 3.3h）× 天气系数 |
| 负载 | 8 个分路之和，每个分路 = 额定功率 × 时段曲线（高斯叠加）× 慢抖动 |
| 储能 | 10 kWh；有光伏余量就充、峰段放电；充/放各有 3 kW 功率上限，SOC 限 20~95% |
| 电网 | `负载 + 充电 - 放电 - 光伏`，正=买电、负=卖电（四个数字永远自洽） |
| 电价 | 谷 0.32（23-7 点）/ 平 0.56 / 峰 0.62（8-11、18-21 点），余电上网 0.38 |
| 碳排 | 光伏发电量 + 上网电量 × 0.581 kg/kWh |

时间轴默认 **60 倍速演示**（1 秒 = 1 分钟，24 分钟走完一天），
开机时若系统有 RTC 则从真实时刻起走。

### 接真实数据

UI 只读下面这些字段。把采集写进来即可，**界面一行都不用改**：

```lua
local data = require "energy_data"

data.state.load = 2.86      -- 家庭负载 kW（恒正）
data.state.pv   = 3.42      -- 光伏发电 kW
data.state.bat  = 1.20      -- 储能 kW：正=充电，负=放电
data.state.soc  = 62        -- 储能电量 %
data.state.grid = 0.86      -- 电网 kW：正=买电，负=卖电
data.state.hour = 14.5      -- 当前时刻（0..24）

data.today.load, data.today.pv = 9.4, 12.6   -- 今日累计 kWh
data.today.buy, data.today.sell = 3.2, 2.1
data.today.cost, data.today.income = 1.79, 0.79
-- 分路：改 data.circuits[i].now 即可（排行榜自动排序）
```

典型数据源：

- **电表**：DL/T 645、Modbus RTU（`modbus` 库）/ MQTT 网关
- **逆变器**：厂家云 API 或本地 Modbus TCP 寄存器
- **储能 BMS**：CAN / Modbus RTU

采集任务用 `sys.taskInit` 起一个 1~5 秒轮询，写完字段后曲线和数字会在下一个刷新周期自动更新。

## 性能设计

10 寸 1024x600 没有 GPU，一次全屏重绘就是 61 万像素，所以按"脏区"分频重绘：

| 图层 | 周期 | 面积 |
|------|------|------|
| 能源流向（光点动画） | 66ms（15fps） | 336x316 |
| 分路排行 | 500ms | 264x316 |
| 功率曲线 | 1s | 384x316 |
| 全部文字 | 250ms（且内容不变不写） | 局部 |
| 背景 / 卡片 / 标题 | 开机一次 | — |

另外两点：

- 图元对象池复用 Lua 表，`finish()` 清空尾部残留 —— 否则 `set_items` 读到的长度会把上一帧的图元一起画出来；
- 所有整型字段进图元表前 `math.floor`：C 层用 `lua_tointeger` 取整型，传 3.7 这种非整数浮点会**静默得到 0**，宽度变 0、透明度变 0，物件直接消失。

## 硬件注意

- 背光 PWM3，LCD 供电使能 GPIO17（低有效），显示复位 GPIO15
- 触摸 GT911：I2C1，RST=14，INT=51；`tp.init` 必须给 `w/h`，否则 input 适配器静默拒绝，表现为"初始化成功但点不动"
- 背光在首帧画完后才点亮，避免上电花屏
- 语音走芯片内置 DAC + 板载 HT6873 功放，功放使能 `AUDIOPA_EN = GPIO73`（高有效）；
  静音开关会同时拉低它，避免夜深时的底噪
