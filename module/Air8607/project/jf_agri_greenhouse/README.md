# jf_agri_greenhouse · 农业大棚智能控制大屏

> 本工程由 AI 生成，下面是当时提给它的需求原文。

---

我要做一个农业大棚的集中监控大屏，挂在园区值班室和大棚入口，给种植管理者看。
一块屏要装下整个园区的运行情况：看一眼就知道哪里不对、该点哪个开关。

**整体**
横屏一页到底，不要翻页。最上面是标题和实时时钟；下面先横着一排把最要紧的数字摊开：
棚内平均温度、湿度、二氧化碳浓度、光照强度、待处理告警条数、正在运行的设备台数。
再往下分三列。

**左列：环境与土壤**
每个棚区各自的温湿度，并且不要只给数字，要直接给出结论：环境适宜 / 温度偏高 / 湿度偏低。
下面单独一块土壤墒情：每个棚区的含水率、酸碱度、土温，同样给出适宜 / 偏干 / 缺墒的判断。

**中列：棚区与设备**
一眼看清几个棚区的分布和各自状态；下面是设备控制，
卷帘、湿帘、风机、遮阳网、二氧化碳气肥、喷淋、浇灌、水肥、加热、补光这些设备，
每个都能直接在屏上点开或点关，点完在顶部弹一条提示告诉我操作成功、过两秒自己消失。

**右列：室外、水质与告警**
室外的温度、湿度、风速、风向、气压、降雨、紫外线；
灌溉水质给一个总评分，再加水温、酸碱度、浊度、液位。
最下面是告警：按紧急、警告、提示、已处理四档分别计数，
并列出还没处理的告警来自哪个棚区、是什么事；每条都能点"处理"，
也可以一键全部清除（清之前要再确认一次）。

**风格**
深蓝色夜间底、主色电光青；正常用青绿、警告用暖黄、异常用红，靠颜色就能判断轻重。
卡片平涂、小圆角，不要花哨的渐变和光效 —— 值班的人要长时间盯着看。

**数据**
先接模拟数据跑起来（设备清单和棚区配置按真实的来），各项数值每隔几秒小幅变动，
让大屏看起来是活的；以后换成真实采集时界面不用改。

**其他**
不要用图片素材，图表和卡片都用画的方式做出来。
