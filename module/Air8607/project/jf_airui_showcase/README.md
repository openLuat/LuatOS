# jf_airui_showcase · 视觉特效演示

> 本工程由 AI 生成，下面是当时提给它的需求原文。

---

我有一块 10 寸的屏，想做一个纯展示用的"特效样机"：给客户和展会看这块屏能画出多炫的画面，
不承载任何业务。

**整体结构**
上面一条窄顶栏：左边标题，中间显示当前场景的名字和一句看点，右边显示一下当前画面的流畅度。
中间是一整块大舞台。底部一排七个场景按钮，旁边一个"自动轮播"开关。

**七个场景（每个都要有自己的看点，不能都长一个样）**
1. 星系粒子：一堆光点绕着中心转，越靠外转得越慢，挨得近的点之间自动连线，像星座。
2. 频谱律动：一排音柱随节拍上下跳，柱顶有一顶"峰值帽"，地面有倒影，顶上还往下洒能量瀑布。
3. 雷达扫描：几圈距离环、一圈方位刻度，一道扫描扇面在转，扫到目标时留下余晖和涟漪。
4. 环形仪表：三层同心进度环反向转，最外圈带刻度，中间一个大读数，下面三条图例。
5. 三维晶体：一个立方体加一层对偶线框在自转，脚下是透视的地面网格。
6. 时空隧道：一层层方框从远处推近放大，中间有辐条，外面飞流星，要有很强的纵深。
7. 三维星球：一颗由点云组成的球体自转，带赤道环和一条倾斜的卫星轨道。

**风格**
深空黑底，主色电光青，配紫罗兰、品红、暖黄、青绿点缀；大面积流动渐变和辉光。
一张图片都不要，所有画面都现场算出来。

**交互与数据**
点底部按钮切场景；打开自动轮播就自己一个个放过去。
画面由合成波形驱动（正弦叠加噪声和节拍脉冲），不接任何传感器，每次开机看到的效果一致。

**最重要的一点**
七个场景都要跑得动、不能卡；右上角那个流畅度读数要好看。
