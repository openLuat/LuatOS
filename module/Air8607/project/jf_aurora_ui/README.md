# jf_aurora_ui · 极光界面演示

我想做一个「极光」主题的炫技界面，用来做品牌和技术展示，不承载业务。

**整体**
深空黑底，上面浮一层慢慢流动的极光。顶栏左边品牌名，中间时间，右边显示当前流畅度。
中间是主舞台，右侧叠三张半透明玻璃质感的卡片，底部四个页签。
点页签或用手指左右滑都能翻页，翻页时整页一起平移，页签下面有个会弹的小指示器；
长时间没人操作就自己轮播。

**四个页面**
1. **核心**：空间里三重陀螺仪环在旋转，外圈有刻度和一圈进度弧；
   右边卡片显示核心温度、输出功率、同步率，各配一条小趋势和一条能量条。
   用手指横向拖，能让它加速转起来，松手还有惯性。
2. **声场**：左右对称的音柱阵列，带峰值帽、地面倒影、顶部能量瀑布；低频来了有一圈冲击波的涟漪。
   右边卡片显示采样率、播放进度、低频能量，还有一个能拖动的音量条。
3. **星轨**：一片双臂旋臂的星云在缓慢旋转，星体之间有连线，盘面上有定位环；
   右边卡片显示恒星数、系统半径，还有一个调视距的滑块。
   拖动可以旋转视角，松手缓缓回正。
4. **星尘**：一圈被中心吸住的涡流粒子；手指划过去就喷粒子，粒子带拖尾和白芯；
   右边卡片显示粒子数，可以开关涡流、开关拖尾，还有一个「清空」按钮。

**风格**
深空黑加流动的极光，主色电光青，配青绿、紫罗兰、品红、暖黄；
卡片是玻璃质感：半透明底、顶部一道高光、细描边。一张图片都不要用。

**其他**
数值要平滑跟随、不要跳；切页要有过渡感（比如一道光带扫过），不要生硬地闪一下。
