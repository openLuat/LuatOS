我要做一个工厂车间的「数字孪生」大屏，挂在车间墙上或展厅里：
给管理者看整厂实时状态，也给参观者看气势。

**整体**
中央是一块三维的车间现场（画出来的，不要用车间的照片），左右各三块半透明的玻璃面板，
顶部一条标题栏，底部三个视图按钮加一条滚动字幕。
点按钮切视图，也可以打开自动轮播让它自己换。

**三个视图**
1. **孪生总览**：中央是车间透视场景，地面是全息网格，立着光柱、有物料流光沿路径跑，
   三处设备热点用标签标出状态和负载；左栏是综合效率环、今日产量与达成、设备在线数和健康度；
   右栏是实时功率与峰值、主轴温度和轴承振动两个半圆表、实时告警列表。
2. **产线透视**：五根按透视站立的产能光柱，柱高代表产出、颜色代表状态，下面是传送带的光流；
   左栏各产线的产出与工单状态、当前工单的进度环和当班趋势；
   右栏产能构成占比、生产节拍、产出曲线。
3. **能效态势**：一张分区×时段的立体柱阵，柱顶连成起伏的曲面，看起来像一片能耗地形；
   左栏各分区能耗排行和单位能耗（带目标线）；右栏实时功率曲线和全天峰谷分布。

**风格**
深色科技风，主色电光青；状态用青绿、蓝、紫罗兰、品红、暖黄、红来分轻重缓急。
背景是渐变夜空、地平线光带和厂房剪影，面板像浮在空中。整屏不要依赖照片素材。

**动效**
地面网格要有呼吸感，光柱随设备健康度起伏，物料流光沿线跑，热点带引导线和脉冲，
设备状态灯会呼吸，紧急告警的色条要闪，功率和产量曲线一直在游走 ——
看过去要像「活」的车间，而不是一张静态看板。

**数据**
先接模拟的产线数据（效率、产量、功率、温度、振动、分区能耗、告警），
数值用平滑的波动、不要跳；以后换成真实采集时界面不用改。
