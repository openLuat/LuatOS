# jf_ev_dash · 电动车仪表盘

> 本工程由 AI 生成，下面是当时提给它的需求原文。

---

我想在 10 寸屏上做一个电动车的仪表盘，全屏，深色风格，晚上看不刺眼、白天也看得清。
界面里不要用任何图片素材，所有图形（圆弧、刻度、条形、折线）都用代码画出来。

**主表盘**
中间放一个大圆表盘，车速不用指针，用一条发光的圆弧表示：速度越快弧越长，
从零扫到表底，快到极速的那一段要变成警告色，弧的末端有一个亮点。
车速数字放在表盘正中，要很大很醒目，下面是单位和当前档位。
表盘外圈要有刻度，大刻度带数字，方便一眼估算。

**左边两张卡**
一张是电量：一个环形进度 + 百分比，再告诉我还能跑多少公里，以及电池温度、
健康度、大约还要充多久。
一张是里程：总里程用大字，另外给单次里程、平均速度，再配一条行程进度的长条。

**右边两张卡**
一张是功率：把"正在出力"和"正在回收"分开显示，加速时一边长、松油门回收时往反方向长，
中间告诉我是多少千瓦。
一张是最近的百公里电耗趋势，用一条小折线就够，旁边给个平均和最大值。

**顶部**
一条状态栏：左转向、近光、远光、右转向、READY 指示灯、时间、车外温度。

**底部**
三个驾驶模式按钮：ECO、NORMAL、SPORT。切换的时候整个界面的主色调要跟着变
（青绿、电光青、品红），并且车子的"性格"也要变：节能模式跑不快、运动模式冲得猛。

**动效和手感**
- 转向灯要一闪一闪的，模式切换要有过渡，不要生硬跳变。
- 上电时先做一次自检：速度弧从零扫到底再回零，所有指示灯亮一下，然后才进入正常显示。
- 按住屏幕中间的表盘就算踩油门，车速往上冲；松手就是滑行，顺便显示能量回收。
- 没人操作几秒之后自己开始演示，像车真的在开一样（起步、巡航、滑行），
  否则摆在展台上画面是死的。
- 电量、温度、电耗这些数字要跟着车速和功率合理地变，别乱跳，要像真车的读数。

**其他要求**
- 表底按电动车常见的范围来定，速度、电量、功率的量级要合理。
- 最重要的一点：整屏要跟手、不能一顿一顿的。宁可少一点花哨效果，也要流畅。
- 交付一个能直接跑的完整工程，文件分好类，颜色、尺寸、字号这些统一管理，
  不要到处散落一堆魔法数字。
