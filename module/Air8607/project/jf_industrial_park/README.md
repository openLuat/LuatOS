# jf_industrial_park · 智慧工业园区管理平台

> 本工程由 AI 生成，下面是当时提给它的需求原文。

---

我要做一个智慧工业园区的管理大屏，挂在园区值班室和展厅：值班的人看一眼就知道园区整体怎么样、
哪里出了事；来参观的人也能看出这是个像样的管理平台。

**整体**
竖屏不行，要横屏一屏装下，全屏、深色底，晚上不刺眼。
最上面一条状态栏：左边平台名，中间日期和天气，右边设备在线数和时间。
底栏一条滚动的园区通知，右边小字说明数据多久刷新一次。
中间分三列：左边园区概况和能耗，中间园区平面图和通行/环境/工单，右边告警和安防。

**园区平面图（重点，要撑得住场面）**
把园区画成一张俯视的示意图：主干道十字交叉，把园区分成四块；楼栋按功能分块排布，
研发楼、生产车间、仓储、办公、机房、宿舍、食堂、绿化广场、停车区、物流门都要有，
楼与楼之间留出通道，不能挤在一起。
每栋楼要能看出是什么（楼名标在楼里），不同功能用不同的点缀色区分。
绿化广场里点几棵小树，停车区画出车位线，主干道上画车道虚线。
图上还要标出报警点位：有问题的位置点一颗会呼吸的圆点，不同严重程度不同颜色。
再让地图"动起来"：每隔两三秒有一栋楼被高亮一下，像巡检在依次看过去。
图例放在图的右上角（正常/告警/离线）。

**左上：园区总览**
一个入驻率圆环（中间大百分比），旁边四项：入驻企业、在岗人数、今日访客、车辆在园；
底部一条月度目标达成进度。

**左下：能耗监测**
今日总用电用大字显示，下面电、水、气三条进度，各自给百分比；底部本月累计和同比。

**右上：实时告警**
列五条，按严重程度排序，每条有颜色条、时间、发生位置和一句描述；
顶部显示还有几条待处理，底部给一个"查看全部"。
告警要会滚动：每隔几秒插一条新的到最上面，时间按当前时刻。

**右下：安防与通行**
设备在线率一条大进度 + 百分比；下面四类设备（视频监控、门禁、消防、广播）各自的在线数；
底部今日通行人次。

**中下三张小卡**
1. 通行车辆：今日进、出各多少，再分人工放行、ETC、临停入场。
2. 环境空气：PM2.5 数值 + 优/良判断，再列噪声、温度、湿度。
3. 服务工单：待处理几个，处理中、今日完成，配一条完成率。

**风格**
深色科技风：近黑的底、玻璃质感的卡片（半透明、顶部一道高光、细描边、圆角），
主色用电光青，只在一个地方用强调色，其它信息靠明暗分层；
状态色只在需要判断的时候出现：正常青绿、警告暖黄、异常红、提示蓝紫。
数字用等宽感的对齐方式（右对齐、单位小一号），大数加千分位。
不要用图片素材，全部用画的方式做出来。

**数据**
先跑模拟数据（园区规模、楼栋、设备清单按真实的编），数值平滑变化、不要跳；
人员、车辆、能耗、告警之间要有基本联动，看着像真的在运行。
以后接真实采集时界面不用改。

**性能**
这是要 7×24 挂着的屏，不能越跑越卡：卡片和数字按自己的节拍刷新，不要整屏一起重画；
地图上只让该动的东西动（报警点呼吸、楼栋高亮），不要做整块区域的扫描动画。
