# jf_moto_dash · 两轮车仪表盘

> 本工程由 AI 生成，下面是当时提给它的需求原文。

---

我要给两轮电动车 / 摩托车做一个仪表盘，装在车头上当仪表，也用来做展台样机。

**主表盘**
中间一个大圆表，带刻度和数字；车速用一根指针加一圈进度弧一起表示，弧的末端有一个亮点，
超过安全速度的那一段是红线区，快到时那一块要闪起来。
表心是大号车速数字，下面写单位和当前档位。

**左边两张卡**
一张电量：百分比、电池格子条、还能跑多远、电池温度。
一张里程：总里程用大字，另外给单次里程和平均速度。

**右边两张卡**
一张功率：当前输出功率，松油门时的回收功率，还有电机温度。
一张速度趋势：最近一段时间的车速曲线，加上最高车速和平均车速。

**顶部**
左右转向灯、近光 / 远光、时间。

**底部**
三个骑行模式键，切换时主色调和车的性格一起变：节能偏青绿、标准青蓝、运动橙红。

**动效和手感**
- 上电先自检：指针从零扫到满再回零，所有指示灯一起亮一下。
- 表盘里两道光点追着跑，看着有速度感。
- 按住表盘就等于拧油门，按当前档位往上冲；松手就滑行，顺便显示能量回收。
- 转向灯规律地闪；切档时来一圈涟漪加一道从上往下的扫光，颜色渐变过去。
- 没人操作几秒之后自动开始演示（起步、巡航、停车的循环），否则摆在那儿就是死的。

**风格**
接近纯黑的车规暗底，晚上不刺眼，底纹可以有一点碳纤维质感；
除了底纹和一点点光晕，其他尽量都用画的方式做，不要堆图片。

**其他**
速度、功率、电量、温度之间要互相关联，看起来像真车的数据，不要各走各的。
