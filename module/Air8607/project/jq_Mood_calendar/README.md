# 情绪日历 —— Air8607 治愈系心情记录

> 10 寸屏 · 本月月历 · 五档心情（超棒 / 不错 / 一般 / 不好 / 糟糕）· 本月心情指数 · 治愈系祝福语
> **纯离线运行**：本机没有 4G / WiFi，数据全部存在本机，不上传、不联网。
> **什么时候烧录，今天就是哪天**：烧录前双击 `tools\更新烧录时间.bat`，上电后按这一刻自动校准 RTC。

- 适用硬件：Air8607（Air1603）+ 10 寸 RGB 屏 1024x600 + GT911 电容触摸
- 编码 / 换行：UTF-8 / LF

## 提示词（Prompt）

> 以下是本项目交给 AI 的原始需求提示词，可据此复现或继续迭代本工程。

在 `module/Air8607/project` 下单独创建一个目录，名叫「情绪日历」，
今天以及过去的每一天都能点击选择心情：超棒、不错、一般、不好、糟糕共五档，分别对应 1-5 分；
点击下方按键「本月心情」，能统计本月心情指数，还能根据心情指数生成一句祝福语或者安慰语，
丰富 UI 内容，治愈风。

## 三之二、农历与节假日

格子第二行左边是农历日（`初一`..`三十`，闰月带「闰」字，如 `闰初四`），逢节日换成正红色的节日名。

| 类型 | 规则 | 显示 |
|---|---|---|
| 公历法定 | 1/1 元旦、5/1 劳动节、10/1 国庆节 | `元旦` `劳动` `国庆` |
| 节气法定 | 清明（4/4 或 4/5，按 21 世纪公式算） | `清明` |
| 农历法定 | 正月初一 春节、五月初五 端午、八月十五 中秋 | `春节` `端午` `中秋` |
| 农历传统 | 正月十五 元宵、九月初九 重阳、腊月初八 腊八、腊月最后一天 除夕 | `元宵` `重阳` `腊八` `除夕` |

- **节日当天**：格子铺一层淡红底、日期数字转酒红、第二行显示节日名。
- **初一看得出月份**：农历初一只写「初一」根本分不清是几月，所以格子第二行遇到初一就改成月名
  （`九月`、`闰六月`、`冬月`、`腊月`），顶栏则始终给完整写法 `农历九月廿一`。
- **提前看放假**：未来月份的节日也会显示成红字（虽然那天还不能点）。
- **心情优先**：这天已经记了心情时，保留心情底色和心情名，只把第二行的农历换成红色节日名 —— 用户自己填的内容不能被节日盖掉。

数据与算法（`app/lunar.lua`）：

- 农历用标准 `lunarInfo` 编码表，覆盖 **2020-2040**；超出范围格子第二行留空，其它功能不受影响。
- 每一年都用「闰月月份」+「春节公历日期」交叉核对过：2020 闰四月、2023 闰二月、2025 闰六月、2033 闰十一月（著名的「2033 问题」）等全部对得上；2020-2040 的春节、2024/2025/2026 的中秋也逐条验过。
- 闰月日期显示成 `闰初四`，且**闰月不重复过节**（闰八月十五不算中秋）。
- 换算结果带缓存（上限 800 条），翻月、记心情时重画 42 格不会重复算。

## 四、本月心情指数怎么算

```
指数 = 当月所有已记录日子的分数平均值        （1.0 ~ 5.0，保留 1 位小数）
```

- **没记录的日子不参与计算**，也不当成 0 分 —— 否则「这个月才记了 3 天」会被算成「心情很糟」。
- 一天都没记时显示 `--`，短评是「还没开始记录」，祝福语是「这个月还很空，点一个日子，把心情放进来吧」。
- 短评分 5 段：≥4.5 闪闪发光 / ≥4.0 挺好的 / ≥3.2 有晴有雨 / ≥2.5 有点起伏 / <2.5 辛苦了。

祝福语同样按这 5 段各准备 4 句，每句拆成 3 个短行方便排版；同一天多次点击会用 `os.time()` 取模轮换，
所以点「本月心情」每次可能看到不一样的句子，但同一份报告里的文字是稳定的。

> 只用常用汉字和中文标点：hzfont 字库里没有的符号（如中点「·」、emoji）会渲染成空白，本项目一律不用。

## 五、数据存在哪

按月存，一个月的记录最长也就 200 字节，读写都快、也不会有单值超限的问题。

| 后端 | 位置 | 说明 |
|---|---|---|
| 首选 | fskv（片内 flash） | key = `mood_202610`，掉电不丢，开机不用挂卡 |
| 备选 | `/sd/.mood/202610.txt` | 仅在 fskv 不可用时启用；文件名点开头，界面上看不到 |
| 兜底 | 内存 | 两个后端都不可用时只在内存生效，界面照常能点，不会崩 |

编码格式：`1:5,2:3,10:4`（号数:分数，逗号分隔）。

## 六、时间从哪来（什么时候烧录，今天就是哪天）

Air8607 **不带 4G、不带 WiFi**，无法 SNTP 授时；RTC 断电后又是无效值。
所以「今天是哪天」必须由烧录这个动作带进来 —— 就是 **烧录戳**。

| 优先级 | 时间基准 | 来源 | 精度 |
|---|---|---|---|
| 1 | **烧录戳** | `code/app/build_stamp.lua` 的 `stamp`，由 `tools/更新烧录时间.bat` 在烧录前写入电脑时间 | 到秒 |
| 2 | 固件编译日期 | `rtos.buildDate()` → `"Oct 30 2026"` | 到天 |
| 3 | RTC 自身 | 前两者都没有时，RTC 是多少算多少 | — |

> **为什么不能只用 `rtos.buildDate()`**：它返回的是**固件**的编译日期，
> 合宙官方固件往往是几个月前发布的，直接拿它当「今天」会把日历拉回几个月前。
> 烧录戳是「烧录前一刻的电脑时间」，才是真正的今天。

### 烧录流程（关键的一步）

```
① 双击 tools\更新烧录时间.bat        ← 把当前电脑时间写进 build_stamp.lua
② 立刻用 LuatTools 烧录 code/ 目录
③ 上电，日历的「今天」就是第 ① 步那个时刻
```

`tools/更新烧录时间.bat` 只改 `build_stamp.lua` 里 `stamp =` 那一行，注释原样保留：

```lua
return {
    stamp = "2026-10-30 15:37:37",   -- ← bat 每次重写这一行
}
```

### 上电后怎么校准

`drv/rtc_util.lua` 的 `calibrate()` 在每次上电跑一次：

| 情况 | 处理 |
|---|---|
| RTC 年份 < `conf.rtc.valid_year`（2020） | RTC 没初始化，校准到基准时间 |
| RTC 日期 < 基准日期 | 落后了（上次烧录的时间），校准到基准时间 |
| RTC ≥ 基准日期 | 不动，保留精确到秒的时间 |
| PC 模拟器 | 跳过（用电脑时间，绝不去写系统时钟） |

基准只有日期时（固件编译日期）校准到**上午 8 点**，避开 0 点跨时区把日期算到前一天。
想每次上电都强制重置成基准，把 `conf.rtc.force_calibrate` 设成 `true`（默认 `false`）。

启动日志会明确说明用了哪个基准：

```
I/user.rtc_util 时间基准 = 烧录戳 2026-10-30 15:37:37
I/user.rtc_util RTC 未初始化(1970-01-01) -> 已校准为 2026-10-30 15:37:38
```

> 忘了打戳时，只会退回「固件编译日期」，日志里会显示 `时间基准 = 固件编译日期 ...`。
> 看到这行就说明该补一次 `更新烧录时间.bat` 了。
>
> 还有一条物理限制：设备断电久放后重新上电，时间会回到**最后一次烧录的那个时刻**，
> 而不是真实今天（无网络、无 RTC 电池备份时无解）。这期间日历照常能点，只是「今天」偏早。

## 八、烧录与运行

## 九、已知限制

- **断电久放后日期会回到「最后一次烧录的时刻」**：无网络 + RTC 无电池备份时物理上无法恢复真实日期；
  想刷新就再打一次戳、再烧一次。
- **忘了打戳**：会退回固件编译日期（可能是几个月前），日志里 `时间基准 = 固件编译日期` 就是提示。
- **不能翻到未来**：未来的日子不可点（灰色底），这是产品定义，不是 bug。
- **农历只覆盖 2020-2040**：超出范围的年份，格子第二行留空，其它功能正常；要扩年份就往 `lunar.lua` 的 `INFO` 表里加。
- **只有清明一个节气**：二十四节气需要太阳黄经表，本版只算了清明（法定节假日里唯一的节气）。
- **不放假的调休没体现**：只标节日当天，不标「哪天补班」——调休安排每年国务院才发布，硬编码会过期。
- **没有删除当天记录的入口**：改心情只能覆盖，不能清空（`mood_store.clear()` 已提供，需要时可接一个长按格子）。
- **没有备份 / 导出**：数据只在片内 fskv；卡拔了不影响使用，也不会自动同步到卡。
- **满月 31 天时格子不会溢出**：网格固定 42 格，1 号位置由 `wday_of` 决定，任意年月都放得下。

## 十、后续可扩展

| 方向 | 说明 |
|---|---|
| 长按格子清空 | `label/container` 都支持 `set_on_long_press`，接上 `mood_store.clear` 即可 |
| 年度心情热力图 | 12 个月各取一次 `mood_store.load`，按格子颜色深浅画一张年视图 |
| 连续记录天数 | 从今天往前逐日查 `data[day]`，断掉就停，显示「已连续记录 N 天」 |
| 心情词云 / 月度回顾 | 复用 `mood_stat.summary` 的 `cnt`，加一页纯文字回顾 |
| 记录音效 | 硬件有内置 DAC + HT6873 功放（PA = GPIO73），选心情时放一声轻响 |
