# ev_charge_monitor · 电车充电站实时状态大屏

Air8607（Air1603）10 寸屏上的充电站监控界面：10 个充电桩的实时状态、每桩一节动态电池、
充电完成高亮停留计时、离线语音播报（含定时重复提醒）、手动输入播报内容。
零图片素材，全部用 `airui.shape` + `airui.label` 代码绘制。

- 分辨率：1024 × 600，深空科技简洁风
- 中文字体：固件内置 hzfont（中文最小字号 16，本工程全文 ≥ 16）
- 触摸：GT911 电容触摸
- 语音：离线 TTS（`exaudio`），无音频硬件时自动降级为日志播报

## 一、硬件与环境

| 项目 | 值 |
|---|---|
| 主控 | Air8607（Air1603） |
| 屏幕 | 10 寸 RGB 1024×600（免序列面板） |
| LCD 复位 / 显示使能 | `pin_rst = 15`（`gpio.setup(15, 1)`） |
| LCD 供电使能 | `pin_pwr = 17`，低有效（`gpio.setup(17, 0)` 即上电） |
| 背光 | PWM3（GPIO13），1000 Hz，先 0% 等 UI 就绪再 100% |
| 触摸 | GT911，I2C1 400 kHz（`i2c.FAST`），`pin_rst = 14`，`pin_int = 51`，下降沿 |
| 音频 | 芯片内置 DAC + HT6873 功放，`AUDIOPA_EN = GPIO73`，高电平使能 |

引脚与 `module/Air8607/project/factory/config/eng_8607_10i_v0.lua` 对齐。

固件需具备：

- `LUAT_USE_AIRUI`（含 hzfont 字库、`airui.textarea` / `airui.keyboard` / `airui.shape`）
- `exaudio` 扩展库 + `audio_v2`（语音播报；缺失不影响界面，只是没有声音）
- `LUAT_USE_PINYIN`（**可选**，只影响是否启用固件原生拼音输入法，见第六节）

## 二、功能

1. **10 个桩位实时状态**：5 列 × 2 行卡片，空闲 / 充电中 / 充电完成三态。
2. **每桩一节电池**：外壳 + 正极 + 5 个暗槽，电量按 soc 连续推进（不是整格跳变），
   充电中末段用更亮的青色。
3. **充电完成（充满 / 预充金额用完）**：
   - 卡片整体转荧光绿并做呼吸高亮（400 ms 节拍）；
   - 开始「停留计时」，每秒跳动；
   - 立即语音播报「XX号充电桩充电完成，请及时驶离，超时将产生费用」。
4. **定时播报**：勾选后按 N 分钟重复提醒，直到车辆驶离（计时归零、停止提醒）。
5. **手动播报**：点底部输入区弹出浮层，可用软键盘输入（字母/数字/英文）并配合
   内置拼音词表输入中文，或点常用短语一键填入；「播报」即时朗读，「停止」打断。
6. **演示入口**：点击任意卡片按 空闲 → 充电中 → 已完成 → 驶离 循环切换。

## 五、业务规则

**充电完成判定**：`soc >= target_soc` 记 `full`（充满）；`kwh >= limit_kwh` 记 `limit`（预充金额用完）。

**播报规则**：

1. 进入 `done` 的瞬间立即播报一次，无论定时开关是否勾选。
2. 勾选定时播报时，从完成时刻起每 N 分钟重复一次；未勾选则只在完成时播报。
3. 车辆驶离（`done → idle`）后 `done_s` / `next_say_s` 清空，计时归零，该桩不再提醒。
4. 中途修改 N 或开关开关：对已完成的桩从「现在」重新起算 N 分钟。
5. 多桩同时完成时进队列串行播报，不会互相打断；队列上限 8 条。

**计时基准**：不用 `sys.wait` 累加（会漂移），统一走 `mcu.ticks() / mcu.hz()` 折算秒。
Air1603 约 20 ms/tick，PC 模拟器 `hz() <= 1` 时按 1 tick = 1 ms 处理。

**演示数据**：`ev_manager.auto_demo = true` 时每 0.5 秒推进一次模拟
（soc +0.8%/s、电量按 90 秒走完额度），并偶发自动开始充电；接真机数据时置 `false`。

## 六、中文输入

`components/airui/inc/luat_airui_conf.h` 里 `LV_IME_PINYIN_USE_DEFAULT_DICT = 0`，
即不编译 LVGL 自带词典，词库只由固件宏 `LUAT_USE_PINYIN` 注入。固件没开这个宏时，
原生 IME 能创建但候选永远为空，打不出中文。因此本工程自带一层输入方案：

1. 键盘使用 `mode = "text"`，字母/数字原样进入输入框；
2. `ev_pinyin.lua` 对输入框末尾的字母串做「全拼精确 + 前缀」匹配；
3. 浮层里列出最多 6 个候选词，点击即把拼音替换成中文。

词表覆盖充电站播报场景（约 100 条，如 `chongdian→充电`、`shili→驶离`、
`chaoshi→超时`、`qingwu→请勿`、`nuoche→挪车`），同音字会一起出候选。
扩充只需在 `ev_pinyin.lua` 的 `ENTRIES` 里加一行 `{ "拼音", "词" }`。

若固件已开 `LUAT_USE_PINYIN`，原生拼音 IME 也会工作（串口会打印
`打开中文输入法支持，词典数量：N`），两套方案不冲突。

## 八、真机对接（关闭演示数据后）

```lua
local mgr = require "ev_manager"
mgr.auto_demo = false

-- 开始充电：soc 起始电量 / target_soc 充满阈值 / limit_kwh 预充额度 / kw 功率
mgr.begin_charge(3, { soc = 15, target_soc = 85, limit_kwh = 30, kw = 7.0 })

-- 充电过程中推进电量（电池动画会跟着走）
mgr.set_soc(3, 62)

-- 结束充电：reason = "full" 充满 / "limit" 预充金额用完
mgr.finish(3, "full")

-- 车辆驶离：停留计时归零，停止该桩的定时提醒
mgr.leave(3)
```

查询接口：

| 接口 | 说明 |
|---|---|
| `mgr.counts()` | 返回空闲、充电中、已完成的数量 |
| `mgr.stay_seconds(i)` | 第 i 桩的停留秒数（非完成态返回 0） |
| `mgr.charge_seconds(i)` | 第 i 桩已充电时长秒数 |
| `mgr.next_say_in(i)` | 距下次定时播报的秒数，无则 nil |
| `mgr.first_done()` | 第一个待驶离的桩（`nil` 表示没有） |
| `mgr.set_timer(on)` / `mgr.set_interval(min)` | 定时播报开关与间隔 |

状态变化会通过 `mgr.on_change(cb)` 回调，`cb(pile, action)` 的 `action` 为
`"charging"` / `"done"` / `"idle"` / `"soc"`。UI 已注册，正常情况无需再挂。

## 九、配置项（`ev_config.lua`）

## 十、已知限制与排障

- **上电花屏**：检查 `power_on()` 与 `backlight_on()` 顺序，背光必须在 UI 就绪后点亮。
- **点不动**：`tp.init` 的 `w` / `h` 必须传，缺了会被 input 适配器以 EINVAL 静默拒绝；
  触摸绑定必须在界面搭建完成之后。
- **没有声音**：先看串口 `ev_voice` 是否打印「exaudio 扩展库不可用」；
  有该日志说明固件没带 `exaudio`，界面照常运行，播报转日志。
  有库但无声则查 `pa_ctrl = 73` 与功放使能电平。
- **打不出中文**：确认是走 `ev_pinyin` 候选行（点候选词上屏），不要直接敲字母；
  若固件已开 `LUAT_USE_PINYIN`，原生候选面板会先接住字母，同样可用。
- **百分比/电量不刷新**：电池只在 soc 或状态变化时重绘，静置时不动是正常的。
- **RTC 未校时**：顶栏时钟显示 `--:--`，联网对时后自动恢复（业务计时不受影响，
  停留计时走 `mcu.ticks`，与系统时间无关）。
- **中文显示成方块**：固件未加载 hzfont，或字号 < 16。
