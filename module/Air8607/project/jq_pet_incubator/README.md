# jq_pet_incubator · 宠物恒温箱监控大屏

Air8607（Air1603）+ 10.1 寸 RGB 1024×600 屏上的宠物恒温箱集中监控界面：
多房间 / 多设备的温度、湿度、有毒气体实时监测，阈值设置、设备开关、越界声光报警。
零图片素材，宠物头像、图标、曲线、进度条全部用 `airui.shape` 图元现画。

- 分辨率：1024 × 600，奶油底 + 白卡片的软萌马卡龙风格
- 中文字体：固件内置 hzfont，字号 ≥ 16
- 触摸：GT911 电容触摸
- 报警音：内置 DAC + HT6873 功放，`/luadb/alarm.wav`
- 数据：全部为本地模拟数据，接真机采集时只需替换 `store.tick()`

## 一、硬件与环境

| 项目 | 值 |
|---|---|
| 主控 | Air8607（Air1603） |
| 屏幕 | 10.1 寸 RGB 1024×600（免序列面板） |
| LCD 复位 / 显示使能 | `pin_rst = 15`（`gpio.setup(15, 1)`） |
| LCD 供电使能 | `pin_pwr = 17`，低有效（`gpio.setup(17, 0)` 即上电） |
| 背光 | PWM3（GPIO13），1000 Hz，默认 82%，UI 就绪后才点亮 |
| 触摸 | GT911，I2C1 400 kHz（`i2c.FAST`），`pin_rst = 14`，`pin_int = 51`，下降沿 |
| 音频 | 芯片内置 DAC + HT6873 功放，`pa_ctrl = GPIO73`，高电平使能 |

引脚与 `module/Air8607/project/factory/config/eng_8607_10i_v0.lua` 对齐。

固件需具备：

- `LUAT_USE_AIRUI`（含 hzfont 字库、`airui.shape` / `airui.container` / `airui.button`）
- `exaudio` 扩展库 + `audio_v2`（缺失不影响界面，只是没有报警声）

## 二、功能

1. **主页设备墙**：3 列 × 2 行卡片（316×196），单页 6 台，多页时底栏出现翻页按钮。
2. **房间筛选**：`全部 / 各房间 / + 房间` 胶囊，房间条最多排到 x = 812，
   超出部分不再显示（需要更多房间就得改布局）。
3. **单卡三指标**：温度 / 湿度 / 有毒气体，各带数值、单位、紧凑阈值、进度条；
   越界时数值与进度条转红，整卡描红 + 淡红底。
4. **设备开关**：卡片底部「暖风 / 冷风 / 灯光」三个按钮，点击即切换并弹轻提示。
5. **详情页**：三张指标卡带 30 点历史曲线（含阈值带、上下限虚线、当前值圆点）。
6. **阈值设置**：温度、湿度为上下限双阈值，有毒气体仅报警上限；圆形 `-` / `+`
   按钮按步进调整，上下限互相约束，改完立刻重判并刷界面。
7. **报警**：任一指标越界即整机报警，`tick` 内按 2600 ms 限频播放 `alarm.wav`；
   顶栏可静音，`试听警报` 可随时验证音频通路。
8. **提示**：操作结果用底部居中的胶囊 toast，2.2 s 后自动隐藏。

## 五、数据与业务规则

**模拟规律**（`store.tick()`，每 `conf.sim.interval_ms = 1000` ms 推进一次）：

- 暖风开启：目标温度 +3.4 ℃、湿度 −9 %；冷风开启：温度 −3.2 ℃、湿度 +7 %；
- 两者都关时缓慢回落，叠加正弦自然波动；
- 有毒气体缓慢累积，灯光开启时每 tick 略降 0.35 ppm；
- 数值用一阶惯性逼近期望值（温度 0.16 / 湿度 0.12 / 气体 0.14），并夹在安全范围内。

**异常注入**：每 `anomaly_every = 24` 个 tick 随机挑一台设备、随机一个指标，
注入持续 14 个 tick 的正弦包络异常（温度 ±6.5 ℃、湿度 ±26 %、气体 ±9 ppm），
用来演示报警从触发到恢复的完整过程。

**报警判定**（`store.judge()`）：

1. 越界带 `tolerance = 0.02` 浮点容差，避免抖动误报；
2. 只在「正常 → 越界」的上升沿写报警日志，持续越界不刷屏；
3. 日志最多保留 20 条，最新在最前，`store.last_alarm()` 供底栏显示；
4. 阈值步进受互斥约束：下限不能顶到上限，反之亦然。

**报警音**（`alarm.lua`）：

- 后端优先级 `exaudio` → 固件 `audio_v2` → 无（只显示界面）；
- `exaudio.setup` 后默认处于 SHUTDOWN，起播前先 `pm(RESUME)`，否则第二次起播会静默；
- 播放前先 `play_stop` 再 `play_start`，避免上一段尾音叠在下一段开头；
- `tick` 内按 `repeat_ms / interval_ms = 2.6` 折算成 tick 限频，不会把音频通路打满；
- 静音只停播，不销毁音频通路，取消静音后下一次报警立即恢复。

## 六、配置项（`conf.lua`）

| 字段 | 说明 |
|---|---|
| `W` / `H` | 1024 × 600，改分辨率需要同步改各页布局常量 |
| `backlight.pwm_ch` / `freq` / `default` | PWM3、1000 Hz、82% |
| `font.size` / `cache_size` / `antialias` | hzfont 16 号、4096 缓存、抗锯齿 |

| `audio.pa_ctrl` / `pa_on_level` / `vol` | GPIO73、高电平、音量 40 |

| `sim.interval_ms` / `history_n` | 刷新 1000 ms、曲线 30 点 |
| `sim.anomaly_every` / `anomaly_ticks` / `tolerance` | 异常注入节奏与判定容差 |
| `limits.*` | 三指标的调节范围、步进、小数位、默认阈值 |

| `presets.pets` / `presets.rooms` | 添加设备时的候选名字 |

## 七、运行与烧录

**真机**：把 `code/` 下全部 `.lua` 与 `alarm.wav` 放到脚本目录，用 Luatools 烧录；
固件选带 AirUI 的 Air8607 10 寸版本。`alarm.wav` 必须落在 `/luadb/`，
否则 `alarm.init()` 只会打印「找不到报警音文件」，界面正常但不会响。

**PC 模拟器**（只验证逻辑与界面骨架，无音频、无触摸）：

```powershell
cd bsp\pc
cmd /c build_windows_32bit_msvc_gui.bat      # 必须 GUI 版，非 GUI 版不含 airui
build\out\luatos-lua.exe ..\..\module\Air8607\project\jq_pet_incubator\code
```

`main.lua` 会检测 `rtos.bsp() == "PC"` 并跳过供电、显示、触摸、背光，只跑 `airui` 与业务。

## 八、真机对接（替换模拟数据）

界面只读 `store` 的字段，接真实传感器时保持字段名不变即可：

```lua
local store = require "store"

-- 单台设备的最新值（key: t 温度 / h 湿度 / g 有毒气体）
local d = store.get(id)
d.temp, d.hum, d.gas = 27.6, 58, 1.2
store.tick()          -- 会推进历史曲线并重判报警

-- 新增/删除设备
local dev = store.add_device("小米", "chick", room_id)
store.remove_device(dev.id)

-- 阈值
store.step_th(d, "t", "hi", 1)     -- 上限 +0.5
d.th.t_lo, d.th.t_hi = 25.0, 31.0  -- 也可直接写字段，随后调用 store.tick()

-- 报警相关
store.any_alarm()      -- 是否有设备报警
store.alarms()         -- 报警日志（最新在前，最多 20 条）
store.alarm_devices()  -- 报警设备台数
```

实际接采集时，把 `store.tick()` 里的模拟递推替换成「读传感器 → 写 `d.temp/d.hum/d.gas`
→ `push_hist` → `judge`」即可，`app.lua` 的刷新定时器不用动。

## 九、已知限制与排障

- **白屏 / 花屏**：`main.lua` 的启动顺序不能调。背光必须在 `app.start()` 与
  `touch_init()` 之后才点亮，提前点亮会看到未初始化的花屏。
- **点不动**：`tp.init` 的 `w` / `h` 必须传（本工程传 1024×600），缺了会被 input
  适配器以 EINVAL 静默拒绝；触摸绑定必须在界面搭好之后。
- **没有报警声**：看串口 `alarm` 标签。打印「未找到 exaudio 扩展库」说明固件没带
  `exaudio`，此时会尝试直连 `audio_v2`；两者都不可用会打印「无可用音频后端」。
  有后端仍无声则查 `alarm.wav` 是否在 `/luadb/`、`pa_ctrl = 73` 与功放使能电平。
- **第二次报警不响**：`exaudio.setup` 后处于 SHUTDOWN，起播前必须 `pm(RESUME)`；
  本工程已在 `alarm.play()` 内处理，自行扩展时不要漏掉。
- **`type(lib) == "table"` 判断失效**：部分固件里 `exaudio` 是 userdata，
  只能逐方法探测（见 `alarm.lua` 的 `has_fn`），也不要用全局变量直接当库用。
- **按钮无法隐藏**：`airui.button` 没有 `set_hidden`，需要「出现/消失」的控件
  （翻页按钮）通过整页重建实现，这也是切换房间、翻页都调用 `M.build()` 的原因。
- **卡片文字挤压**：卡片单格只有 88 px 宽，卡片上必须用 `store.th_range_short()`
  （省略「阈值」前缀），详情页才用 `store.th_range_text()`。
- **点卡片进错设备**：`build_card` 的闭包必须捕获局部 `local id = d.id`，
  直接用循环变量会取到 nil。
- **中文显示成方块**：固件未加载 hzfont，或字号 < 16（本工程全文 ≥ 16）。
- **没有删除入口**：`store.remove_device()` 已实现但未接到界面，需要删除功能时
  在详情页顶栏加按钮并调用 `app.close_detail()` 后 `app.reload_home()`。
- **房间胶囊显示不全**：房间条可用宽度到 x = 812 为止，房间多了会被裁掉，
  属于布局限制而非 bug。
