# uav_gcs · 无人机姿态与飞控地面站

> 本工程由 AI 生成，下面是当时提给它的需求原文。

---

我要做一个展示无人机姿态和飞控的应用，装在一块 10 寸屏上做展台样机，也当调试地面站用。

**主界面（姿态）**
左边要有一个立体的机体姿态视图：线框训练场里停着一台四旋翼，机身跟着真实的横滚、俯仰、
偏航一起转，桨叶要转起来，四个电机下面有推力光柱，前桨后桨用不同颜色。
右边是一个标准的人工地平仪：球会随姿态倾斜，外面套一圈航向罗盘，
左右各一条速度带和高度带，中间显示当前值。球下面要有俯仰横滚的读数。
再往下是遥测表：飞行模式、锁定状态、高度、电压、卫星数、定位精度、链路、飞行时间。

**数据页**
把各个子系统的数据摊开：姿态角、四个电机的转速、电池电压电流电量温度、
IMU 振动和三轴加速度、最近一段时间的高度剖面、链路质量曲线。用卡片排，一眼能扫完。

**参数页**
列一堆 PID 参数，能加减调整。右边要有一条**跟着参数实时变化的阶跃响应曲线**，
调 P 变大飞机就抖，调 D 变大就变钝，这些都要能在曲线上看出来。
同时给出超调量和上升时间。

**功能页**
八个动作按钮：解锁上锁、一键起飞、定点悬停、自动返航、立即降落、校准罗盘、
故障注入、清零统计。图标全部要画出来，不要图片。右边是事件日志，最新在最上面，
按级别染色。

**地图页**
一张相对起飞点的战术图：同心距离环、电子围栏、实时航迹、航点规划、
无人机图标跟着航向转。点地图能加航点。

**动效和手感**
- 上电先自检一下，别一上来就是一张静态图。
- 没人操作 8 秒之后自己开始演示：解锁、起飞、巡航、返航、降落，走一个完整循环。
- 一碰屏幕立刻交还手动控制。
- 按住姿态页的三维视图就是虚拟摇杆：左右横滚、上下俯仰，松手回中。

**风格**
深空蓝黑的底，只用一个青蓝强调色分层，告警色只在真出问题时出现。
机体、仪表、曲线、图标全部用图元画，不要堆图片素材。

**其他**
姿态、速度、高度、电量、链路之间要互相关联，看起来像真的在飞，不要各走各的。

## 实现要点

**零图片素材**：机体、训练场、姿态球、罗盘、刻度带、曲线、八个动作图标全部由
`airui.shape` 的 `line / rect / circle / arc / ellipse` 图元实时绘制。真机上没有
图片解码开销，也没有图片缓存压力（`LUAT_USE_AIRUI_IMAGE_CACHE_SIZE` 只有 1MB）。

**姿态球用扫描填充**：shape 没有多边形填充，天地球按 4px 横带切开逐行填，
每行算弦宽与天/地分界，一行两个 rect，半径 86 的球一共 86 个图元。
横滚任意角度都连续，且比逐点绘制省两个数量级。

**真 3D 不是假转**：机体的每个顶点做「偏航 -> 俯仰 -> 横滚」旋转再透视投影
（`fx.rot3` + `fx.proj3`），所以任意姿态、任意角度都准确；房间网格是静态的，
只算一次投影，塞进单独的 shape，不占每帧预算。

**刷新预算**：仿真永远 30Hz；姿态页 30fps（球在转，掉帧最明显），其余页面 10Hz，
顶栏 2Hz。文字写入全部走 `parts.text` 的缓存，值没变就不 `set_text`
（LVGL 每次 set_text 都要重新排版）。

**数据自洽**：倾斜角 -> 水平速度 -> 位置 -> 距起飞点距离 -> 链路质量；
桨转速 -> 电流 -> 电压 / 电量 / 电调温度。所有量互相咬合，不会出现
「速度 0 但位置在跑」这种一眼假的情况。

## 字体说明

界面文本只用 ASCII + 汉字 + 斜杠：角度不带单位、温度写 `42 C`、速度写 `5.2 m/s`。
日志里的全角逗号 / 冒号由 `sim.log` 统一清洗成空格（部分固件的标点子集不全）。
