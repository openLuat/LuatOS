# 今天吃什么 · 三页转盘（Air8607 10 寸屏）

用 LuatOS + AirUI 在 1024×600 上做的「今天吃什么」转盘，卡通风格，整屏**零图片素材**，盘面、扇区、灯泡、卡片、页签全部由矢量图元现场绘制。

- 页面一 **减脂餐**：50 道菜 50 选 1，停稳后右侧出编号、菜名、菜谱要点和一条小贴士。
- 页面二 **家常菜**：三环盘 80 选 5（外环荤菜 40 选 2 / 中环素菜 30 选 2 / 内环汤 10 选 1），点一次连续停靠 5 次，右侧逐张出卡片，点卡片看做法。
- 页面三 **外卖**：50 家店 50 选 1，停稳后右侧出菜名 + 一句趣味文案。

顶栏三枚胶囊页签切换场景，各页结果各自保留；转动期间所有输入锁死，不会两个盘同时转。

## 几个设计取舍（改之前建议先看）

**1. 为什么整屏不用图片**
真机的图片缓存只有 1MB（`components/airui/inc/luat_airui_conf.h` 里 `LUAT_USE_AIRUI_LUATOS` 分支 `LV_CACHE_DEF_SIZE = 1024*1024`），一张 500×500 的 RGBA 盘面就接近这个数，来回切页必然把缓存挤爆、出现二次解码卡顿。所以全部用 `airui.shape` 现场画，顺带换来了「任意分辨率都清晰」。

**2. 扇区为什么用「胶囊」而不是 arc**
`airui.shape` 的 `arc` 图元在软件渲染器里，每个圆弧的绘制任务区是**整圆外接矩形**，50 个扇区一次整盘重绘要跑 50 次 546×546 的角度掩码，真机会卡 0.3s 以上；而页签切换必然触发整盘重绘，躲不掉。改用 `line` 图元 + 圆头（`round_start/round_end`）拼的「胶囊」后，每个扇区只栅格化自己那一小块，整盘约 13 万像素。附带好处：只依赖 `line/circle/rect` 三个最老的图元，老固件也能跑。

**3. 为什么是「扫光带」而不是「盘面旋转」**
AirUI 里只有 `image` 支持 `set_rotation`，而旋转盘面必须预生成 PNG，正好撞上第 1 条的图片缓存问题。现在的做法是：盘面静止不动，一个 156×156 的**小对象**（扫光带）每帧 `set_pos` + `set_items` 挪到当前角度，脏区只有两块小方块——这是整屏唯一的逐帧开销，30fps 下约 1.2 Mpx/s。编号压在光带上面，扫过时逐个点亮，停稳后光带留在原地当指针。

**4. 家常菜为什么是「连停 5 次」**
需求是 80 选 5（荤 40 选 2 / 素 30 选 2 / 汤 10 选 1）。三环盘一次停靠同时命中三个环，观感上分不清哪一道被采纳；改成点一次连续停 5 次（荤 1 → 素 1 → 荤 2 → 素 2 → 汤），每停一次右侧加一张卡片，配额一目了然，而且五道菜互不重复。

**5. 卡片点开才看菜谱**
5 道菜的菜谱要点同屏挤不下（面板只有 368×514），所以卡片只放「类别 + 菜名」，点哪张就在下方固定高度的详情区显示它的做法。`airui` 的 container / label 都没有 `set_size`，所有尺寸只能在创建时定死，这也是详情区高度固定的原因。

## 数据来源

菜品与菜谱来自 `D:\Air\Documents\8607\whatWeeat\今天吃什么.xlsx`：

- **减脂餐**：原表只有 48 条（39、40 号是空号），按同样的「少油少盐、家常可做」风格补了 **39 柠檬香草虾、40 南瓜燕麦粥**两道，凑满 50；补的两条在 `foods.lua` 里有注释标记。
- **家常菜**：荤菜 40 / 素菜 30 / 汤 10，共 80，无缺号。
- **外卖**：50 条，原表没有菜谱列，所以外卖页只出菜名，另外配了一句随机趣味文案。

菜谱原文里的长破折号（—）、摄氏度（℃）、中间点（·）、全角括号会被 hzfont 渲染成方框，`foods.lua` 在加载时统一替换成兼容写法（`—→-`、`℃→度`、`（）→()`），源文件里保留原样。

`foods.check()` 会在开机时校验条数，少一条就在串口报警，避免数据被改动后界面静默错位。

## 可调参数

都在 `code/ui/ui_theme.lua` 一张表里：

| 想改什么 | 改哪里 |
| --- | --- |
| 盘面大小、圆心 | `T.wheel.r_plate / cx / cy`（改半径要同时看 `r_in / r_out`） |
| 各环扇区数、颜色、编号半径 | `T.rings.diet / out / home` |
| 单抽时长与圈数 | `T.spin.single_ms / single_turns` |
| 家常菜每次停靠时长与停顿 | `T.spin.home_ms / home_turns / home_hold` |
| 配色 | `T.c`（主色 `accent`、盘体 `plate`、三页糖果色 `diet_* / out_* / meat_* / veg_* / soup_*`） |
| 字号 | `T.f` + `T.font_sizes`（`font_sizes` 是开机预载清单，加字号记得同步加上） |
| 右侧面板位置 | `T.panel` |

## 已知限制

- 转动时页签与其它按钮不可点（全局 `busy` 互斥），这是刻意设计。
- 菜谱正文按估算的行数在固定区间里垂直居中，极端长文本（超过 8 行）会被框裁掉；当前最长 57 字约 3 行，安全。
- 盘面每帧的脏区是 2 个 156×156 方块，盘面图元虽被连带重绘但会被裁剪，只在 Air1603 这类带 PSRAM 的板子上验证过；若换更弱的平台，可先把 `T.wheel.frame_ms` 从 30 调到 40。
- 家常菜卡片详情区高度固定（100px），菜谱超过约 5 行会显示不全 —— 数据里没有这么长的条目。
- 送样机若屏参不同（时序/背光通道），改 `code/drv/lcd/exd_air8607_rgb.lua` 的 `ic_info` 与 `app_main` 的 `power_on()`。
