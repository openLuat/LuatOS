# ASRS-2400 立体库 · PLC 主控屏（PLCUI）

Air8607 / Air1603 + 10.1 寸 RGB 1024×600，PLCUI 做的**单屏主视图**界面。
左侧 360 个库位构成的点阵常驻，右侧面板在「库位 / 任务 / 报警」三视图间切换——**不分页**，与前几套（顶部页签、左侧导航）都不同。

## 设计要点

**单屏 + 右侧面板**：左边矩阵永远在，右边切换。切换不是翻页，观众能一直看到库位分布，不会“换一屏就丢上下文”。

**库位矩阵**：6 巷道 × 12 列 × 5 层 = 360 个托盘位，每格 38×7（托盘位本来就是扁的）。
在库 243 / 锁定 15 / 空位 102，与顶栏「在库 243 / 360 · 67.5 %」一致。

**搬运模拟**：每 3 秒配对执行一次「出库 + 入库」，只对这两个格子 `set_hidden`，不遍历全部 360 个；
两台堆垛机各有一块赭石标记，用 `set_pos` 移到目标格。

## 两个绕不开的 PLCUI 约束

### 1. 512 个组件上限

原本设计是 6 巷道 × 24 列 × 5 层 = 720 格，实测加载报：

```
E/user.ui 加载失败 Component count limit exceeded | code=E_SCHEMA line=521
```

`PLCUI_MAX_WIDGETS 512` 在 commit `cf63730b9`（2026-11-18）才被移除，而：

- **PC 模拟器** `luatos-pc.exe`（LuatOS-PC V2040）ROM Build **2026-11-17 17:45** → 有 512 限制
- **设备固件**是 2026-11-12 构建 → 同样有

所以两侧都跑不了 720 格。改为 **6 × 12 × 5 = 360 格**，总组件 494，留 18 个余量。
若将来换用 11-18 之后编译的固件，可恢复 24 列（组件数只受 256 KB XML 限制）。

### 2. 容器不继承 `hidden`

PLCUI 的 container 只是背景块，**隐藏父容器不会隐藏子元素**。所以三个视图不能靠"藏一个组"实现，
必须把每个视图的元素逐个登记、切换时统一开关。`ui_app.view_ids()` 就是这张登记表。

## 已知限制

- 三个视图共 60 余个元素，每次切换约 60 次 `set_hidden`；实测点击到画面刷新无明显延迟。
- 库位格颜色写死在 XML：空格入不了库（入库只在"已隐藏的在库格"之间配对），锁定格不能解锁。
  真实系统应改为「按状态查表更新颜色」，那需要 PLCUI 提供 `set_color`。
- 任务队列与报警是静态示例，未接 PLC。

## 在 PC 模拟器上跑

用 LuatTools 自带的 PC 模拟器（与真机固件同源，行为最接近）：

```
cd D:\hezhou_workfiles\luatools_v3\resource\LuatOS_PC\LuatOS-SoC_V2040_PC
luatos-pc.exe --agent-ctl=127.0.0.1:9992 D:\hezhou_workfiles\warehouse_code\LuatOS\module\Air8607\project\mmy_asrs_plc\code
```

它同样支持 `--agent-ctl`，可用 9992 端口截图与点击；它把脚本目录挂在 `/luadb`（`res` 被拍平），
所以 `ui_app` 的候选路径会命中 `/luadb/main.xml`。

chip 中心坐标：(672,131) / (748,131) / (824,131)。
