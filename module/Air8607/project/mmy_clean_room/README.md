# mmy_clean_room · 华康生物 无菌制剂车间 GMP 环境监控

> Air8607 + 10 寸 1024x600 RGB 屏 + GT911 触摸的常亮型看板。
> 挂在无菌车间走廊门口的那一块：五间洁净区 + 一条洁净走廊，看得是"有没有守规矩"。

---

## 它回答什么

无菌车间的看板不是"看产量"，是看三件事有没有越界：压差梯度、温湿度、悬浮粒子。
任何一项失守，整批药就是废品。四个问题对应四页，一页只讲一件事：

| 页 | 问题 | 主要内容 |
| --- | --- | --- |
| 1 总览 | 哪一间正在失守？ | 洁净区平面（房间块染色 + 对走廊压差 + 粒子量条 + 门洞气流）/ 待确认事件 / 今日概览 |
| 2 气候 | 是刚掉下来的，还是一直在往下走？ | 24h 温湿度双道大图（合规带打底 + 末端呼吸光点）/ 五个监测点 / 三张读数卡 |
| 3 送风 | 送风侧还撑不撑得住？ | AHU 频率与送风温度 / 三级滤器阻力对限值 / 风路框图 / 今日负荷曲线 |
| 4 事件 | 刚才发生了什么，还有谁没确认？ | 一屏 10 行事件表 / 按等级筛选 / 未确认统计 / 全部确认 |

## 交互

| 操作 | 结果 |
| --- | --- |
| 点页签（顶栏下方） | 切到该页；切页不动数据、不重建控件，回来还是同一间房间 |
| 点房间块（总览） | 选中该间（全局共用），气候页跟着切到这间的 24h 曲线 |
| 再点同一间（总览） | 4 秒内再点：模拟开门，门开 8 秒，压差往下掉、粒子涨，记一条事件并播报 |
| 点监测点行（气候） | 换房间，曲线与三张读数卡一起重绘 |
| 点右上模式胶囊 | 生产 → 值班 → 消毒 循环；整场的压差/温湿度设定随之一阶跟随 |
| 点"挂牌隔离" | 该房间停送风、压差归零、粒子按 0.7 倍沉降；再点解除（同时播报） |
| 点事件行（总览 / 事件页） | 确认该条（变色但不消失，留痕给人回看） |
| 点筛选胶囊（事件页） | 全部 / 未确认 / 仅报警；默认"未确认"，交班时从上往下点完即清屏 |
| 点"全部确认"（事件页） | 一次清掉所有未确认事件 |
| 点右下角语音 | 语音开 / 关；PC 模拟器和无 TTS 固件上显示"语音不可用" |
| 15 秒无操作 | 总览页每 12 秒轮换选中房间，适合无人值守的墙上看板 |

## 数据模型（接真实采集只看这一节）

界面只读下面这些字段，**不自己算限值、不自己算达标**。接 Modbus 采集
（压差变送器 / 温湿度传感器 / 粒子计数器 / AHU 变频器）时按同样字段往里写值即可，
`dashboard.lua` 与四个 `page_*.lua` 一行都不用改：

```lua
data.rooms[i] = {
    id = "B", name = "灌装间", grade = "A",
    dp = 18.0,        -- 对走廊压差 Pa
    t  = 21.2,        -- 温度 C
    rh = 48,          -- 相对湿度 %RH
    p05 = 900, p5 = 9,-- 0.5um / 5.0um 悬浮粒子 count/m3
    lim05 = 3520, lim5 = 29,   -- 该级别上限（GMP 附录1 / ISO 14644）
    ach = 60,         -- 换气次数
    door = false,     -- 门磁
    iso  = false,     -- 挂牌隔离
    over = false,     -- 越限
}

data.state = { min_dp = 12.4, avg_t = 22.1, avg_rh = 50, ok_pct = 100,
               at_grade = 2, over = 0, ach = 60, energy = 12.6 }
data.ahu   = { freq = 42.5, sup_t = 19.2, ret_pct = 78, flow = 8600,
               filt = { 0.32, 0.58, 0.41 } }   -- 初/中/高效阻力，0..1
data.events[1] = { t = "09:12", level = 3, text = "压塞间压差低 6.4Pa", acked = false }

data.sel = 2      -- 当前选中房间 1..5，四页共用：在总览点房间，切到气候页还是这一间
```

事件用**下标**确认（`data.ack_event(k)` 收的是 `data.events` 的索引），
页面只缓存下标，不缓存事件对象 —— 事件表头部插入新事件时下标会整体后移，
每 500ms 重新 `pick()` 一次即可，不存在悬空引用。

## 物理模型（演示数据怎么来的）

- **模式 → 送风**：生产（18Pa / 60 次/h）、值班（16Pa / 30 次/h，压差不降）、
  消毒（22Pa / 65%RH，人员禁入）。模式一换，房间用 3 秒一阶惯性跟过去，不会瞬间跳变。
- **压差**：目标值 = 模式基准 + 该房间的梯度偏差（灌装间最高，待检包装最低）；
  开门 -8Pa，隔离归零。门开 8 秒自动回弹。
- **粒子**：门开 ×2.4、压差失守按缺口放大，恢复后 5 秒时间常数回落。
  A 级限值 3520，D 级 352 万 —— 相差一千倍，所以粒子量条按"占限值比例"画。
- **AHU**：频率跟随模式，流量跟频率，送风温度跟模式设定；
  三级滤器阻力缓慢上涨（演示压到一天涨 8%），高效过 85% 记一条警告事件。
- **能耗**：风机功率按 f³ 估，累加 kWh。
- **事件流**：只记状态边沿（越限、恢复、开门、切模式、隔离），不按定时刷屏；
  同键 40 秒内去重。首帧不会刷一屏"恢复"。
- **随机数用固定种子**：每次开机现象一致，方便截图与复现。

## 性能取舍

10 寸 RGB 屏没有 GPU，一次全屏就是 61 万像素。两条原则：

1. **切页不重建**：四页开机各建一次，切页只 `set_hidden`。在触摸回调里销毁再重建
   一整页控件是这块屏最容易崩的写法。代价是常驻内存多几十 KB，换来切页 0 帧卡顿。
2. **只重画本页在变的那块**：每页各持一块 `airui.shape`，只 feed 自己的图元，
   绝不全屏清一次再画一遍。四页里只有当前页的 `update` 会被调用。

| 页 | 区域 | 周期 | 理由 |
| --- | --- | --- | --- |
| 全局 | 时钟 / 状态 / 超标数 | 250ms | 内容不变不 `set_text` |
| 全局 | 模式胶囊 | 500ms | 跟着数据模式走 |
| 1 总览 | 洁净区平面 | 200ms | 气流动画 + 压差读数，房间少，整块重绘不贵 |
| 1 总览 | 待确认事件 | 500ms | 只在事件变化时有意义 |
| 1 总览 | 今日概览 | 700ms | 三个数都是慢变量 |
| 1 总览 | KPI 四格 | 250ms | 量条跟数值走 |
| 2 气候 | 24h 双道趋势 | 1500ms | 温湿度都是慢变量 |
| 2 气候 | 监测点列表 | 500ms | 行内读数刷新 |
| 2 气候 | 三张读数卡 | 300ms | 当前值要给"现在"的手感 |
| 3 送风 | AHU 主卡 + 滤器 | 400ms | 阻力是慢变量，量条比文字更值得刷 |
| 3 送风 | 负荷曲线 | 1000ms | 一天的量级，快刷没有信息增量 |
| 3 送风 | 风路框图 | 500ms | 框内读数跟着变 |
| 4 事件 | 事件表 | 500ms | 新事件边沿本来就是秒级 |
| 4 事件 | 统计 + 操作卡 | 500ms | 计数与按钮可用态 |
| 所有页 | 背景 / 卡片 / 标题 / 页签 | 开机一次 | 静态层不进每帧预算 |

## 上机

1. 整份 `code/` 直接作为 Air8607 工程的 script 目录；
2. 屏幕分辨率改 `theme.screen` 与 `app_main.lua` 里的 `SCREEN_W/SCREEN_H`；
3. 触摸引脚（`pin_rst = 14`、`pin_int = 51`）按实际板子改 `app_main.touch_init()`；
4. 功放使能脚不在 GPIO73 时改 `theme.audio.pa_ctrl` 与 `pa_on_level`；
   没有功放就置 nil，语音自动降级为静音，右下角会标出来，不影响主流程。

## 已知限制

- 界面文本只用 ASCII + 汉字：`hzfont` 矢量字库没有 `°`、`·`、`→`、`μ` 这类符号，
  用了会显示方框，所以温度写 `22.1C`、湿度写 `48%RH`、粒子写 `P0.5` `um`。
- 房间块是画在 `shape` 上的图元，不是独立控件，所以没有"按钮按下态"：
  选中态用四角括号 + 外框表达。
- 触摸只认 `TP_DOWN`：抬手坐标可能已经滑到隔壁房间，抬手误触比漏触更讨厌。
- 语音是在触摸回调里入队、由独立 worker 起播的（起播要等 40ms 音频通路稳定，
  不能在 LVGL 输入回调里 `sys.wait`）。队列最多积 3 条，再多就丢。
- 四页控件常驻：换来切页不卡，代价是几十 KB 内存和更长的开机首次构建时间。
  内存吃紧的板子可以改成"切页销毁、只保留当前页"，但要把 `dashboard.switch()`
  里的 `set_hidden` 换成 `destroy + build`，并接受切页 1~2 帧的停顿。
- 总览的自动轮播只在本页可见时进行；停留在气候/送风/事件页时不会抢走用户选的房间，
  但也不会自动换房间 —— 墙上看板建议常驻总览页。
- 数据是本地仿真。接真机时把 `room_data.tick()` 的仿真段整体替换为
  "读缓存 + 算派生指标"，事件边沿判定那段建议保留。
