# EFEM-200 晶圆传输模块 · PLC 主控屏（PLCUI）

Air8607 / Air1603 + 10.1 寸 RGB 1024×600，PLCUI 做的五页主控屏。
**侧栏导航版式**：左侧 88px 竖向导航 + 64px 状态条 + 非网格主区，与前两套（顶部页签 + 卡片网格）刻意区分。

## 五页

**总览** — 晶圆流转（LP1 / LP2 → ALIGNER → ROBOT → PM1/PM2/PM3，当前路径绿色）+ 吞吐卡 + 机械手卡 + 底部横向事件流。

**时序** — 24.3 s 搬运甘特（5 条泳道、逐段标注）+ 各站占用条 + 节拍分解 + 瓶颈提示。

**曲线** — 2×2 四张实时曲线：腔体真空度、N2 吹扫压力、机械手电流、腔体温度。

**点位** — DI / DO / AI 三张表 + AO 横向三块（含给定条）+ 强制 + 诊断。

**系统** — 左侧 9 项设备档案竖列 + 维护计数 2×2 + 显示 + 运行。

## 数据自洽

- 节拍 24.3 s = 取放片 8.6 + 对中读码 5.0 + 腔体交接 3.4 + 等待 7.3
- WPH 148 ≈ 3600 / 24.3 ✓
- 甘特图 ROBOT 四段合计 10.3 s，占 38 %，与页脚标注一致
- 占用率与甘特条长度对应（ROBOT 93 % 最高，标成橙色）
- 搬运片数、维护计数随周期累加（`S.cyc` 驱动，带千分位）

## 版式落地的几个处理

| 手法 | 原因 |
|---|---|
| 侧栏高亮 = **每页各存一份，XML 里预置位置** | 运行时改不了颜色；且 `xml.show` 之后组件延后实例化，此刻 `find` 拿不到句柄，`set_pos` 会静默失败——真机上表现为"绿条不动" |
| 侧栏文字统一 `#A9BECC` | 选中项不能变白，用高亮块 + 绿条表达选中 |
| 卡片 = 白底 + 1px `#E3E7ED` 描边 + 4px 圆角 | 白底上只靠阴影分不开（PLCUI 无阴影），描边是唯一可靠手段 |
| 流转连线 = 2px 细色块拼 L 形 | 没有画线组件，用容器拼直线最省 |
| 甘特条 = 容器 + 内嵌标签 | 宽度按时间比例算，窄于 44px 时不放文字避免截断 |
| 四张曲线 200 ms 取数、**1 Hz 入图** | 30 点 = 30 秒窗口；5 Hz 入图会让慢变量在窗口里变成直线 |
| 表格位号列 **74px** | 62px 会让 `Q0.0` 折行（`I0.0` 却放得下），PLCUI 的列宽要比字面宽度多留约 12px |

## 已知限制

- 侧栏切换是"整页显示/隐藏"，不是滚动容器；切页耗时约一帧。
- 侧栏每页各有一份高亮块与绿条（共 10 个组件，各 88×88 与 3×88），换来的是零运行时依赖；
  不要改成"移动单个高亮块"——切页瞬间组件尚未实例化，`find` 返回 nil，`set_pos` 不会报错也不会生效。
- 甘特与占用率是**定值**（真实产线应由 PLC 周期回传），当前只在总览页做了动态。
- 事件流三条时间是初始化时写入的，运行中新增事件会滚动替换。
- 曲线页需停留 30 秒以上才能填满窗口，切走再切回不会清空。
