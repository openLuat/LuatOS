# ReefOS 珊瑚礁生态缸大屏

Air8607（Air1603）+ 10.1 寸 RGB 1024×600 触摸屏的珊瑚礁生态缸监控面板。
整屏用 LuatOS `airui`（LVGL）纯 Lua 绘制：主界面是一口会呼吸的礁缸，水质、设备、光照、喂食全部可触摸操作。

## 硬件

| 项目 | 参数 |
|------|------|
| 主控 | Air8607（Air1603） |
| 屏幕 | 10.1 寸 RGB 1024×600（免序列） |
| 触摸 | GT911 电容触摸，I2C1，RST=GPIO14，INT=GPIO51 |
| 背光 | PWM3（GPIO13），默认 82% |
| 显示 | `exd_air8607_rgb.setup({ pin_rst = 15 })` |

## 四个页面

**主页（tank）**
- 生态缸动画：水色随光谱实时变化，光柱、沙床、珊瑚/海扇/海葵/海草随波摆动，3 条鱼巡游，气泡上升
- 底部 HUD 显示水温 / 盐度 / pH 三个核心读数，点击进入详情
- 6 个设备磁贴（主循环泵、造浪泵、蛋白分离、加热棒、冷水机、UV 杀菌），点击即开关，功率同步变化
- 日常维护：投喂（抬升营养盐）、RO 补水（盐度回 1.025）、换水 10%（降低 NO₃/PO₄）
- 水质 6 行：点击进详情页；状态点按 正常/偏离/超限 三档变色
- 光谱卡片：三色 LED 条 + 渐变预览，点击进光照页
- 环境卡：室温、湿度、累计电量；事件卡：最近 6 条事件

**参数详情（metric）**
- 最近 48 次采样趋势曲线，含正常区间带与网格
- 最低 / 平均 / 最高统计，10 分钟变化量
- 手动模拟滑块（锁定该参数）与「恢复自动」
- 双阈值滑块：越过软门限提示偏离，越过硬门限红色报警并写入事件
- 上一项 / 下一项在 8 项参数间循环

**光照（light）**
- 蓝 / 白 / UV 三通道 0~100% 滑块，LED 分段条实时跟随
- 5 套预设配方（晨曦 / 正午 / 黄昏 / 月光 / 荧光），点击即应用，当前配方高亮
- 混光预览：光晕圆球、总强度、灯具功率、蓝白比、UV 占比、可见光带示意
- 日夜节律：24 小时光照曲线 + 当前时刻游标 + 已开灯时长

**设置（settings）**
- 设备管理：逐台开关，顶部汇总开启数量与总功率
- 演示控制：暂停/恢复水质演化、补水、换水、投喂、重置演示数据
- 参数体检：8 项参数一屏总览
- 关于：固件版本、硬件平台、屏幕、缸体、开缸缸龄、模型运行时长

## 数据说明

项目**没有外接传感器**，所有数值由 `sim.lua` 的本地物理模型生成，但各参数之间保持真实因果：

- 蒸发让盐度缓慢上升，补水拉回 1.025；加热棒/冷水机决定水温走向
- 光照曲线驱动 pH 昼夜起伏，蛋白分离器与换水降低 NO₃/PO₄，投喂抬升
- KH、钙、镁随钙化消耗缓慢下降，换水小幅回补
- 每 1.2 秒采样一次，`conf.sim.min_per_tick` 让每次采样推进 3 个「水体分钟」，便于演示数小时内才该发生的漂移
- `conf.events` 会在特定时刻注入一次扰动（加热棒回差、蒸发未补水、过量投喂、滴定液见底），让演示有起伏

接入真实传感器时，只需把 `sim.tick()` 内的演化替换为采样写入 `sim.push(key, value)` 即可，UI 层无需改动。

## 关键实现约定

- **屏幕坐标以 px 绝对定位**，四张卡片都按 1024×600 手工排布（布局常量写在每个 `ui_*.lua` 顶部）
- **container 没有 `set_size`**，进度条统一用 `theme.segbar`（固定小方块，靠改颜色点亮）
- **slider 只接受整数**，小数参数用 `def.scale` 做定点换算（`sim.to_slider` / `sim.from_slider`）
- **hzfont 只按已加载字号出字**，`main.lua` 遍历 `theme.SZ`（12/14/16/20/26/40）逐个加载
- **页面切换即销毁重建**，每页返回 `{ refresh, destroy }`，`destroy` 置 `alive=false` 并停掉本页定时器
- 所有跨页组件操作都用 `pcall` 包裹，避免回调打到已销毁的 LVGL 对象

## 运行

把 `code/` 目录下的 lua 文件烧录到设备文件系统（保持同目录），重启后自动进入主页。
