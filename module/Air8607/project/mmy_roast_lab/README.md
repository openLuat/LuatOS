# ROAST LAB 咖啡烘焙工坊

Air8607（Air1603）+ 10.1 寸 RGB 1024×600 触摸屏的**智能曲线烘焙台**。
整屏用 LuatOS `airui`（LVGL9）纯 Lua 矢量绘制：一屏完成一炉咖啡的完整闭环——入豆、升温、一爆、出豆、冷却、评分、存档、曲线对比。

## 硬件

| 项目 | 参数 |
|------|------|
| 主控 | Air8607（Air1603） |
| 屏幕 | 10.1 寸 RGB 1024×600（免序列） |
| 触摸 | GT911 电容触摸，I2C1（400kHz），RST=GPIO14，INT=GPIO51，轮询模式 |
| 背光 | PWM3（GPIO13），默认 84% |
| 显示 | `exd_air8607_rgb.setup({ pin_rst = 15 })`，LCD 供电 GPIO17 |

## 四个页面

**主页（dash）**

- 顶栏：品牌标识、批次号 chip、模式 chip（待机 / 烘焙中 / 冷却中 / 完成）、时钟与日期、「豆单」「设置」入口
- 左列
  - 当前豆种卡：矢量豆形剪影、产地、处理法 · 海拔、风味描述、推荐出豆提示；整卡点按可换豆
  - 烘焙阶段卡：阶段轨道（脱水 / 梅纳 / 发展）按豆种一爆温度动态重建，当前阶段名 + 已用时间 + 阶段说明
  - 批次操作卡：入豆、出豆冷却、存曲线、重置、查看完整曲线
- 中列
  - 烘焙曲线卡（412×286）：豆温 BT / 炉温 ET 双曲线，含网格、阶段色带、回温 / 一爆 / 二爆标记与末端圆点；点按进详情
  - 烤炉控制卡：火力 / 风门 / 滚筒转速三条滑块，拖动立即写入模型
- 右列
  - 豆温环形表：当前豆温大字号读数 + 炉温 + ROR、预测烘焙度色阶与游标、距一爆 / 距二爆、实时评分
  - 烘焙事件：最近 4 条（带状态色点），可一键清空
  - 曲线档案：最近 3 条存档，点按切换对比曲线；再次点按取消

**曲线详情（curve）**

- 主图 900×186：BT / ET 双曲线 + 阶段色带 + 关键节点标记，可叠加历史批次对比曲线（横轴按时间对齐，不随采样点数拉伸）
- ROR 速率带 900×56：零轴、正负区间、网格
- 关键节点卡：回温点、一爆、二爆、出豆的温度与时刻
- 烘焙分析卡：评分、发展比、峰值 ROR、脱水结束时刻、总时长
- 实际操作卡：目标出豆温度滑块、「存为档案」、返回主页

**豆种档案（beans）**

- 6 款豆（耶加雪菲 / 瑰夏 / 哥伦比亚 / 巴西喜拉多 / 曼特宁 / 云南保山）3×2 卡片
- 每卡显示豆形剪影、产地、处理法 · 海拔、风味、一爆温度、推荐烘焙度与出豆区间、建议时长、推荐火力/风门/转速
- 点按即切换当前豆种，推荐参数自动套用到烤炉并复位批次，返回主页

**设置（settings）**

- 显示：背光亮度滑块，经 `pwm.setup` 对 PWM3 实时生效（不落盘）
- 报警与提示阈值：ROR 上限、炉温上限两个滑块，直接改 `conf.roast.hint`，主页提示同源生效
- 演示控制：暂停/继续推演、复位当前批次
- 关于：屏幕 / 触摸 / 采样周期 / 硬件平台 / 模型说明

## 操作流程

1. 主页点「豆单」选豆 → 推荐火力/风门/转速自动套用
2. 点「入豆」开始烘焙 → 30 秒内豆温下探，之后出现**回温点**
3. 拖动火力/风门/滚筒维持升温：火力升升温快、风门升炉温低但排烟好、转速过低升温抖动
4. 豆温到达该豆种一爆温度自动记录**一爆**，再升 24°C 记录**二爆**
5. 达到目标出豆温度时点「出豆冷却」→ 豆温向 36°C 收敛，评分与烘焙度定格
6. 冷却完成后点「存曲线」→ 写入右侧档案列表（保留最近 5 条）
7. 点档案条目 → 曲线详情页叠加对比；点曲线卡进入详情查看关键节点与分析

## 烘焙模型说明

`sim.lua` 不含任何外设依赖，数值由本地物理模型推演（每 500ms 采样一次，每次推进 6 秒烘焙时间，约 12 倍速）：

- **炉温 ET**：`target = clamp(38 + 火力×2.36 − 风门×0.30 + 滚筒×0.03 − 入豆冲击, 30, 272)`，一阶惯性逼近（系数 0.10）；入豆冲击 `74·e^(−t/150)` 模拟冷豆吸热
- **豆温 BT**：`rise = (ET − BT) × k`，`k = 0.030 × (0.80 + 风门/180) × (0.66 + 火力/200) × (0.90 + 滚筒/420)`；入豆后 30 秒内额外 −5.2，滚筒低于 35rpm 时叠加随机抖动
- **ROR**：`ΔBT / 6s × 60`，即 °C/min
- **阶段**：脱水 25~150°C、梅纳 150~一爆、发展 一爆~262°C，一爆点由豆种 `crack` 决定
- **事件**：回温点、进入梅纳、一爆、二爆、出豆、冷却完成、参数预警（升温过快 / 炉温偏高 / 排风不足 / 火力过低 / 发展过深）
- **评分**：以推荐出豆中值为基准 `100 − |出豆温 − 中值| × 2.6`，发展不足（< 6°C）或过深（> 32°C）再扣分，结果收敛在 40~99
- **存档对比**：未存过的预置档案按指数曲线合成历史 BT（`26 + (出豆温−26)·(1−e^(−3.1t))/(1−e^(−3.1))`），存过的直接用真实采样

接入真实烘焙机温度采集时，只需把 `sim.tick()` 内的推演替换为写入 `S.bt` / `S.et` 即可，UI 层无需改动。

## 关键实现约定

- **绝对像素布局**：四张页面全部按 1024×600 手工排布，几何常量写在每个 `ui_*.lua` 顶部
- **shape 没有 `set_color`**：曲线、表盘、阶段轨道改色一律 `set_items` 重建；`label` 支持 `set_text` / `set_color`
- **container 没有 `set_size`**：进度类指示用分段色块（`theme.segbar`）或重建容器
- **hzfont 只按已加载字号出字**：`main.lua` 遍历 `theme.SZ`（12/14/16/20/26/40）全部载入
- **单循环驱动**：`app.start()` 起一个 `timerLoopStart`，每拍 `sim.tick()` 再调用当前页 `refresh()`；页面自己不起定时器，避免销毁后回调打到已销毁对象
- **页面切换即销毁重建**：每页返回 `{ refresh, refresh_clock, destroy }`，`destroy` 置 `alive = false`
- **触摸先于界面**：GT911 初始化必须在 I2C 空闲时完成，UI 先跑起来会抢总线导致「屏幕正常但点不动」
- 所有跨页组件操作都用 `pcall` 包裹

## 运行

把 `code/` 下的全部 lua 文件烧录到设备文件系统（保持同目录），重启后自动进入主页。
