# SkyLift 雪山索道运营大屏

Air8607（Air1603）+ 10.1 寸 RGB 1024×600 触摸屏的滑雪场索道运营监控面板。
整屏用 LuatOS `airui`（LVGL）纯 Lua 绘制：主页是一条会动的索道，缆车沿钢绳巡航、雪粒飘落、造雪机喷雪，运力、雪况、气象、设备全部可触摸操作。

## 硬件

| 项目 | 参数 |
|------|------|
| 主控 | Air8607（Air1603） |
| 屏幕 | 10.1 寸 RGB 1024×600（免序列） |
| 触摸 | GT911 电容触摸，I2C1，RST=GPIO14，INT=GPIO51 |
| 背光 | PWM3（GPIO13），默认 80% |
| 显示 | `exd_air8607_rgb.setup({ pin_rst = 15 })` |

## 四个页面

**主页（lift）**
- 索道剖面动画：两座站房、钢绳、5 台缆车来回巡航，缆车到站会减速停顿，雪粒持续飘落
- 天空与山体亮度随「当前时刻 + 天气」变化，夜间自动转极光配色
- 4 个 KPI：索道速度、运力（人/小时）、平均雪深、在线缆车
- 3 条线路状态（A 主索道 / B 中级道 / C 魔毯）：运行状态、载客率、车厢数徽标
- 气象卡：气温、风速、能见度、湿度 + 体感与停运风险提示
- 6 个设备磁贴：主驱动、备用电机、造雪机、除冰加热、夜间照明、广播
- 事件卡：最近 7 条运行事件，按等级着色

**线路（line）**
- 索道纵剖面：上/下站、14 座支架塔、当前车厢位置、坡段色带
- 目标速度滑块（0~6.0 m/s），实际速度带惯性跟随，超风速自动降速
- 上下行发车间隔、单程时间、当前运力、今日运送人次
- 钢绳张力与电机电流趋势曲线
- 支架塔列表：编号、海拔、倾角、状态点

**雪况（snow）**
- 4 条雪道（新手 / 中级 / 高级 / 越野）：雪深条 + 目标雪深、开放状态、压雪时间
- 3 台造雪机：开关、喷嘴开度滑块、单台产雪量
- 气象窗口：干球 / 湿球 / 相对湿度，判断是否具备造雪条件
- 24 小时雪深趋势曲线 + 今日补雪量
- 一键压雪：平整雪面并提升雪道等级

**设置（settings）**
- 显示与背光：亮度滑块（10~100%）直接写 PWM3 占空比，另有夜间/标准/明亮三档预设
- 演示模型：暂停/恢复、重置数据、一键压雪，实时显示仿真时长、采样次数、累计事件
- 机械体检：主电机温度、减速机油压、钢绳张力、制动间隙、液压油温，按 lo/hi/dlo/dhi 分级着色
- 系统信息：分辨率、显示驱动、触摸、字库档位、固件版本、运行时长、系统内存
- 站点档案：雪场名称与位置、上站海拔、垂直落差、索道/雪道/造雪机规模、开业时间

## 数据说明

项目**没有外接传感器**，所有数值由 `sim.lua` 的本地运行模型生成，但各参数之间保持真实因果：

- 主驱动决定实际速度；风速超过 12 m/s 自动降速，超过 18 m/s 触发停运事件
- 运力 = 速度 × 车厢数 × 每厢座位 / 站间间隔，排队人数由到客率累积、由运力消化
- 造雪需要湿球温度低于 -2 ℃，否则造雪机空转；产雪量抬升对应雪道雪深，气温回升会缓慢融雪
- 压雪把雪深回补到目标值并降低雪面粗糙度，雪道等级随之变化
- 每 1 秒采样一次，`conf.sim.min_per_tick` 让每次采样推进 2 个「雪场分钟」，便于演示数小时的漂移
- `conf.events` 会在特定时刻注入阵风、客流高峰、造雪机缺水等扰动，让演示有起伏

接入真实传感器时，把 `sim.tick()` 内的演化替换为采样写入 `sim.push(key, value)` 即可，UI 层无需改动。

## 关键实现约定

- **屏幕坐标以 px 绝对定位**，四张页面都按 1024×600 手工排布（布局常量写在每个 `ui_*.lua` 顶部）
- **container 没有 `set_size`**，进度条统一用 `theme.segbar`（固定小方块，靠改颜色点亮）
- **slider 只接受整数**，速度 5.0 m/s 用 `×10` 定点换算
- **hzfont 只按已加载字号出字**，`main.lua` 遍历 `theme.SZ`（12/14/16/20/26/40）逐个加载
- **页面切换即销毁重建**，每页返回 `{ refresh, destroy }`，`destroy` 置 `alive=false`
- 所有跨页组件操作都用 `pcall` 包裹，避免回调打到已销毁的 LVGL 对象
- **页面模块必须用字面量 `require`**：PC 模拟器默认开启依赖裁剪（`bsp/pc/port/luat_cmds.c` 的 `cfg_dep_strip`），
  只把 `main.lua` 静态可达的文件打进 luadb。`app.lua` 的 `PAGE_LOADERS` 就是为此保留的字面量登记表，
  改成 `require(route.module)` 这种变量形式会让 `ui_*.lua` 被剔除，运行时报 `module 'ui_lift' not found`

## 运行

把 `code/` 目录下的 lua 文件烧录到设备文件系统（保持同目录），重启后自动进入主页。
