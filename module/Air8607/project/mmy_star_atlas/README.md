# 星野观测台 Star Atlas

> 一块 10.1 寸竖屏，一整个可以随手“拨动”的星空。

`mmy_star_atlas` 是运行在 **Air8607**（Air1603 核心板 + 1024×600 RGB 屏 + GT911 电容触摸）上的
LuatOS / AirUI 演示项目：它不显示仪表盘，而是把一整片夜空画出来——
只要拖动时间流速，星座就会在屏幕上真实地东升西落。

核心思路：**用一个可以加速的天文时钟驱动全部界面**。
所有数字（高度角、方位角、升起 / 中天 / 落下、暮光、月相、曝光建议）都由同一个
仿真时间戳实时算出，因此加速 300 倍后，你能在一分钟内看完一整夜的星移。

---

## 1. 功能一览

### 星图（Sky）
- 方位等距投影全天星图（天顶在圆心，外圈为地平线），内置约 120 颗亮星（含拜耳名、星等、色指数）
- 星等决定点径与亮度，色指数决定色温；接近地平线的恒星做消光压暗
- 约 100 条星座连线 + 30 点银河带 + 14 个深空天体（M31/M42/M45/M13…）
- 太阳与月亮实时位置，月亮带相位盈亏（逐列绘制明暗界线），日出日落前压暗天空
- 右侧「今夜观测条件」：观测指数、24 段整夜条件电平表、云量 / 视宁 / 透明度、月相与月龄
- 「此刻最值得看的目标」：按高度角排序推荐，点击进入详情
- 时间流速 1× / 60× / 300× / 1800× / 7200×，可暂停、可夜视
- 点击任意星点或深空天体进入详情；点空白处播报该方位的坐标（赤经赤纬、方位高度）

### 天体详情（Object）
- 基本信息：星等、赤经赤纬、所属星座 / 天体类型、视面大小
- 此刻状态：大号高度角 + 罗盘指针、最高高度、中天时刻、升起 / 落下
- 12 小时高度轨迹曲线（分段着色 + 柔光竖线填充 + 当前时刻游标，时间窗每 30 分钟自动滚动）
- 未来 24 小时可见窗口（34 段），已在视野中时直接给出“可观测至几点”
- 一键加入今晚观测队列

### 观测计划（Session）
- 12 小时时间轴（当地 18:00 起）：三级暮光渐变、整点网格、当前时刻指针
- 队列目标以“可见窗口色块”排列在各自的轨道上，一眼看出目标是否撞车
- 队列最多 6 条，可点开详情、可移除
- 曝光计算器：焦距 / 口径 / ISO 三根滑条 → 500 法则极限曝光、是否拖线、是否需要跟踪

### 设置（Settings）
- 站点经纬度（0.1° 步进）+ 5 个预设观测地：冷湖 / 阿里 / 兴隆 / 丽江 / 稻城
- 星等极限（1.0 ~ 5.0）实时影响星图显示密度
- 屏幕背光亮度（PWM 实时调光）
- 星座连线、夜视模式开关
- 仿真时间重置为当地 20:00

### 全局
- 顶部信息栏：项目名、当前站点、仿真时钟、观测地经纬度
- 左侧导航：星图 / 计划 / 设置
- 底部 Toast 提示（点星空白处、加入队列等操作反馈）
- **夜视模式**：整屏光谱收敛为暗红，保护暗适应（可随时切换）

## 2. 目录结构

```
mmy_star_atlas/
├── README.md
└── code/
    ├── main.lua              # 启动入口：供电 → 显示 → airui → 页面 → 触摸 → 背光
    ├── conf.lua              # 屏幕、站点、字体、背光、时间流速等配置
    ├── theme.lua             # 调色板 + 控件封装（label/button/card/slider/分隔线/条带）+ 夜视染色
    ├── app.lua               # 应用框架：页面路由、仿真时钟、全局状态、Toast、导航、顶栏
    ├── astro.lua             # 天文计算：儒略日/恒星时、赤道↔地平、投影、日月位置、升落、暮光、格式化
    ├── star_data.lua         # 星表（星点/星座连线/深空天体/银河带/星座中文名）
    ├── exd_air8607_rgb.lua   # RGB 屏显示 IC 初始化扩展库
    ├── ui_sky.lua            # 星图页
    ├── ui_object.lua         # 天体详情页
    ├── ui_session.lua        # 观测计划页
    └── ui_settings.lua       # 设置页
```

### 分层关系

```
main.lua
  └── app.lua（唯一单例：st 状态 / 路由 go() / 时钟 / 200ms tick 分发）
        ├── ui_sky / ui_object / ui_session / ui_settings   （页面工厂，返回 {root,tick,touch,arg}）
        ├── astro.lua      （纯函数，无 UI 依赖）
        ├── star_data.lua  （纯数据）
        └── theme.lua      （所有控件都从这里创建，颜色统一过 tint() 做夜视）
```

页面工厂约定：`page(root, arg)` 返回 `page` 表，`app` 在 200ms 定时器里调用
`page.tick()`，触摸事件经 `airui.touch_subscribe` 转发给 `page.touch(state,x,y)`。
切换页面时 `app` 直接销毁旧页面根容器，页面内部无需做清理。

## 3. 硬件与引脚

| 功能 | 配置 |
| --- | --- |
| 屏幕 | 1024×600 RGB，`exd.setup{pin_rst = 15}` |
| 屏幕供电 | GPIO17（低有效） |
| 背光 | PWM3，1kHz，占空比即亮度百分比 |
| 触摸 | GT911，I2C1 @400kHz，`pin_rst = 14`，`pin_int = 51`，下降沿中断 |
| 中文字体 | `airui.font_load{type = "hzfont", size = 16}` |

引脚定义与 `module/Air8607/project/factory/config/eng_8607_10i_v0.lua` 保持一致。

## 4. 运行方式

1. 用 LuatOS 工具链打开 `module/Air8607/project/mmy_star_atlas`，将 `code/` 下的脚本下载到设备；
2. 若在电脑上调试，可把 `code/` 目录作为脚本目录喂给 `luatos-lua.exe`（需要 airui/PC 模拟器支持）；
3. 上电后自动初始化显示与触摸，进入星图页。默认站点为青海冷湖（38.6°N, 93.4°E，Bortle 2），
   仿真时间从当地 20:00 开始、以 300× 流动。

**建议的演示动线**：星图页把流速调到 1800× 看星座升起 → 点一颗亮星看高度轨迹 →
加入队列 → 去“计划”页看时间轴上的可见窗口和曝光建议 → 打开夜视模式再回星图。

## 5. 算法说明

- **时间**：由本地时间构造 Unix 时间戳 → 儒略日 JD → GMST → 地方恒星时 LST，所有天体位置都基于 LST 计算。
- **赤道↔地平**：标准球面三角公式，输出高度角 alt 与方位角 az（北起顺时针）。
- **投影**：方位等距投影 `r = (90 - alt) / 90 * R`，以天顶为圆心，便于直观读取“离天顶多远”。
- **太阳 / 月亮**：低精度解析式（太阳黄经 + 月亮平黄经/交点项），月相由日月黄经差得到照亮比例与月龄，
  精度足够做界面展示（误差数角分到数度）。
- **升落 / 中天**：以 5 分钟步长扫描 24 小时高度曲线做线性插值，得到升起、落下与中天时刻。
- **暮光**：分别对太阳高度 −6° / −12° / −18° 做上升与下降扫描，得到民用 / 航海 / 天文暮光的起止。
- **观测指数**：由月相亮度、目标高度、云量、视宁度、透明度加权，云量与视宁度用平滑伪随机模拟，
  这样界面上的“今夜条件”会随时间缓慢变化，不是一张死数据。
- **曝光**：500 法则 `t = 500 / (焦距 × 裁切系数)`，再按口径给出是否建议跟踪。

## 6. 已知取舍

- 星表是内置的亮星子集（约 120 颗），不是完整星表；深空天体只放了 14 个经典目标。
- 日月位置用低精度解析式，做教学演示足够，不可用于精确指向。
- 云量 / 视宁度 / 透明度为模拟值（无气象数据源），用于表现“条件在变”。
- 仿真时间只存在内存中，重启复位到 20:00。
- 时间流速 7200× 时，细节抖动会明显加快，属正常现象。
