# HELIOS-1 逐日一号 · 聚变放电控制台

Air8607（Air1603）+ 10.1 寸 RGB 1024×600 触摸屏的托卡马克聚变实验装置中控大屏。
整屏用 LuatOS `airui`（LVGL 9）纯 Lua 绘制：主页是一只悬浮的环形真空室，等离子体随放电阶段呼吸、粒子沿环向流动；
放电页有实时电流/加热波形，磁约束页有极向截面与磁扰动频谱瀑布，低温页有氦回路流动示意。

装置为虚构演示对象，全部数据由 `code/sim.lua` 的本地模型演化，不接真实传感器。

## 硬件

| 项目 | 参数 |
|------|------|
| 主控 | Air8607（Air1603） |
| 屏幕 | 10.1 寸 RGB 1024×600（免序列） |
| 触摸 | GT911 电容触摸，I2C1，RST=GPIO14，INT=GPIO51 |
| 背光 | PWM3（GPIO13），默认 82% |
| 显示 | `exd_air8607_rgb.setup({ pin_rst = 15 })` |

## 五个页面

**总览（overview）**
- 环形真空室 3/4 视图：金属环体由 30 圈同轴椭圆叠出柱面明暗，等离子体带按电流强度呼吸，12 颗粒子沿环向流动
- 右侧读数：等离子体电流（40 号大字）、电子温度、电子密度、聚变功率，附 Q 与 H98 胶囊
- 4 个 KPI：环向磁场、储能、能量增益 Q、约束因子 H98
- 放电时序：7 段进度条（抽真空 / 预电离 / 爬升 / 平顶 / 加热 / 下降 / 复位），当前段实时推进，附启动与终止按钮
- 子系统：8 个磁贴（环向场、极向场、NBI、ECRH、ICRH、低温、真空、偏滤器水冷），点按即投切
- 磁约束摘要：拉长比、三角形变、q95、βN，底部破裂风险条
- 运行事件：最近 5 条，按等级着色

**放电（shot）**
- 双轴波形：粉色为等离子体电流（0~2 MA），珊瑚为辅助加热总功率（0~30 MW），底纹按阶段着色
- 阶段推进表：7 段的时长、进度、完成状态
- 辅助加热：NBI / ECRH / ICRH 三路功率与开关，点按磁贴投切
- Q 环表：环形表显示 Q，右侧给出聚变功率、辅助加热、增益余量
- 控制：目标电流滑块（0.60~2.00 MA）、加热总功率滑块（5~30 MW）、终止放电、下一炮

**磁约束（magnetic）**
- 极向截面：D 形真空室、三道磁面、等离子体边界、中心螺线管、6 组 PF 线圈、偏滤器 X 点
- PF 线圈电流：以中线为零点的双向条，电流随位形反馈摆动
- 平衡参数：κ、δ、q95、βN、储能、内感、Zeff、n/nGW
- 磁扰动频谱：26×6 的瀑布图，每 2 秒推进一列，红色越深幅值越强
- 破裂预警：大号风险百分比 + 密度极限/MHD/锁模三项贡献 + RMP 投入按钮

**低温真空（cryo）**
- 氦回路：压缩机站 → 冷箱 → JT 阀 → 冷屏/磁体，供气与回流双管路，粒子沿管流动
- 温度梯度：4.5 K / 80 K / 冷泵 / 室温支撑四支温度计
- 液氦库存：液位条、补液阈值刻度、日蒸发率，氦气再生按钮
- 真空系统：真空室压力（科学计数法）、漏率、中性束注入器真空、RGA 五组分、冷泵状态

**系统（settings）**
- 显示与背光：亮度滑块直接写 PWM3，另有夜间 / 标准 / 明亮三档
- 演示模型：采样次数、仿真时长、事件条数，暂停 / 恢复、重置数据
- 系统信息：分辨率、显示驱动、触摸、字库、固件、运行时长、Lua 内存
- 设备体检：6 项按 lo / hi 分级着色，超出 dhi / dlo 转红
- 装置档案：名称、地点、R0/a/Bt、体积、第一壁、投运时间、累计放电

## 数据说明

所有参数由同一个状态机演化，彼此保持因果，而不是各自随机：

- 放电分 7 段，共 60 个采样；`conf.sim.clock_step = 30` 让每次采样推进 30 秒装置时间，一炮约 30 分钟
- 等离子体电流按 0.22 MA/拍的速率跟随目标曲线，环向场随电流建立
- 聚变功率 `Pfus ≈ 66 × ((Te-2.2)/6.2)^1.85 × (ne/4.15)^0.85 × (Ip/Ip_target)^1.1`，Q = Pfus / Paux
- 辅助加热掉线时可用功率下降，温度目标同比下调，Q 随之跌落
- ELM 每 9 秒来一次锯齿，抬高 MHD 幅值；风险 = 密度项 + MHD 项 + 子系统惩罚
- 低温：压缩机负荷越低，4.5 K 与 80 K 冷屏温度越高；液氦以 0.05%/拍消耗，低于 30% 自动补液
- 真空：泵组停机后压力按 1.55×/拍指数上升
- `conf.events` 在第 26 / 88 / 100 / 155 / 176 拍注入事件：第 100 拍把 1 号中性束降功率，第 176 拍检修恢复，用于演示子系统掉线与恢复的连锁反应

接入真实采集时，把 `evolve()` 里的目标值换成实测写入 `M.push(key, value)` 即可，UI 层无需改动。

## 降载策略

总览页原先每秒要写近 110 次 UI（文本 + 颜色 + 进度条），单帧容易超过 110 ms 的采样周期，
把 SoC 的静态事件池顶满，出现 `soc_send_event_to_task ... no free static event` 告警。现在的做法：

- **值不变不写**：`st / sc / sb` 三个缓存分别拦截文本、颜色、进度条，实测每秒 UI 写入降到约 12 次
- **分时刷新**：真空室读数与时序每秒刷，KPI / 子系统 / 磁约束隔秒刷；按钮操作走 `refresh(true)` 全量刷
- **事件列表按签名跳过**：没有新事件时不动那 20 个标签
- **等离子体带量化到 1/6 档**：跨档才重建 12 个椭圆，避免连续调功率时反复分配对象
- **粒子 5 fps**：轨道很慢，没必要每帧刷 12 个对象
- **波形节点 6 px 一段**：图元数量比 4 px 少四成，视觉上仍是连续曲线

`conf.debug.profile = true` 会在日志里每 10 秒输出一行 `[prof] 10s 帧耗时 avg / max / refresh max`，
单帧超过 90 ms 时另有一条告警。定位完成后改成 `false` 即可关闭，关闭时零开销。

## 关键实现约定

- **屏幕坐标以 px 绝对定位**，五张页面都按 1024×600 手工排布，布局常量写在每个 `ui_*.lua` 顶部
- **container 没有 `set_size`**，进度条统一用 `airui.bar`（原生控件，支持 `set_value`），刻度类用 `theme.segbar`
- **slider 只接受整数**，目标电流用 `×100` 定点换算
- **hzfont 只按已加载字号出字**，`main.lua` 遍历 `theme.SZ`（12/14/16/20/26/40）逐个加载
- **页面切换即销毁重建**，每页返回 `{ refresh, slow, frame, destroy }`，`destroy` 置 `alive=false`
- **页面模块必须用字面量 `require`**：PC 模拟器默认开启依赖裁剪，`app.lua` 的 `PAGE_LOADERS` 是给静态分析的登记表
- **字形避坑**：GB2312 子集缺 `·`、`³`、`²`、`µ`、`—`，工程内统一改用 `，`、`m3`、`m2`、`μ`（希腊 μ）
- **Lua 5.4 的 `%d` 不接受浮点**，凡进 `%d` 的量先过 `theme.n()`；`dec = 0` 的体检项统一用 `%.0f`
- **轻提示最后创建**：LVGL 后创建的对象在上层，先建会被内容区盖住
- 所有跨页组件操作都用 `pcall` 包裹，避免回调打到已销毁的 LVGL 对象

## 运行

把 `code/` 目录下的 lua 文件烧录到设备文件系统（保持同目录），重启后自动进入总览页。
