# mmy_wind_farm · 北岭风电场集控中枢

> Air8607 + 10 寸 1024x600 RGB 屏 + GT911 触摸的常亮型大屏看板。
> 12 台风机、75MW 装机的陆上风电场，中控室墙上的那一块。

---

## 它回答什么

一块风电场大屏不该只是"把数字排整齐"。值班的人真正会盯着看的是四件事：

| 问题 | 屏幕上对应的地方 |
| --- | --- |
| 现在发多少？离满发还差多远？ | KPI 第一块 + 今日功率曲线（含 75MW 装机参考线） |
| 哪几台没在转？为什么？ | 机组阵列（转子停转 + 砖块染色 + 状态点） |
| 风从哪来？这个场站什么时候来风？ | 风向玫瑰（瓣长 = 出现频率，瓣色 = 该方位平均风速） |
| 刚才发生了什么，还有谁没确认？ | 运行事件流（最新 4 条，点一下确认） |

## 交互

| 操作 | 结果 |
| --- | --- |
| 点机组砖块 | 选中，底部一行显示该机的风速 / 转速 / 桨距 / 齿轮箱温度 |
| 再点同一块 | 运行机 → 检修挂牌停机；故障机 → 人工复位并网（同时播报） |
| 点右上 AGC 胶囊 | 模拟调度下发限电（压到 62% 装机），再点解除；出力分布当场变暗 |
| 点事件行 | 确认该条事件（变色但不消失，留痕给人回看） |
| 点"全部确认" | 一次清掉所有未确认事件 |
| 点右下角喇叭 | 语音开 / 关；PC 模拟器上会显示"无语音（真机可用）" |
| 12 秒无操作 | 自动轮播选中机组，适合无人值守的墙上看板 |

## 数据模型（接真实采集只看这一节）

界面只读下面这些字段，**不自己算功率**。接 SCADA / Modbus / IEC104 / MQTT 网关时，
按同样字段往里写值即可，`dashboard.lua` 一行都不用改：

```lua
data.turbines[i] = {
    name = "WT-07", short = "07",
    power = 5.82,   -- 有功 MW
    wind  = 9.4,    -- 轮毂风速 m/s（已含尾流折减的用 weff）
    weff  = 8.7,    -- 尾流折减后的有效风速
    rpm   = 13.2, pitch = 3.1, temp = 62,
    status = 0,     -- 0 发电 / 1 待风 / 2 故障 / 3 检修停机
}

data.state = { wind = 8.4, dir = 315, power = 48.6, avail = 98.6,
               curt = false, curtail_limit = 0, hour = 9.43, online = 12 }
data.today = { mwh = 512.8, peak = 62.1, loss = 4.2, faults = 1 }
data.hist  = { meas = {...96 点...}, fcst = {...96 点...} }   -- MW
data.rose  = { freq = {...16 方位...}, spd = {...} }
data.events[1] = { t = "09:12", level = 3, text = "WT-05 变桨系统故障停机" }
```

## 物理模型（演示数据怎么来的）

- **风速**：基值 + 天气尺度正弦（凌晨起风、午后回落）+ 小时尺度 + 湍流尺度，
  60 倍速下一分钟走一小时，曲线是"会呼吸"的，不是随机噪声。
- **尾流**：把 12 个机位投影到气流方向上，数一数上游挡了几台，按 7.5%/台 折减，
  单机最多 30%。**风向一转，阵列里下风向那两列立刻变暗** —— 这是整块屏信息量最大的细节。
- **功率曲线**：切入 3 m/s、额定 11.5 m/s、切出 25 m/s，中间三次方上升。
- **限电**：调度给上限，超出部分按比例压到每台机，同时累计"限电损失"MWh。
- **事件流**：只记状态边沿（故障、复机、限电、解限、阵风），不按定时刷屏。
- **随机数用固定种子**：每次开机现象一致，方便截图与复现问题。

## 性能取舍

10 寸 RGB 屏没有 GPU，一次全屏就是 61 万像素，所以只重画真正在变的那块：

| 区域 | 周期 | 理由 |
| --- | --- | --- |
| 机组阵列 | 120ms | 转子在转，人眼最敏感；转子角度按真实时间推进，与 60x 仿真倍率无关 |
| 文字 | 250ms | 内容不变不 `set_text`，否则每秒上千次重排 |
| 事件流 | 500ms | 只在事件变化时有意义 |
| 功率曲线 / 风向玫瑰 | 1s | 功率和风向都是慢变量 |
| 背景 / 卡片 / 标题 | 开机一次 | 静态层不进每帧预算 |

## 上机

1. 整份 `code/` 直接作为 Air8607 工程的 script 目录；
2. 屏幕分辨率改 `theme.screen` 与 `app_main.lua` 里的 `SCREEN_W/SCREEN_H`；
3. 触摸引脚（`pin_rst = 14`、`pin_int = 51`）按实际板子改 `app_main.touch_init()`；
4. 没有 DAC 功放时把 `theme.audio.pa_ctrl` 置 nil，语音会自动降级为静音，
   面板右下角会标出"语音不可用"，不会影响主流程。

## 已知限制

- 界面文本只用 ASCII + 汉字：`hzfont` 矢量字库没有 `°`、`·`、`→` 这类符号，用了会显示方框，
  所以方位写 `NW`、单位写 `m/s`、温度写 `62C`。
- 机组砖块是画在 `shape` 上的图元，不是独立控件，所以没有"按钮按下态"，
  选中态用四角括号表达。
- 数据是本地仿真。接真机时建议把 `wind_data.tick()` 的仿真段整体替换为
  "读缓存 + 计算派生指标"，`settle()` 保留（限电分配和统计仍然有用）。
