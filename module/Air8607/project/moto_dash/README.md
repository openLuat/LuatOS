# MOTO DASH 两轮车仪表盘（Air8607 + 10 寸 1024x600）

全屏仪表盘演示：大号速度表 + 电量 / 功率 / 里程 / 速度趋势四张卡 + 骑行模式切换。
**零图片素材**，指针、进度弧、刻度、电池条、折线全部由 `airui.shape` 的
`line / circle / rect` 图元实时绘制。

---

## 画面

```
┌──────────────────────────────────────────────────────────────┐
│ ←  近光            12:48            远光  →                  │  顶栏：转向灯 / 灯光 / 时钟
├───────────┬──────────────────────────────────┬───────────────┤
│  电量     │                                  │  功率         │
│  78%      │            0 - 160               │  2.4 kW       │
│  ▮▮▮▮▮▮▯▯ │         ╭──────────╮             │  输出 ▮▮▮ 回收 │
│  续航 86  │        │   指针+弧  │            │  电机 42 C    │
├───────────┤         ╰──────────╯             ├───────────────┤
│  里程     │          km/h   D                 │  速度趋势     │
│  12345.6  │                                  │  ╱╲╱╲╱        │
│  TRIP/AVG │                                  │  MAX / AVG    │
├───────────┴──────────────────────────────────┴───────────────┤
│              [ ECO ]   [ NORMAL ]   [ SPORT ]                │
└──────────────────────────────────────────────────────────────┘
```

- **速度表**：半径 196，扫角 150°~390°（240°），0~160 km/h。
  小刻度每 4 一根、大刻度每 20 一根带数字，140 以上是红线区（接近时会闪烁）。
  进度弧 + 弧头光点 + 实体指针（光晕/灯芯/尾配重三笔）+ 中心轴盖。
- **表内彗尾**：两条彗尾在半径 143 的环带上追光，角速度跟车速联动；
  静止时透明度归零（不画图元），怠速零开销。
- **四张卡**：电量 20 段电池条 + 续航；里程 ODO/TRIP/AVG；功率双向条
  （右红=输出，左绿=回收）；速度趋势 60 格迷你折线（约 24 秒历史）。
- **骑行模式**：ECO / NORMAL / SPORT 三档，切换同时改**强调色**（绿/青/橙）、
  最高速（60/110/160）和加减速度，切换瞬间打一圈涟漪，颜色是逐帧插值不是硬切。

## 交互

| 操作 | 效果 |
|---|---|
| **无操作 3 秒后** | 自动进入**演示巡游**：24 秒一个循环，起步 → 巡航（正弦 + 噪声起伏）→ 停车 → 再起步，指针、数字、功率条、趋势线全程在动 |
| 按住表盘区域 | 手动驾驶：速度按当前模式加速度冲到本档极速，功率/温度/掉电速度全部联动 |
| 松开 | 滑行减速（功率条转绿色回收），3 秒后自动恢复巡游 |
| 点 ECO / NORMAL / SPORT | 切换骑行模式：强调色、最高速（60/110/160）、加减速度同时变，巡游幅度随之变大变小 |
| 点顶栏四个热区 | 左转向 / 近光 / 远光 / 右转向；转向灯 1.25Hz 闪烁 |

上电后有 **1.5 秒自检动画**：指针 0→160→0 扫一圈，指示灯全亮，
和真车 key-on 的灯检动作一致；自检期间不计里程、不采样趋势，结束后直接进入巡游。

> 为什么要"自动巡游"：真机演示时没人会一直按着屏幕，表针停在 0 会让整个界面
> 看起来像死机。巡游的所有幅度都按当前档位的 `vmax` 缩放，所以点模式键
> 立刻能看到表针幅度的变化 —— 这就是点按钮的直观反馈。

## 运行

把全部 .lua 与 3 张素材图 **平铺**加入脚本区，入口 `main.lua`（`PROJECT = "moto_dash"`）。
引脚与 `factory/config/eng_8607_10i_v0.lua` 一致：

```
LCD 复位 pin_rst = 15      LCD 供电 pin_pwr = 17
背光 PWM3 (GPIO13)         GT911: I2C1 400kHz, pin_rst = 14, pin_int = 51
```

串口看到 `MOTO DASH 已就绪` + `自检完成` 即进入骑行态，
之后每 5 秒打印一次 `speed=.. items=..`（当前车速与动态图元数）。

## 实现要点

### 图元预算

| 层 | 刷新率 | 图元数 |
|---|---|---|
| 静态层（刻度 / 轨道 / 内外环 / 分隔线） | 只画一次 | 94 |
| 动态层（进度弧 / 红线 / 指针 / 彗尾 / 指示灯） | 30fps | 59~94 |
| 四张卡（电池条 / 双向功率条 / 折线） | 10Hz | 约 60 |

动态层只重绘"会动的东西"，刻度盘这类一成不变的内容放在独立 shape 里建一次，
省下来的图元预算全给了指针和弧线。

### 时间基准与节拍

- 毫秒换算走 `mcu.hz()`：Air8607 主控约 20ms/tick，PC 模拟器 1ms/tick，
  直接把 tick 当毫秒会让动画慢 20 倍。
- **动画步长用固定 30ms**：tick 分辨率比帧间隔还粗，拿 tick 差当 `dt` 会得到
  20/40ms 的抖动值，指针会"顿"。实测被挂起超过 3 帧才按真实时间补跳。
- `sys.wait(n)` 是"至少睡 n 毫秒"，主循环按实测耗时补偿：`wait = 30 - cost`。

### 四条踩过的坑

1. **整型参数**：`set_pos` / `set_color` 在 C 层是 `luaL_checkinteger`，
   传小数会抛 `number has no integer representation` 并**直接退出 Lua VM**。
   而图元字段走的是 `lua_tointeger`——小数会被**静默转成 0**（宽度变 0、
   透明度变 0，物件"凭空消失"）。所以 `fx.pool` 里所有整型字段都过 `fx.int()` 取整，
   外部 `set_pos` 一律先 `math.floor`。
2. **字体缺字**：hzfont 里没有中间点（·）、度数（°）这类符号，用了显示方框。
   本工程界面文本只用 ASCII + 汉字，温度写 `42 C`、单位写 `km/h`。
3. **卡片/按钮一律不用 container**（真机两轮暴露的坑）：
   `container` 就是 `lv_obj_create`，**默认带 `LV_OBJ_FLAG_SCROLLABLE`**。
   只要所有子对象的包围盒超出内容区一点点（border 1px、字体行高比给的高 1px、
   以后多加一个字符……），LVGL 就按 AUTO 模式在右/下画**滚动条**——
   真机上看到的就是"卡片里多一圈方角细框、按钮文字下面多一条横线"。
   靠"把子对象缩 1px"去凑只能保证这一次，属于随时复发的坑。

   现在的做法：卡片和模式键的宿主对象直接用 `airui.shape`
   （C 层对它硬编码了 `lv_obj_remove_flag(shape, LV_OBJ_FLAG_SCROLLABLE)`），
   底板（圆角填充 + 描边 + 顶部高光 + 左侧色条）本身也用图元画，
   和条/折线一起在同一个 10Hz 刷新里重绘；文字作为 shape 的子对象挂在上面。
   结构上就不存在"滚动条"这个可能。
   注意 `P:box` 的宽高要 -1：C 层用的是 `x2 = x + w`（含端点），不减会被图层裁掉 1px 描边。
4. **几何出界**：表盘半径和圆心必须满足
   `cy + R < 516`（底部分隔线）且 `cx ± R ⊂ (292, 732)`（左右卡片之间），
   否则圆环会压到卡片或分隔线上。改 `theme.dial` 的三个数就能整体缩放。

## 调优旋钮

| 位置 | 参数 | 作用 |
|---|---|---|
| `theme.lua` | `perf.frame_ms` | 主循环节拍，30=约 33fps；吃力改 40 或 50，动作速度不变 |
| `theme.lua` | `perf.card_ms` | 卡片刷新间隔，默认 100（10Hz） |
| `theme.lua` | `dial.vmax / vred` | 表底与红线起点 |
| `theme.lua` | `modes[i].vmax/acc/dec` | 三档的动力参数 |
| `cluster.lua` | `segs = ceil(24*v/vmax)` | 进度弧分段，降到 16 更省 |
| `cluster.lua` | 电池段数 `n = 20` | 电池条格数 |
