# MUSIC STUDIO · Air8607 音乐播放器

> 10 寸屏 · SD 卡歌曲与歌词 · 播放列表 · 五种唯美画面风格
> 界面零图片素材：唱片、频谱、波形、光波全部由 `airui.shape` 图元逐帧实时绘制。

- 适用固件：`luatos@air8607@10i_v0`（需开启 `LUAT_USE_AIRUI` 含 hzfont 矢量字库）
- 适用硬件：Air8607（Air1603）+ 10 寸 RGB 屏 1024x600（免序列）+ GT911 电容触摸
  + 内置 DAC + HT6873 功放 + SPI1 SD 卡
- 编码 / 换行：UTF-8 / LF

## 功能与交互

| 操作 | 效果 |
|---|---|
| 点列表里的曲目名 | 立刻切到该曲（命令入队，不阻塞 UI） |
| 上一页 / 下一页 | 列表按 8 行翻页（曲目少于此数时按钮无动作） |
| 上一曲 / 下一曲 | 切歌；随机模式下"下一曲"随机挑一首（不重复当前） |
| 播放 / 暂停 | 暂停时唱片停转、频谱定格、歌词停止滚动；继续从原位置接着放 |
| 顺序 / 随机 / 单曲循环 | 左侧模式键每点一次循环切换，按钮文字同步 |
| 音量滑块 / ± 键 | 0~100，实时作用于 `exaudio.vol` |
| 画面风格 5 键 | 唱片模式 / 歌词模式 / 柱状频谱 / 波形频谱 / 玻璃光波 |

播放结束按当前模式自动续播：顺序播下一首（末尾回到第一首）、随机挑一首、单曲循环重播本曲。

## SD 卡目录约定

插卡后无需配置，程序按下列顺序找歌（**先命中的目录优先**，命中即停）：

```
/sd/music/   ← 推荐
/sd/audio/
/sd/mp3/
/sd/         ← 根目录兜底
```

- 支持扩展名：`mp3` / `wav` / `amr`
- 每个目录会再看**一级子目录**（`/sd/music/歌手/歌.mp3` 也能扫到）
- 文件名按路径字典序排序，即播放顺序
- 曲名展示规则：`歌手 - 曲名.mp3` 自动拆成"歌手 / 曲名"；
  有 `[ti:]` `[ar:]` 标签时以歌词文件为准
- 列表编号 `01`、`02`… 与播放顺序一致

**歌词**：与歌曲**同名**的 `.lrc`，放同一目录即可：

```
/sd/music/郭顶 - 水星记.mp3
/sd/music/郭顶 - 水星记.lrc
```

也支持 `/sd/lyric/`、`/sd/lrc/`、`/sd/lyrics/` 下放同名歌词（大小写 `.lrc/.LRC/.Lrc` 都认）。

### 歌词格式

支持标准 LRC 及常见变体：

```
[ti:水星记]  [ar:郭顶]  [offset:+500]      ← 元信息（offset 单位毫秒，正数=整体提前）
[00:19.200]着迷于你眼睛                     ← 三位小数按毫秒，两位按百分秒
[00:22.91]银河有迹可循
[00:26.160][01:20.00]副歌复用同一句          ← 一行多时间戳
[00:29:74]冒号分隔的变体                     ← 部分老播放器的写法
```

- **编码必须是 UTF-8**（带不带 BOM 都行）。固件里没有可用的 iconv，
  GBK 文件会显示成乱码，界面右下角会提示"歌词不是 UTF-8 编码"，用记事本另存为 UTF-8 即可。
- **网易云音乐的 .lrc 可以直接用**：这类文件前面有几行 `{"t":0,"c":[...]}` 的逐字 JSON 头，
  解析器会跳过它们，只取后面的标准 LRC 行（已用 5 首真实网易云歌词验证）。
- 纯音乐（只有 `[00:05.00]纯音乐，请欣赏` 一行）也能正常显示。

## 音频后端

优先 `audio_v2`，退回 `exaudio`：

| 后端 | 暂停/继续 | 进度 |
|---|---|---|
| `audio_v2`（推荐） | 真暂停，继续从原位置播 | DMA 实际消费量，准确 |
| `exaudio` | 暂停=停止，继续=从头播 | 按起播时刻估算 |
| 无音频库（PC 模拟器） | 计时演示模式，画面与歌词照常走 | 计时器 |

`exaudio.setup({model="dac", pa_ctrl=73 ...})` 负责把 DAC + HT6873 通路配好
（DAC 模式下只有它配好 `pa_ctrl` 才不会无声），随后自己调 `audio_v2.play()`
拿 `request_index` —— 只有拿到它才能做暂停与进度（`exaudio` 把它藏在内部变量里）。

## 烧录与运行

1. 用 LuatTools / 量产工具，把本目录下**全部 .lua 平铺添加**到脚本区（不需要保留子目录），
   再把 `res/Time_travel_8k.mp3` 一起加进去（被拍平到 `/luadb/` 也没关系，
   代码会依次探测 `/luadb/res/`、`/luadb/`、`/res/`、`/`）。
2. 入口 `main.lua`（`PROJECT = "music_studio"`）。
3. 烧录后上电：背光上电时占空比为 0，界面搭好才点亮，避免花屏。
4. 串口看到 `音乐播放器已就绪 music_studio 1.0.0` 即表示进入动画循环。
5. 往 SD 卡拷歌：建议整目录拷到 `/sd/music/`，mp3 与同名 lrc 成对放置。

引脚（与 `factory/config/eng_8607_10i_v0.lua` 对齐）：

```
LCD 复位/DISP  GPIO15        LCD 供电 GPIO17（低有效）
背光 PWM3 (GPIO13)           SPI1_CS = GPIO8    SD_EN = GPIO74
AUDIOPA_EN = GPIO73（高有效） GT911: I2C1 400kHz, pin_rst = 14, pin_int = 51
```

## 已知限制

- **频谱是合成的**，不是真实 PCM 分析：Air8607 音频链路没有 PCM 出口
  （`audio_v2` 回调只给整数，`exaudio` 也没有取数据接口），Lua 侧也没有 mp3 解码器。
  合成频谱由多路正弦 + 节拍包络生成，观感接近真实音乐，但不会和某首歌强相关。
- **MP3 时长按首帧码率估算**：CBR 准确，VBR 会偏（进度条终点可能与实际略有出入，
  但进度推进本身用的是 DMA 播放时钟，不会漂）。
- `exaudio` 后端没有断点续播：暂停后继续会从头播，界面右下角会提示。
- 列表翻页是"上一页/下一页"，不支持手指拖动滚动（虚拟列表 + 定长槽位换取零内存增长）。
- 屏幕固定 1024x600，换屏要同时改 `ui_theme.layout` 与 `exd_air8607_rgb` 里的 RGB 时序。
