# WSH · ANDON OEE —— 产线安灯 + OEE 生产看板

> 10 寸屏挂在车间墙上：工位异常按灯呼叫、班组长看屏响应、厂长看产量与效率。
> **纯离线运行**：虚拟产线自带数据，无外设也能完整演示；接真机时替换数据源即可。

- 适用硬件：Air8607（Air1603）+ 10 寸 RGB 屏 1024x600 + GT911 电容触摸 + SPI1 TF 卡
- 编码 / 换行：UTF-8 / LF

## 提示词（Prompt）

> 以下是本项目交给 AI 的原始需求，可据此复现或继续迭代。

做一个工业现场真正用得上的产线看板：

- 场景是离散制造车间，屏幕挂在产线通道或班组园地，操作工、班组长、车间主任都会看。
- 核心是 **Andon 安灯**：某个工位出问题（缺料 / 设备故障 / 质量问题 / 换型），操作工按灯或点屏呼叫，
  大屏立刻把该工位标红并响铃；班组长处理后点"已响应"，超时未响应要自动升级（黄变红闪烁）。
- 同时是 **OEE 看板**：实时统计产量、良率、节拍、可用率、性能，算出 OEE，
  并且把停机时间按异常类型做帕累托，让人知道问题主要卡在哪。
- 8 个工位 4x2 网格，每个卡片显示：工位名、状态、当前产量、异常已等多久。
- 右侧实时异常列表（工位、类型、已等时长、是否已响应），按时间排序。
- 底部一条汇总：今日产量、良率、节拍、OEE（颜色区分好坏）。
- 全部触摸可操作，深色工业风，1024x600 横屏一屏装下。
- 代码要有虚拟数据源，PC 模拟器和无外设真机都能完整跑起来。

## 二、应用场景

| 角色 | 在哪儿 | 看什么 |
|---|---|---|
| 操作工 | 工位 | 点屏或按灯呼叫异常 |
| 班组长 / 线长 | 车间走动 | 哪个工位报警、已等多久、是否超时 |
| 车间主任 / 厂长 | 通道、办公室 | 产量、良率、节拍、OEE |
| 参观客户 | 车间展厅 | 数字化管理能力展示 |

典型流程：

```
09:40 工位03 缺料 → 呼叫 → 卡片变红 + 报警音
09:42 班组长到场 → 点"已响应" → 记录响应 2 分钟
09:45 补料完成 → 点"恢复生产" → 记停机 5 分钟
     系统持续累计产量/停机 → 实时算 OEE
12:00 交接班 → 班次报表（产量/良率/停机帕累托）存 SD
```

## 四、功能与操作

| 操作 | 效果 |
|---|---|
| 点工位卡片 | 弹出操作面板（当前状态 + 可选动作） |
| 点「缺料 / 设备故障 / 质量问题 / 换型」 | 该工位进入异常状态，开始计时，卡片变红 |
| 点「已响应」 | 记录班组长到场时间，响应耗时打日志 |
| 点「恢复生产」 | 结束本次异常，停机时长计入帕累托统计 |
| 超时规则 | 60 秒未响应变黄，120 秒变红闪烁（阈值在 `conf.threshold`） |

### P0 显示指标（区别于基础版的关键信息）

| 显示 | 内容 | 来源 |
|---|---|---|
| 顶栏 | 工单号、产品型号、安全运行天数 | `conf.line`（work_order / product / safety_days） |
| OEE 三分项 | 可用率 / 性能 / 良率 | `oee.compute`，OEE 拆解 |
| 底栏达成率 | 实际/目标产量 + 分段进度条 + 百分比（≥100% 绿、≥80% 黄） | `line_sim.stats` + `conf.line.target` |
| 停机帕累托 | 停机时长按异常类型占比排序，分段条形 | `oee.pareto` |
| 响应统计 | 平均响应时长、最长响应时长（分钟） | `line_sim` 每次异常结束记录 `response_samples` |

## 五、OEE 计算口径

```
OEE = 可用率(A) x 性能(P) x 良率(Q)
  A = 运行时间 / 计划时间
  P = 实际产量 / (运行时间 / 节拍)
  Q = 良品数 / 总产量
```

颜色：`>= 85%` 绿、`>= 60%` 黄、`< 60%` 红。

## 六、硬件引脚（与 factory/config/eng_8607_10i_v0.lua 对齐）

```
LCD_DISP = GPIO15      LCD 供电 = GPIO17（低有效）
背光     = PWM3 (GPIO13)   SD_EN = GPIO74   SPI1_CS = GPIO8
GT911    = I2C1 轮询模式, pin_rst = 14, pin_int = 51
功放 PA  = GPIO73（默认关断，报警音时再开）
```

## 七、烧录与运行

1. LuatTools 里把 `code/` 目录**整体加入**（保留 `app/` `drv/` `ui/` 子目录），入口 `main.lua`。
2. 烧录上电看串口：
   ```
   I/user.main     andon_oee 001.000.001
   I/user.app_main 运行环境检测 rtos.bsp() = ... => IS_PC = false
   I/user.app_main 显示初始化完成 display 1024 600
   I/user.line     虚拟产线已初始化 SMT 产线 A 工位数 8
   I/user.app_main Andon 看板已就绪 ...
   ```
3. 点工位卡片 → 呼叫异常 → 观察看板变化。
4. 改产线名、目标、工位数、阈值：只改 `conf.lua`。

**PC 模拟器已验证**（`IS_PC = true` 分支跳过硬件，虚拟产线照常跑）：

- 全部 lua 加载无语法 / 运行错误；
- 8 工位每秒按节拍累计产量，异常按 25~55 秒随机注入；
- 超时升级（60s 黄 / 120s 红闪烁）与响应、恢复流程正常。

## 八、接真机的扩展点

| 数据 | 现在 | 真机怎么接 |
|---|---|---|
| 异常呼叫 | 触摸弹窗 | GPIO 安灯按钮：`gpio.setup(pin, 1, gpio.PULLUP)` + 中断回调里调 `line_sim.call_alarm` |
| 三色塔灯 | 无 | GPIO 输出，按工位状态点亮红/黄/绿 |
| 产量 / 节拍 | 虚拟累加 | RS485 读 PLC（可复用 `modbus_hmi` 的 `modbus.lua`） |
| 报警音 | 无 | DAC + 功放（GPIO73），复用 `tom_cat` 的音频播放方式 |
| 班次报表 | 未落盘 | `sd_card.mount()` + 写 CSV 到 `/sd/andon/` |
