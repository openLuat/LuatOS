# WSH · DESKTOP CLOCK —— Air8607 桌面时钟 / 日历

> 10 寸屏 · 大时钟 · 当月日历 · 干支生肖 · 纪念日倒计时 · 手动校时 · 可选壁纸
> **纯离线运行**：本机没有 4G / WiFi，**不存在自动授时**，时间靠本地 RTC + 手动校准。

- 适用硬件：Air8607（Air1603）+ 10 寸 RGB 屏 1024x600 + GT911 电容触摸 + SPI1 TF 卡
- 编码 / 换行：UTF-8 / LF

## 三、功能与交互

| 操作 | 效果 |
|---|---|
| 点「设置」 | 进入设置页（校时 + 亮度），点「返回」回到时钟 |
| 校时 `-` / `+` | 逐字段调整 年/月/日/时/分；`日` 上限按月长自动钳制（2 月不会到 31） |
| 「读取当前」 | 把界面值重新同步成 RTC 的当前值 |
| 「保存校时」 | 写入 RTC，成功后显示 `已校时：YYYY-MM-DD HH:MM:SS` |
| 亮度 `-` / `+` | 每次 ±10%，写 PWM 并存盘（范围 10~100，下限防止调全黑把自己锁在门外） |

## 四、为什么必须手动校时（重点）

本机没有 4G / WiFi，**无法 SNTP 授时**。RTC 掉电或首次上电后时间可能是出厂默认值，
所以「校时」做成一等公民功能。配方严格按官方 demo `demo/rtc/rtc_app.lua`（无网络分支）：

```lua
rtc.setBaseYear(1900)   -- 必须先设基准年
rtc.timezone(32)        -- 必须先设东八区（合宙时区单位是 15 分钟，8h = 32）
rtc.set(时间戳)          -- 传时间戳，避开 rtc.set({mon=}) 与 os.time({month=}) 的键名差异
```

> **两个必须，缺一不可**：不设 `timezone(32)`，本地时间会差 8 小时；
> 不设 `setBaseYear(1900)`，时间戳换算基准不对。
>
> 用 LuatTools 下载时若工具提供「下载时同步电脑时间」，可先粗同步，再用校时页微调到秒。

## 五、壁纸铁律（务必看完再放文件）

壁纸默认路径 `/sd/wallpaper/clock.jpg`，找不到时依次尝试 `clock.jpg` → `wp1.jpg` → `/sd/clock.jpg` → `/sd/bg.jpg`。

1. **只能 baseline JPEG**。真机解码全屏大图的内存开销很大，全屏 PNG 不推荐，
   统一用 JPEG，尺寸建议正好 1024x600。
2. 建议尺寸正好 **1024x600**；过大或非 baseline 会解码失败，失败只丢壁纸（有渐变背景兜底），
   时钟不会崩，串口 `user.wallpaper` 会打出候选列表与具体原因。
3. 不需要壁纸就把 `conf.wallpaper.enabled` 改成 `false`，退化为渐变背景。

## 七、烧录与运行

1. LuatTools 里把 `code/` 目录**整体加入**（保留 `app/` `drv/` `ui/` 子目录，不要平铺），入口 `main.lua`。
   代码按层分目录，`require` 只写模块名（如 `require "app_main"`），不写目录前缀。
2. 烧录上电看串口：
   ```
   I/user.app_main 运行环境检测 rtos.bsp() = ... => IS_PC = false
   I/user.app_main 显示初始化完成 display 1024 600
   I/user.sd       挂载成功 /sd spi_id 1 cs 8 speed 40000000
   I/user.clock    跨天刷新 2026年10月26日 星期一 本月1号星期(1=周日) 5
   I/user.app_main 桌面时钟已就绪 wsh_desktop_clock 1.0.0
   ```
3. 首次使用：点「设置」→ 把年/月/日/时/分调准 →「保存校时」。
4. 换纪念日：改 `conf.lua` 的 `events`（每年循环写 `month/day`，一次性写 `date = "2027-06-01"`）。

**PC 模拟器已验证**（`IS_PC = true` 分支跳过全部硬件）：

- 13 个 lua 全部加载（含 `app/` `drv/` `ui/` 子目录），无语法 / 运行错误；
- 月历算法：`2026-10` 的 1 号是星期四（wday=5），当日 `2026-10-26` 判定为星期一；
- 跨天才重画月历；时分秒每秒刷新但只在值变化时 `set_text`，不掉帧。

## 八、已知限制

- **没有农历 / 节气**：需要农历信息表驱动，本版未引入（干支、生肖是年份公式直算，不查表，已有）。
- **没有闹钟**：硬件其实支持（内置 DAC + HT6873 功放，PA=GPIO73），只是本版没做。
- **不能翻月**：日历只显示当前月（跟随时间自动跳月）。
- **没有 NTP**：必须手动校时；若 RTC 没有后备电池，彻底断电后可能要重新校准。
