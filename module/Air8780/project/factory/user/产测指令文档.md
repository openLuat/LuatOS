# Air878x 出厂固件产测指令文档（iRTU + 厂测合一固件）

> 工程位置：`module/iRTU/irtu_8780_factory/`
> 产测模块：`factory.lua`（按 `factory_config.DEVICE_VER` 聚合 5 型号产测指令）
> 通信：USB 虚拟串口 `uart.VUART_0`，波特率 115200，指令以 `#` 结尾，回复以 `#` 结尾

---

## 一、启动模式（main.lua）

| test_done | 行为 |
|---|---|
| 无（默认） | 进入产测模式（`require "factory"`，独占 VUART_0 响应指令） |
| 有 | 进入正常模式（`require "irtu_main"`，AirCloud 上报/下行） |

> 产测完成后发 `TEST_DONE#` 写 test_done 并重启进入正常模式。
> 需要重新产测：清 fskv 的 test_done 键，或烧录时勾选"擦除 fskv"。

## 二、管脚定义（板子统一）

| 功能 | GPIO | 说明 |
|------|------|------|
| 状态灯 LED | GPIO27 | 高亮/低灭（NET_STATUS） |
| 看门狗喂狗 | GPIO24 | Air153D，经 NPN 三极管反相（空闲高、喂狗低脉冲） |
| VREF 上拉 | GPIO23 | 全程常开（SIM 上拉 + 8780G 内置GNSS/DA221供电） |
| 电池电压 | ADC CH_VBAT | 模组内部电池电压通道 |

### 8780V 音频（仅 8780V）

| 功能 | GPIO | 说明 |
|------|------|------|
| PA_EN | GPIO22 | 音频功放使能（高电平打开） |
| DAC 电源 | GPIO20 | codec(es8311) 电源控制脚 |
| es8311 | I2C0 | 地址 0x18，1.8V 电平 |

### 8780G GNSS/加速度（仅 8780G）

| 功能 | GPIO | 说明 |
|------|------|------|
| GNSS 供电 | GPIO21 | GPSTEST 指令控制 |
| GNSS 串口 | UART2 | 内置 GNSS，115200 |
| DA221 加速度 | I2C1 地址 0x27 | 芯片 ID 寄存器 0x01 期望 0x13 |

### 8782 232/485（仅 8782）

| 功能 | GPIO | 说明 |
|------|------|------|
| 232 供电 | GPIO25 | UART3 转 232 |
| 485 供电 | GPIO26 | UART2 转 485 |
| 485 方向 | GPIO31 | DE/RE 控制 |
| LDO 输出 | GPIO23 | 排针 3.3V |

## 三、指令列表

### 通用指令（所有版本）

| 指令 | 功能 | 返回值 |
|------|------|--------|
| `VERSION#` | 固件版本 | `Air8780Factory_001.001.000#` |
| `IMEI#` | IMEI | 15 位数字# / ERROR# |
| `IMSI#` | SIM IMSI | 460 开头# / ERROR# |
| `ICCID#` | SIM ICCID | 20 位# / ERROR# |
| `CSQ#` | 信号强度 | 数字#（0=无信号，合法）/ ERROR# |
| `MUID#` | 模组唯一标识 | 非空# / ERROR# |
| `VBAT#` | 电池电压 | 电压值(mV)#，如 `3720.00#` / ERROR# |
| `LED,1#` / `LED,0#` | 状态灯控制（GPIO27） | OK# |
| `WD_TEST#` | 看门狗强制复位（设备约1s内重启） | OK# |
| `WD_TEST,1#` | 恢复正常喂狗 | OK# |
| `FLYMODE,1#` / `FLYMODE,0#` | 飞行模式开关 | OK# |
| `ECNPICFG#` | RF 校准标志位（只读） | `true#` / `false#` / ERROR# |

### 写号指令（OTP，写错无法改）

| 指令 | 功能 | 返回值 |
|------|------|--------|
| `MODEL,型号#` | 写工业模组型号（OTP PROD） | OK# / ERROR# |
| `MODEL?#` | 读回型号（未写 ERROR） | 型号# / ERROR# |
| `HVERSION,版本#` | 写硬件版本（OTP PCB） | OK# / ERROR# |
| `HVERSION#` | 读回硬件版本（未写 ERROR） | 版本# / ERROR# |

### 完成指令

| 指令 | 功能 | 返回值 |
|------|------|--------|
| `RST#` | 单独重启（不写 test_done，重启后还进产测） | OK# |
| `TEST_DONE#` | 测试完成（写 fskv，3s 重启进正常模式） | OK# |
| `PCBA_TEST_DONE#` | 测试完成关机（不写 fskv） | OK# |

### 8780V 专属（音频）

| 指令 | 功能 | 返回值 |
|------|------|--------|
| `RECORD#` | 录音 5 秒（AMR，存 /record.amr） | OK# / ERROR# |
| `PLAY#` | 回放录音文件（喇叭测试） | OK# / ERROR# |

### 8780G 专属（GPS/加速度）

| 指令 | 功能 | 返回值 |
|------|------|--------|
| `GPSTEST,1#` | 打开内置 GNSS 并透传 NMEA 给 USB | OK# / ERROR# |
| `GPSTEST,0#` | 关闭 GNSS | OK# / ERROR# |
| `GS_STATE#` | DA221 加速度芯片 ID 测试 | OK#（ID=0x13）/ ERROR# |

### 8782 专属（232/485）

| 指令 | 功能 | 返回值 |
|------|------|--------|
| `LDO,1#` / `LDO,0#` | 排针 3.3V 输出控制 | OK# |
| `U232_TEST#` | 232 回环测试（发"232TEST"比对） | OK# / ERROR# |
| `U485_TEST`（485口直接发） | 485 独立测试，设备回"485TEST\r\n" | PC 收到即 OK |

## 四、测试流程（参考）

```
1. VERSION      校验固件版本
2. IMEI         读 IMEI
3. IMSI         读 SIM IMSI
4. ICCID        读 SIM ICCID
5. CSQ          读信号强度
6. MUID         读模组唯一标识
7. VBAT         读电池电压
8. LED          状态灯亮灭（人工看灯）
9. ECNPICFG     读 RF 校准位
10. [专属]      8780V→RECORD/PLAY；8780G→GPSTEST/GS_STATE；8782→LDO/U232_TEST/U485_TEST
11. MODEL       写型号
12. MODEL?      读回校验型号
13. HVERSION    写硬件版本
14. HVERSION    读回校验版本
15. RST         单独重启（验证写号掉电不丢）
16. MODEL?      重启后读回验证型号
17. HVERSION    重启后读回验证版本
18. WD_TEST     看门狗强制复位（建议最后）
19. VERSION     轮询确认重启成功
20. TEST_DONE   测试完成，重启进正常模式
```
