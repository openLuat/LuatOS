# Web 控制台操作说明

适用于 `meter_cloud` 项目配套页面（`web/index.html`），设备端为 Air780EPM + 板载 RS485，
经 AirCloud（合宙 IOT 通用报文协议）与页面通信。

---

## 一、进入与选设备

1. 打开页面后点右上角 **登录**，用合宙账号授权登录；
2. 顶部下拉框选择 **项目** → **设备**（设备 ID 形如 `868926080467512`）；
3. 页面自动加载该设备的最新一次上报，并每 **60 秒**自动刷新（可取消「自动刷新」勾选）。

顶部状态条说明：

| 项目 | 含义 |
|---|---|
| 设备状态 | 最近一次上报 ≤3 分钟 → 在线；≤30 分钟 → 数据陈旧；更久 → 离线 |
| 设备 ID / 项目名称 | 来自设备上报的 1293 / 1294 字段 |
| 最近上报 | 云端最新一条记录的时间 |
| 4G 信号 | 设备上报的 CSQ（0~31，越大越好） |

## 二、开关控制（总开关）

页面第一张卡片，控制现场总开关（电表第 1、2 路继电器）。

| 元素 | 说明 |
|---|---|
| 刀闸图示 | **跟随实际反馈 DI1**：转轴在下方触点，红色刀臂向上合上=合闸；深灰刀臂向右上抬起=断开 |
| 状态胶囊 | 合闸 / 断开 / **故障**（故障=反馈与平台目标不一致） |
| 反馈 DI1 | 现场辅助触点真实状态（1=合闸，0=断开），`--` 表示无数据 |
| 平台目标 | 平台最后一次下发的意图（合闸 / 断开） |
| 合闸继电器 DO1A/B | 第 1 路继电器当前输出（动作时 ON 约 2 秒后自动 OFF） |
| 断开继电器 DO2A/B | 第 2 路继电器当前输出 |
| DI 原始位 | 电表 4 路开入量的原始位图 `0bXXXX`，用于排查接线/映射 |
| **合闸 / 断开** 按钮 | 下发动作，继电器输出 **2 秒高电平**后释放 |

操作要点：

- 点击按钮后界面**立即**显示新的“平台目标”（乐观更新），约 **4~6 秒**后 DI 反馈到位
  （设备：2 秒脉冲 + 1.2 秒校验 + 上报入库）；
- 顶部徽标若显示「开关故障」，表示设备回读 DI 与目标不一致（拒动），
  请检查现场开关机构、辅助触点接线；
- 页面与设备之间的指令有 **≥3 秒**的接口限频，连续点击请稍等。

## 三、限制本地合闸

位于开关卡片下方，用于禁止现场手动操作。

| 状态 | 含义 |
|---|---|
| 已限制 | 现场手动合闸会被设备**自动断开**并记录事件 |
| 已解除 | 现场可自由操作 |

规则：

| 触发 | 结果 |
|---|---|
| 平台点「**断开**」 | 自动变为 **已限制** |
| 平台点「**合闸**」 | 限制状态**不变**（只合闸，不解除限制） |
| 点「**解除**」 | 解除限制，**不改变开关状态**（不会顺手合闸） |
| 点「**限制**」 | 手动上锁，用于现场检修 |

限制生效时设备的行为（**监守模式**）：

1. DI 与平台目标不一致 → 输出 2 秒脉冲强制纠正；
2. 纠正后仍不一致 → 进入监守模式，**每 2 秒**再输出一次 2 秒脉冲，直到 DI 与目标一致；
3. 期间「开关故障」徽标保持提示，日志中可见 `进入监守模式` / `状态已恢复，退出监守模式`。

> 目标状态与限制状态都保存在设备本地（掉电不丢），**重启后仍生效**。

## 四、控制日志

显示设备端最近 **40 条**控制事件（环形缓冲，掉电保存）。

| 列 | 说明 |
|---|---|
| 时间 | 设备本地时间；若设备未对时会显示 `T+xxx秒` |
| 事件 | 中文显示，异常类（失败 / 未到位 / 拦截 / 异常 / 监守）**标红** |

常见事件：

| 显示 | 含义 |
|---|---|
| 平台指令 总开关 合闸 / 断开 | 收到平台命令 |
| 总开关 合闸 / 断开 完成 | 动作后 DI 已到位 |
| 总开关 合闸 / 断开 未到位（DI=x） | 动作后 DI 未到位，已记故障 |
| 本地合闸被拦截 → 强制断开（DI=1） | 限制生效时现场手动合闸被纠正 |
| 本地断开被纠正 → 强制合闸（DI=0） | 限制生效时现场断开被纠正 |
| 进入监守模式（每 2s 持续纠偏） | 多次纠正仍未到位 |
| 状态已恢复，退出监守模式 | DI 与目标一致，解除告警 |
| 自动开启 限制本地合闸（平台断开后） | 断开指令附带加限制 |
| 自动解除 限制本地合闸（平台合闸后） | 仅在开启“合闸自动解除”配置时出现 |

点「刷新日志」可手动拉取；每次合闸 / 断开 / 限制操作后也会自动刷新。

## 五、实时数据

12 项电参量，来自电表寄存器（解析口径与说明书一致）：

电压 Ua/Ub/Uc、电流 Ia/Ib/Ic、功率 P/Q/S、功率因数 PF、频率 F、正向有功电能 EP。

- 数据为空（`--`）说明设备最近一次上报里没有该字段；
- 电表侧异常（如变比 PT/CT 为 0）会导致电压/电流/功率为 0，属设备侧问题。

## 六、历史数据与趋势

1. 选择起止日期 → 点「查询」；
2. 表格按上报时刻合并同一时刻的多条记录（时间 + 12 个字段）；
3. 右上角下拉可切换 **电压 / 电流 / 功率 / 电能** 趋势图；
4. 点「加载更多」翻页（每页 20 条）。

---

## 七、越限报警

对电表数据做云端判断（不依赖电表自身的报警继电器）。

| 输入项 | 含义 |
|---|---|
| 启用 | 开启 / 关闭报警判断 |
| 电压上限 / 下限 (V) | 任一相越限即报警 |
| 电流上限 (A) | 任一相超过即报警 |
| 功率上限 (kW) | 有功功率绝对值超过即报警 |
| 频率上 / 下限 (Hz) | 越限即报警 |
| 回差 | 触发后需回到 `门限 ∓ 回差` 才解除，避免数值抖动反复报警 |

- **填 0 表示不判该项**；
- 点「保存阈值」下发，设备掉电保存；点「查询当前」回填设备实际值；
- 卡片右上徽标显示「正常 / 报警：电压越限…」，同时上报字段 1313（位图）、1314（描述）。

## 八、控制命令

| 功能 | 说明 |
|---|---|
| `report:now` | 让设备立即上报一次 |
| 上报周期(秒) | 5~86400 秒，默认 60 |
| 串口调试报文 → 开启 / 关闭 | 打开后设备打印每次 Modbus 收发的原始帧（默认关闭，重启自动复原） |

设备应答会显示在下方灰色框内（`设备应答：{...}`）。

## 九、常见问题

| 现象 | 排查方向 |
|---|---|
| 点按钮后画面要等几秒才变 | 正常：设备动作 2 秒 + 校验 1.2 秒 + 云端入库；接口本身还有 3 秒限频 |
| 「平台目标」短暂回退后又变回来 | 旧版本问题；现版本以“指令之后的上报”为准，若仍出现请刷新页面 |
| 显示「开关故障」 | DI 与平台目标不一致：现场开关未动作、辅助触点未接、或 DI 映射位不对（看「DI 原始位」） |
| 「DI 原始位」与 DI1 不一致 | 说明 DI1 实际对应的不是第 0 位，把原始位数值反馈给开发调整映射 |
| 点「解除」后开关没动 | 正确：解除只解除限制，不改变开关状态 |
| 控制日志显示乱码 | 旧固件中文日志问题；现版本设备只发 ASCII，由页面翻译 |
| 实时数据全是 `--` | 设备离线、或该次上报缺少字段；先点「刷新」并检查“最近上报”时间 |
| 设备应答“暂无应答” | 设备离线或指令未送达，稍后重试；连续失败请检查 4G 与云端连接 |

## 十、安全提示

1. **合闸前确认现场无人作业**，远程合闸会直接驱动现场总开关；
2. 需要现场操作时，先「断开」→ 再点「解除」，操作完成后重新「合闸」；
3. 不需要现场操作时保持「已限制」状态，可自动拦截误操作；
4. 频繁点击会触发接口限频，建议每次操作后等待 5 秒再操作下一次。
