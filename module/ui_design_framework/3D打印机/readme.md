# 3D 打印机 HMI · AirUI 工程（Air8603）

参考 B 站案例 **《HMI串口屏-3D打印机案例》**（兕腾科技，BV1zv9XBmEmA）逐屏复刻，
UI 结构/配色/文案与视频画面保持一致；`code/preview.html` 为 **1024×600 的 1:1 浏览器预览稿**
（定稿设计稿，先于 AirUI 实现落地）。

- 硬件：合宙 Air8603（Air1603 主控，1024×600 RGB565 电容触摸屏）
- 开发方式（下一步）：LuatOS (Lua 5.3) + AirUI（LVGL 9.4 封装）+ exwin 页面管理
- 字号约束：**全 UI 最小 16 号**（标题 26~34 号），保证实机可读
- 资源：**零图片贴图**，图标全部 SVG/自绘（实机侧用 airui shape/line 复刻）

## 预览稿交互清单（preview.html 已实现的行为）

数据驱动（`S` 状态对象 + `FILES` 3 页 × 5 个模型），不是静态图：

| 范围 | 行为 |
|------|------|
| 全局 | 顶栏 home 图标 / 面包屑文字 / 右上 WiFi 图标均可点；WiFi 图标任意页面进入 WiFi 页 |
| 打印-列表 | 点任意 `.obj` 行 → 选中橙条移动 + **右侧预览图/名称/日期同步切换**；`|< < 1/3 > >|` 真翻页（3 页共 15 个模型，末页 3/3）；「打印」按钮把**当前选中模型**带入打印中页 |
| 打印中 | 进度条 0→100% 每 120ms 递增（约 12 秒），百分比与黄条同步；「暂停」→ 弹「已加载 / 是否继续或停止打印?」，是继续、否停止；「停止」→ 弹「是否停止打印?」，**是 → 回文件列表**（非首页）、否继续；到 100% 弹「打印完成!」 |

| 进退料 | 喷头温度橙色滑块可点选位置 → 数值联动；「进料」点击 +5.0MM；「出料」点击弹出橙色数字键盘，输入后写回 |

## 实现说明（page_3d.lua）

| 机制 | 做法 |
|------|------|
| 切屏 | 单 exwin 页 + `nav(name)` 改 `S.screen` 后销毁重建 body（对应 preview 的 `go()`）；重建统一 `defer()` 延迟 30ms，避免点击回调内销毁自身 |
| 状态 | 文件级 `S` 对象，字段与 preview.html 的 `S` 一一对应（页码/选中项/轴坐标/进度/WiFi/温度/开关/亮度/速度/调平序号/键盘目标） |
| 图标 | `theme.icon` 按 100×100 设计稿用 **line/circle/rect** 缩放绘制，共 29 种；弧线一律多段折线 `ARC()` 拼接 |
| 模型预览 | `draw_model` 用 rect/circle/line + 折线弧组合出 15 种模型（对应 HTML 的 SVG 缩略图） |
| 浮层 | `clear_overlay()` + 全屏黑底 `set_color(0x000000, 120~160)` 遮罩，数字键盘 / 对话框 / 滑块弹窗 / WiFi 弹窗共用 |
| 无框可点 | `theme.link`（纯文字链接）+ `theme.hit`（透明 container 压在最上层接收触摸），面包屑/侧边菜单/卡片热区统一用它 |
| 滑块 | `theme.slider` 封装 `airui.slider`（深轨 + 橙色指示 + 黄色旋钮），喷头温度 / 亮度 / 打印速度三处都用它 |
| 原地刷新 | `refs.pct`（百分比）、`refs.fill`（进度条 `shape:set_items`）、`refs.nplabel`（键盘显示）、`refs.kbdtext`（输入行），避免整屏重建 |
| 进度驱动 | build 返回 `(update, 120)`，`make_page` 按 120ms 起 tick，每步 +1% ≈ 12 秒，进度条连续推进 |
| 主题切换 | `theme.PALETTES.dark/light` + `theme.toggle_theme()` 就地覆写 `theme.C`，顶栏太阳/月亮图标切换后整页重建 |

## 实机踩坑（已验证）

1. **`shape` 的 `arc` / `ellipse` 图元在实机上不渲染**。
   表现：牛奶盒底部阴影消失、马克杯把手残缺、WiFi 图标只剩一个圆点、密码锁图标变成小方块。
   结论：只用 `line` / `circle` / `rect`，弧线与椭圆环全部用多段折线近似（`theme.icon` 的 `ARC()`、`draw_model` 的 `ARC()` / `ELL()`）。
2. **坐标必须取整**，小数坐标的图元会直接不显示（统一 `math.floor`）。
3. **子控件会拦截触摸**：卡片里先画图标/文字再设卡片 `on_click`，会出现"点两下才响应"。
   统一改为画完内容后压一层 `theme.hit` 透明热区。
4. 按钮默认样式带底色/描边，面包屑和侧边菜单要用 `label + hit` 而不是 `button`，否则实机出现"方框/下划线"。
5. 多行文案塞进单个 `label` 只显示一行（"已加载 / 是否继续或停止打印?" 会被裁掉），`dialog` 已改为按 `\n` 拆成多行 label 并自适应高度。
6. **中文字符串宽度不能按 `#txt` 算**（UTF-8 一个汉字 3 字节），否则面包屑每段会多出一倍空白、`>` 被推到很远。按 `floor((#txt+2)/3)` 折成字数再乘字宽。
7. **`container` 里装 `label` 容易出滚动条**：只要内容被判定溢出，LVGL 就画出滚动条（实机表现为输入框内多一条灰底线 + 右侧灰竖线），调 `label` 的宽高只能碰运气。
   彻底解法：输入框用 `airui.shape` 画「填充矩形 + 描边」（shape 不是可滚动对象），文字和热区直接挂在对话框容器上。
8. 固定底色的显示区不能配主题色文字（数字键盘显示区原来固定黑底 + `C.text`，切浅色后变黑底黑字），改用 `C.input` 随主题反转。
