# AIR KTV 点歌系统 HMI · AirUI 工程（Air8603 / Air1603）

参考 `docs/index.html`（1024×600 双主题设计稿）1:1 移植到 LuatOS + AirUI。
九页（推荐 / 点歌 / 歌手 / 搜索 / 已点 / 榜单 / 歌单 / 正在播放 / 设置）+ 顶栏、侧栏、迷你播放条，
外加**快捷功能浮层**、**调音 / 空调弹窗**与 toast；深色 / 浅色双主题 × 蓝 / 紫 / 青三套配色。

- 硬件：合宙 Air8603-WiFi（Air1603 主控），1024×600 RGB 屏 + GT911 电容触摸
- 开发方式：LuatOS（Lua 5.3）+ AirUI（LVGL 封装）+ exwin 页面管理
- 数据：`mock.lua` 36 首演示曲目 / 18 位歌手 / 8 个分类 / 6 个歌单 / 4 张榜单；进度按 1 秒步进推进，不接音频解码与网络
- 资源：**零 PNG 贴图**。图标、封面、进度条、滑块、开关全部用 `shape` 的 line / rect / circle 图元绘制（`code/img/` 下 8 张 tile PNG 为早期磁贴素材，当前版本未引用）
- 字号：正文 15~18，标题 20~22，最小 15

## 调试硬件环境

| 项目 | 说明 |
| --- | --- |
| 板卡 | 合宙 Air8603-WiFi（主控 Air1603） |
| 屏幕 | 1024×600 RGB，`display.init("custom", ...)`，pclk = 50MHz，pin_rst = GPIO15 |
| 触摸 | GT911（I2C1 轮询，TP_RST = GPIO14 / TP_INT = GPIO51）；RST 由内核 `tp_gt9xx_gpio_init` 完成，脚本不要重复拉低 |
| 背光 | PWM3 @1kHz，占空比 85；首帧上屏后再开，失败回退 `pwm.setup + pwm.start` |
| 供电轨 | 5V_EN = GPIO12，9V_EN = GPIO56，12V_EN = GPIO44，5VOUT_EN = GPIO52，SD_EN = GPIO74（顺序上电），模组 RST = GPIO72（低） |
| 看门狗 | `wdt.init(60000)` + 独立 task 每秒 `wdt.feed()` |
| 字库 | `airui.font_load{ type="hzfont", size=16, cache_size=1024, antialias=1 }`，必须在 `airui.init` 之后 |

## 内核固件

- 固件：按 Air1603 / Air8603 版本选配 LuatOS 固件（需含 AirUI + hzfont）
- 关键顺序（勿改）：供电轨 → `display.init` → `airui.init(1024,600)` → 铺深色全屏底 → PWM3 背光 → `font_load` → `tp.init("gt911")` → `device_bind_touch` → `theme.apply` → `page.open`
- `airui.init` 早于任何控件创建；先铺 `0x10131D` 全屏底再开背光，避免初始化期间闪白屏
- 搜索页依赖 `airui.keyboard(mode="pinyin_26")` + `airui.textarea`（中文候选栏由固件输入法提供）
- Luatools 烧录时勾选 **“添加默认 lib”**（`exwin` 为扩展库）

## 烧录步骤（Luatools）

1. 电脑安装 Luatools 及 Air8603 板载 USB 转串口驱动；
2. Type-C 数据线接 Air8603-WiFi 的 USB 口；
3. Luatools 新建项目，选 Air1603 对应固件（需含 AirUI + hzfont）；
4. 脚本区添加 `code/` 下 4 个 `.lua`，并勾选 **“添加默认 lib”**；
5. 烧录运行：自动进推荐页；左侧切页；搜索框弹拼音键盘；进度 / 音量可拖；迷你条「功能」开快捷浮层。

## 实现说明

| 机制 | 做法 |
| --- | --- |
| 页面管理 | 单个 exwin；**阶段 1** 只建顶栏 / 侧栏 / 迷你条 / 首页并立即上屏，**阶段 2** 用 `taskInit + wait(20)` 分帧补建其余 8 页与浮层、弹窗、toast，避免长帧白屏 |
| 切页 | 九页预建，切页只 `set_hidden`；切到的页面容器做一次「颜色抖动」（3% 混白→还原）强制整块重绘，清掉 z 序更低的旧页残留 |
| 刷新驱动 | 单一 `sys.taskInit + sys.wait(100)`：每 10 拍（1 秒）推进播放时间与时钟；**不用 `sys.timerLoopStart`** |
| 图元刷新 | 动态图元统一走 `put()`：空表且已清空时跳过 `set_items`；进度/音量条用 `grad_progress` 画青→黄渐变（14 段 + 两端圆头） |
| 主题切换 | `theme.apply()` 就地覆写同一张 `theme.C`，`theme.register()` + `theme.recolor()` 原位换色；切换后 `redraw_page()` 重绘当前页，消除旧颜色的抗锯齿残影 |
| 滑杆 | 自绘轨道 + 圆点 + 透明 `airui.slider`；程序回写与用户拖动用标志位分离，避免互相打断 |
| 输入法 | 懒加载 `airui.textarea` + `airui.keyboard(mode="pinyin_26")`；离开搜索页或点遮罩时先 `hide()` 再隐藏，键盘不残留 |
| 图标 | 全部 `theme.ic_items()` 从 24×24 线稿生成 line / rect / circle 图元；单 shape ≤32 图元，超出拆批 |
| 点击热区 | 可点区域最后压一层透明 `theme.hit`；侧栏这类自带激活态的地方用 `quiet` 模式，按下不闪白框 |
| 事件外执行 | 销毁 / 重建 / 切主题统一 `theme.defer(fn, 30)` 延后，内部 `pcall` 保护 |
| 容错 | 初始化、分帧建页、动态 setter 全程 `pcall`；建页失败在屏幕左上角显示 `BUILD ERR / PAGE ERR` 便于定位 |

## 踩坑要点（来自 theme.lua 头部，务必遵守）

1. `label` 文字在框内**顶部对齐** → `theme.txt` 统一下移 y 并把 h 收紧到 `size * 1.28`；
2. 只有 `container` 有 `set_hidden`，`label / shape / button` 没有 → 要隐藏就塞进容器；
3. 坐标 / 半径 / 线宽一律取整，小数会让整批图元被固件丢弃；
4. 不用 `arc / ellipse`（本批固件不渲染），弧线用多段 line 或 circle 拼；
5. 单 shape 图元超过 32 会吞掉后半段；
6. `set_items` 用整表重建，shape 容器范围必须盖住整块图形，否则被裁剪；
7. 无渐变能力，用纯色 + 多层低透明度块近似；
8. 点击回调里销毁 / 重建子树有 use-after-free 风险 → 一律 `theme.defer` 延后；
9. 子 label / shape 会拦触摸 → 可点区域最后压 `theme.hit`；
10. 隐藏控件用 `set_hidden`，**不要用负坐标移出屏幕**（内容溢出会让 LVGL 画滚动条）；
11. 全屏宽 1024 的面板会撑出横向滚动条，弹窗宽度留边距；
12. 切到 z 序更低的页面时旧页像素无人覆盖 → 必须走 `redraw_page` 强制重绘；
13. 中文宽度按 UTF-8 码点估算（中文 1、ASCII 0.55），不能按字节算；
14. 禁用 `sys.timerLoopStart`：固定周期投递会积压，触发 `task event too much`；
15. 主题切换用颜色注册表原位换色，不要走「关窗 → 重开」整页重建。

## 演示数据与实现状态

- 曲目、歌手、歌单、榜单、空调状态、包厢号均为 `mock.lua` 演示数据，不接真实曲库与音频；
- 播放进度按 1 秒步进推进，到末尾按已点顺序循环；点歌 / 顶置 / 删除只在内存生效；
- 已点列表初始 9 首，首页与分类页的「+」都追加到同一份 `mock.S.ordered`；
- 主题（深/浅 × 蓝/紫/青）、音量、亮度、空调参数只保存在内存，重启恢复默认；
- 已知现象：hzfont 在深色底上的白色小字（15~16 号）抗锯齿边缘会略带彩边，属字体渲染特性；如需减轻可把该处字号提到 17~18；
- 已完成：4 个 Lua 文件、九页 + 顶栏/侧栏/迷你条、快捷功能浮层、调音/空调弹窗、拼音搜索键盘、可拖进度与音量、三配色原位换色、切页残影修复；
- 实机待确认：长按 / 连点压力、RGB565 色偏、不同固件上 `airui.keyboard` 的候选栏高度。
