# 会议室门牌 · UI 设计工程（三套模板）

参考演示：B 站 `BV1Zg4y1W7r6`（10.1 寸会议室门牌，红白 / 商务蓝 / 天际线三套模板）。
目标硬件：Air8603 + 1024×600 RGB 屏 + GT911 触摸，最终用 AirUI（Lua）实现。

产物有两份：浏览器设计稿 `code/preview.html`（**所有可见控件都可点、点了都有反馈**）与 1:1 对应的 AirUI 实现（`code/*.lua`）。

## 打开方式

双击 `code/preview.html` 即可。画布固定 1024×600，窗口小于该尺寸时浏览器等比缩放页面。

快捷键：`1` / `2` / `3` 切换模板，`T` 切浅色 / 深色，`Esc` 关闭任意弹层。

## 主题（浅色 / 深色）

三套模板 + 六个弹层共用一套语义色，浅色 / 深色各一套值：

| 主题 | 天际线 | 商务蓝 | 红白表格 | 弹层 |
| --- | --- | --- | --- | --- |
| 浅色（默认） | 浅蓝白日光天空 + 淡蓝楼宇轮廓 | 浅蓝渐变 + 深蓝字 | 原红白门户风 | 近白底 `#FDFCFA` |
| 深色 | 深蓝夜空 + 窗灯 | 深蓝渐变 + 白字 | 暗红木色底板 + 深色行 | 深灰蓝底 `#1C242E` |

- HTML：顶栏「深色 / 浅色」按钮或 `T` 键，给 `#led` 挂 `.light` / `.dark`，只覆盖有差异的规则（`#led.light .tp-a{...}` / `#led.dark .tp-c{...}`）；城市剪影与通信塔按主题重新计算填充色后再重绘。
- AirUI：`theme.PALETTES = { light = {...}, dark = {...} }`，`theme.toggle_theme()` 就地覆写 `theme.C` 后 `PAGE.rerender()` 重建整页（颜色在构建时写死进控件属性，必须重建；切换发生在 `sys.timerStart` 里，避免在 LVGL 事件回调中销毁控件）。

## 三套模板

三套模板**共用同一份日程数据与状态**（当前场次、免打扰、门禁、预约都会跟着走），切模板不丢状态。

| 模板 | 名称 | 视觉 | 截图 |
| --- | --- | --- | --- |
| A | 天际线 · 企业蓝 | 白顶栏 + 黄昏城市剪影 + 圆形刻度表盘（「当前时间 / 剩余分钟」双面）+ 红色会议卡 + 蓝色底栏（会议详情 / 会议日程 / 预约 / 开门） | `docs/screens/01-tpl-skyline.png` |
| B | 商务蓝 · 二维码 | 大字号时钟 + 房间 / 状态双胶囊 + 当前会议 + 进度条 + 右侧伪二维码 | `docs/screens/02-tpl-business.png` |
| C | 红白表格 · 预约列表 | 红色顶栏 + 左栏（会议室 / 使用状态 / 门禁 / 会议日程 / 预约）+ 右栏全天会议表格（每行带「切换」）+ 下一场条 | `docs/screens/03-tpl-board.png` |

模板 B 底部三个圆点是模板指示器，点即切模板；顶栏「模板 · xx」按钮弹出模板选择面板。

城市剪影、二维码、图标全部是内联 SVG / CSS 生成（`repeating-conic-gradient` 做刻度，seeded 随机画楼宇与窗灯，`qrSVG()` 画带三个 finder pattern 的伪二维码），**不依赖任何 PNG**，便于后续用 AirUI shape 图元复刻。

## 日程与虚拟时钟

- 今天的固定日程（`DAY`）三场：`10:05-11:05` 关于多种交互方案讨论会议（8 人）、`11:17-12:17` Q4 产品规划评审（6 人）、`12:57-13:57` 客户接待·东证创新（10 人），每场带 3 条**会议内容**。
- **虚拟时钟** `VNOW`：从 10:35 起步，每 8 秒推进 1 分钟（`tick()` 里 `VNOW += 0.125`）。所以表盘「剩余时间」始终在 1~60 分钟之间真实递减，**不会出现 0 分钟 / 无会议**；走到本场结束会自动接上下一场，最后一场结束后回到当天首场循环。
- 日期取真实系统日期，时钟取虚拟时间，两者与日程自洽（上午的会议显示上午的剩余分钟）。
- 任意场次都能成为「正在使用」：日程面板里点任意一行，或红白模板表格行右侧的「切换」按钮，切过去时虚拟时钟会落到该场时段内（例如切到 12:57 那场，时钟变 12:58）。

## 设计规格

- 画布 1024×600，可点区域不小于 44×44（`.tool` 44px 高，表格行 58px，胶囊 70px）。
- **字号下限 16px**：正文/表格/提示 16，胶囊标题 22，房间名 44，A 表盘时间 38，B 大时钟 64，弹层标题 22、详情值 22。
- 模板 A 渐变：`#08182f → #0f3357 → #1c5c8c → #2d84b4`，暖色辉光 `rgba(255,116,86,.40)`，表盘底 `#16406c → #061a33`。
- 模板 B 渐变：`#0d1533 → #1a2b63 → #27398a → #3a53ab`，胶囊玫红 `rgba(214,52,86,.52)`。
- 模板 C 基底 `#f3efeb`，顶栏红 `#C62A30`，卡片白 `rgba(255,255,255,.92)`，正文 `#4B3B3B`。
- 状态绿 `#3BE08A`、门禁绿 `#1E8A5B`、红 `#C8343C`、主题蓝 `#1E7BD6`。

## AirUI（Lua）实现计划

1. `theme.lua`：三套模板语义色 token（skyline / business / board），沿用 `theme.cur` + `PALETTES` 结构，页面不写死颜色。
2. `page_skyline.lua`：白顶栏、城市剪影、刻度表盘（6° 一格，图元分批 ≤30）、红色会议卡、底栏 4 个 44px 按钮。
3. `page_business.lua`：大时钟、双胶囊、会议信息、进度条、右侧伪二维码（finder pattern 分块矩形）。
4. `page_board.lua`：红顶栏、左栏 4 卡 + 双按钮、右栏表头 + 3 行（每行含「切换」热区）。
5. `page_overlay.lua`：详情 / 预约 / 二维码 / 模板 / 门禁 / 日程六个弹层统一 `open_panel(id)`，遮罩与 Esc 关闭。
6. `main.lua`：1 秒定时 `sys.timerStart` 推进虚拟时钟（每秒 +1/8 分钟）刷新剩余、进度、状态文案；事件回调只改状态 + 触发重绘（切模板 / 切场次走「先关弹层再重建页面」）。

踩坑约束（与前面几个工程一致）：不用 PNG；shape 图元分批 ≤30；实心圆 width ≥1；坐标取整；容器不存 `.w/.h`；`exwin` 先 close 后 open；`bind_root` 用 pcall 保护；`font_load` 在 `airui.init` 之后且 cache_size 只能 128/256/512/1024/2048。

## AirUI 实现要点（code/*.lua）

- 单页方案：`theme.make_page(1, ...)` 一页里把三套模板全建好（`sp[1..3]`），切模板只 `set_hidden`，不 destroy 重建；六个弹层挂在同一个 `layers_root`（蒙层）下，一次只显示一个。
- 动态内容只改属性：`set_text` / `set_size`（进度条自己记账宽度 380）/ `set_color` 全部 `pcall` 兜底；表格行与日程行预建 6 个槽位（3 场固定会议 + 3 笔预约），无用槽位 `set_hidden`。
- 最小字号 16：`airui.font_load{ size = 16 }` 为基准，控件 `font_size` 放大（按钮 19、正文 16~18、大时钟 64、圆盘时钟 44）。
- 三套模板的「取消预约」入口（A 底栏 / B 工具条 / C 左栏 / 日程弹层底部）都走 `cancel_flow()`：选中了某笔就只删那笔，没选中就跳到日程提示先选；没有预约时按钮整组隐藏。
- 图标全部 `theme.icon_items()` 用 line / circle / rect 绘制，本工程新增 `qr` / `cal` / `clock` / `door` / `check` / `plus` 六个。
- 虚拟时钟 1 分钟 = 8 秒（`sys.timerLoopStart` 1000ms，每次 +0.125 分钟），驱动圆盘时钟、进度条、剩余分钟与「已结束 / 进行中」标签。
