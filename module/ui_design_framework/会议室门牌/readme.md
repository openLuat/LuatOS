# 会议室门牌 · 智能预约门牌（Air8607）

基于 **LuatOS + AirUI（底层 LVGL9）** 的 1024x600 单机门牌：开机即门牌主页，
左侧「有人/空闲 + 当前会议 + 剩余时间 + 今日议程」，右侧 7×12 本周预约网格；
点空白时段进预约页、点会议色块进详情页（密码校验后可编辑 / 删除）。
背景是 1024x600 东方明珠实景照片，前景卡片半透明压在照片上；默认**浅色**主题，
顶栏一键切深色（原地重建、不重启、偏好存 fskv）。顶栏「设置」进设置页：改会议室名称、
离线手动校时，两项都要管理员密码（默认 `8888`）。

## 功能与使用

### 顶栏

- 会议室名、座位与配套、日期（未对时加标记）、「设置」、「浅色/深色」胶囊、实时时钟。
- 深浅切换走 `router.retheme()`：换纱层颜色 → 延后 50ms 整页重建，即时生效、不重启，
  偏好写 fskv（键 `ui_door_mode`）。

### 状态卡（左）

- 使用中 / 空闲中大标签 + 当前会议（主题、部门、人数、负责人、分机、时段、工号）
  + 剩余时间进度条；空闲时直接给「立即预约」（今天 + 最近空档）。
- 无当前会议时展示「下一场」摘要，本周无预约时提示点右侧空白时段。

### 今日议程（左下）

- 今天最多 3 场，带部门色点与「场次 · 小时」统计，只读。

### 本周预约网格（右）

- 周一~周日 × 08:00-20:00 共 12 行；会议块按部门配色，选中列铺淡底，
  **当前小时是一条跨 7 天的淡色横带**，跨小时自动跟随。
- 点空白列 → 预约页（该天 + 该天最近空档）；点日期标题 → 选中该天；点色块 → 详情页。

### 预约登记页

- 左：工号 / 密码显示框 + 3×4 数字键盘；右：部门、负责人、主题、日期 chip
  + 开始时间 / 时长 / 人数三组步进器 + 实时校验提示。
- 工号输入满 4 位且在名录里命中时，自动带出负责人与分机；姓名与主题可点开词库键盘手填
  （负责人 6 字、主题 10 字上限）。
- 同一个入口参数视为「同一次填写」：切主题、去词库页返回都保留草稿；点「取消」清草稿。

### 预约详情页

- 左：部门标签、状态标签、时段面板、日期 / 状态 / 工号 / 会议室明细；
  右：编辑、删除、返回 + 预约规则。
- 第一次点编辑 / 删除只弹键盘，第二次点才做校验：**预约密码或管理员密码**都放行，
  方便管理员处理任意一条别人的预约。

### 门牌设置页（会议室名称 / 离线校时）

- **会议室名称**：门牌没有中文输入法，不做自由文本编辑，改为从 `app_state.M.room_names`
  的 8 个预设里挑一个（A栋 801/802/803、B栋 201/202、C栋 301、8F 培训室、3F 洽谈室）。
- **离线手动校时**：年 / 月 / 日 / 时 / 分五组步进器，**分钟 1 分钟一档（0~59 循环）**，
  右侧实时预览「11-19 周四 09:45」。
- 「保存设置」必须输入管理员密码，通过后才同时写入名称与时间，然后回门牌主页并提示；
  设置项存 fskv（`ui_room_name` / `ui_time_base_v2`），掉电重启后保持。
- 页面底部常驻「当前时钟 + 已校时 / 未对时」，颜色随状态在 `C.ok` / `C.warn` 之间切换。

## 预约规则（与 `app_state.lua` 一一对应）

| 项 | 规则 |
| --- | --- |
| 可约范围 | 周一~周日 × 08:00-20:00（`M.room.open_h / close_h`），时长 1~3 小时，人数 1~20 |
| 过去时段 | 本周已过去的日子整日不可约；今天从「下一个整点」起（`M.earliest_start`） |
| 冲突 | 同一天时间区间相交即冲突（`M.conflict`），步进时实时提示、提交时再拦一次 |
| 身份 | 工号 ≥4 位、密码 ≥4 位；工号命中 `staff.csv` 会被纠正为名录姓名并带出分机，未命中按访客保存 |
| 越界 | 开始 + 时长超过 20:00 直接拒绝 |
| 密码用途 | 只看不校验；编辑 / 删除要「预约密码 或 管理员密码」 |

## 时钟与校时（`clock.lua`）

时钟来源按优先级：

1. 硬件 RTC（`rtc` 库）→ 直接读 `os.time()`；
2. 无 RTC / `os.time()` 为 0 → 「手动基准 + `mcu.ticks()`」推算，精度足够门牌看时间；
3. 两者都没有 → 固定演示时间（2026-11-19 周四 10:20），界面不会出现 1970 年。

关键换算（改这块前务必看 `clock.lua` 头部注释）：

- `rtc.get / rtc.set` **永远是 UTC 秒**，而 `os.date` 会把 UTC 秒加上时区再格式化
  （`lua/src/loslib.c` 的 `os_date` 补丁）。所以写 RTC 前要扣掉时区偏置，读出来才不偏。
- `rtc.timezone(tz)` 的单位是 **1/4 小时**：东八区是 `32`，写成 `8` 会变成 UTC+2，
  整块界面直接偏 6 小时。
- 时区偏置用**固定参考点**测（`os.time(os.date("*t", REF_EPOCH)) - REF_EPOCH`），
  不能拿 `os.time()` 当参考：没校时前它是 0，偏置会被算成 0，首次校时整体偏 8 小时。
- `mcu.ticks()` 是 32 位有符号，约 24.8 天回绕变负，流逝秒按 0 兜底，避免基准往回拉。
- 掉电期间流逝无法补：无 RTC 时会停在上次校准值，主页日期行标「未对时」。
- 旧键 `ui_time_base`（时区换算偏了 2 小时）已作废，开机自动清除，需重新校时一次。

## 深色 / 浅色主题（默认浅色）

- 两套令牌都在 `ui_theme.lua`：`P.dark` / `P.light`，每套含 `c`（颜色）、`glass`（透明度/投影/描边）、
  `dept`（6 个部门色板）三张表，**键必须完全一致**，否则切主题后某处取到 nil 会直接报错。
- 卡片半透明：`glass.card_opa`（浅 206 / 深 186）、`glass.tile_opa`（226 / 214）等控制，
  照片从卡片后面透出来，靠 2px 描边 + 投影保证「卡片与背景可分辨」；
  背景照片前还盖了一层 `glass.veil` 纱层（浅色提亮、深色压暗），把文字对比度拉回可读区间。
- 部门色块：浅色用浅色 tint @214，深色用亮色 tint @96，两套都能一眼分辨。

## 背景照片

- `code/img/bg_tower.jpg` 是**已经裁成 1024x600 的基线 JPEG**（原图 1637x961 的 PNG 不要直接放进工程）：
  硬件 JPEG 解一帧要 ~1.2MB RGB565 缓冲，原尺寸解出来是 3MB 级别，真机会 OOM；
  LVGL 的 `fit="cover"` 是绘制时缩放，控件多大都要按原图尺寸解码，所以尺寸必须在仓库里定好。
- `wallpaper.lua` 把背景挂在 `airui.screen` 上只建一次，页面整页重建（切主题）不会重复解码；
  照片缺失或解码失败时自动退回「纯色 + 四团柔光」，界面不会黑屏。
- 换图：把新图处理成 1024x600 JPEG，覆盖 `code/img/bg_tower.jpg`，并把 `ui_theme.M.bg_image` 改成新文件名。

2. 功能与参考稿对齐：状态位、周视图预约网格、按部门配色的会议块、预约表单、详情 + 密码校验删除；
3. 会议室名称可从预设里改，**必须输入管理员密码 8888** 才能保存，名称与时间一次写入；
4. 离线可手动校准年月日时分（分钟 1 分钟一档），保存后顶栏时钟、日期行、此刻线**立即**按新值刷新，
   日期行不再显示「未对时」；
5. 默认浅色主题，顶栏一键切深色，偏好 fskv 记忆，下次开机保持；
6. 背景为 1024x600 实景照片，前景卡片半透明（描边 + 投影保证轮廓可分辨）；
7. 交互克制：单页内原地刷新，无全屏动画、无逐帧定时器（`ui_theme.motion.instant = true`）；
8. 门牌化取舍：中文输入换成预设 chip + 词库键盘，负责人自带分机，数字键盘只用于工号/密码；
9. 最小字号 16 号，主信息用 22/26/38/40 号，远看可读；
10. 空白列、色块、chip、步进器、键盘按键全部是**透明 container 热区**，
    没有 `airui.button` 描边残留、没有 `hide()/open()` 显隐；
11. 无任何时钟来源时退回固定演示时间（10:20 周四），界面不会出现 1970 年；
12. 提示条（toast）在切页后仍能显示：页面容器每次切页新建，会排在旧 toast 之上，
    所以切页时一律拆掉 toast、需要提示时再重建（`router.lua` 的 `do_go`）。

## 设计约束

- 所有控件经 `ui_widget.lua` 原语创建（`W.glass_card` / `W.text / W.text_mid` / `W.press_layer` /
  `W.chip` / `W.numpad` / `W.bar` / `W.button`），热区一律「透明 container + 闭包」，
  不用 `airui.button` 做热区。
- 显隐只改透明度 + 清文字 + 关命中，**禁止 `hide()/open()`**（真机 `open()` 恢复不回来）。
- 容器默认 `border_width = 0`；子控件坐标按**内容区**核算（外框 − 2×border），
  任何位移（含动画峰值）不得探出父内容区，否则 AirUI 会画滚动条。
- 文字一律走 `W.text / W.text_mid`（行高兜底，居中只取行高预算）；`airui.label` 没有 `font_weight`。
- 页面切换走 `ui_page` 约定：整页根容器在 `airui.screen` 上 `set_pos(-SW, 0)` 推出屏外**负方向**，
  正方向会在可滚动 screen 上出滚动条；切页动作延后 20ms，避免在点击回调里拆控件树。
- 定时器延迟 ≥5ms（`sys.timerStart(fn, 0)` 会静默失败）；userdata 方法一律冒号调用。
- toast 是 `airui.screen` 的直系子控件，绘制顺序 = 创建顺序，切页时必须拆掉重建。

## 定制

- 改配色 / 卡片透明度：只改 `ui_theme.lua` 的 `P.dark` / `P.light`（`c` / `glass` / `dept` 键必须一致）；
- 改背景图：见上面「背景照片」；
- 改会议室名称预设：`app_state.lua` 的 `M.room_names`；改管理员密码：`M.admin_pwd`；
- 改座位/楼层/开放时间：`app_state.lua` 的 `M.room`；
- 改部门 / 主题预设：`app_state.lua` 的 `M.depts`（顺序须与 `ui_theme` 的 `dept` 一致）、`M.topics`；
- 改人员名录：`code/staff.csv`（UTF-8 无 BOM，列序 `姓名,工号,分机,部门,部门代号`；
  表头写「工号,姓名」也能识别，解析按「哪一列是纯数字」自适应；部门按名称反查 `M.depts`，
  开机自动加载，缺失时用 `app_state.M.owners` 内置 5 条兜底）；
- 改时区：`clock.lua` 的 `TZ_QUARTERS`（单位 1/4 小时，东八区 32）；
- 改演示预约：`app_state.lua` 的 `M.seed()`；
- 接真实后端：把 `M.add / M.update / M.remove` 换成 MQTT 或 HTTP 下发，UI 层不用改；
- 关掉所有补间：`ui_theme.lua` 里 `M.motion.instant = false` 后自行确认无动画路径（默认已即时）。
