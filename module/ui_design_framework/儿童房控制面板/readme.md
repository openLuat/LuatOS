# 儿童房控制面板 · AirUI 工程（Air8607 / 1024×600）

给孩子用的房间中控：一屏四页（我的房间 / 灯光乐园 / 故事时间 / 星星奖励），底部四个大图标 Tab 互切，
**五套动漫主题运行中一键循环并记忆**，每套主题 5 个角色（点头像 / 大角色 / 弧上小人换人，房间名跟着变成
「巴斯的小房间」），顶栏名字点一下弹键盘改成孩子自己的名字。
参考 `docs/儿童房面板效果稿.html`（1024×600 五主题四页设计稿）1:1 移植到 LuatOS + AirUI。
所有设备数据为本地模拟，**没有真机外设**，只有 TF 卡可用来覆盖贴图。

- 硬件：合宙 **Air1603_A10**（引擎 AIR8607 10 寸，主控 Air1603），1024×600 RGB 屏 + GT911 电容触摸
- 开发方式：LuatOS（Lua 5.3）+ AirUI 1.3（LVGL 9 封装），脚本区直跑，无 exwin
- 资源：95 张 PNG 贴图（角色 / 装饰 / 图标），构建期由 `docs/gen_assets.py` 一次生成，运行时不联网
- 字号：40 / 26 / 22 / 20 / 16 五级，hzfont 最小 16

## 功能

- **五主题切换**：顶栏按钮循环（文案「玩具总动员 1/5 … 喜羊羊 5/5」），只换配色 / 贴图 / 角色 / 曲目，
  不改布局；当前主题写 fskv，下次开机保持。
- **角色系统**：每套主题 5 个角色，各自记忆上次选的是谁；房间名 = 角色名 + 主题后缀
  （的小房间 / 的小屋 / 的基地）；弧形槽位 `ARC = {-2,-1,1,2}`，切角色后整条弧前移一格，
  所以在同一位置连点能依次切遍 5 个角色。
- **名字编辑**：点顶栏名字 → 半透明遮罩 + 底部 AirUI 键盘（拼音 26 键，带 IME 预览框），
  1~6 个**字符**（不是字节），确认写 fskv 并即刻更新「早安，XXX」，点空白取消还原。
- **我的房间**：温湿度大读数、空调 18–30、四场景联动、四张设备磁贴（卡底随开关在主题浅色与白色间切换）。
- **灯光乐园**：色点 / 亮度（0–100，步进 5）/ 模式 / 投影 / 定时；预览圆底色按亮度混白，亮度越低越接近白。
- **故事时间**：每主题 5 首独立曲目与标签；播放时进度条 1 秒一跳，播完自动下一首或（单曲循环时）重播。
- **星星奖励**：任务打勾 → 副文案换、星数 +1；本周 7 柱按星期几高亮今天；闹钟 ±15 分钟回绕。
- **贴图降级**：TF 卡 `/sd/kidsroom/<name>.png` 优先，其次内置 `/luadb/<name>.png`，
  都没有就画同尺寸几何占位（不留空框、不报错）。

## 调试硬件环境

| 项目 | 说明 |
| --- | --- |
| 板卡 | 合宙 Air1603_A10（引擎 AIR8607 10 寸，主控 Air1603；`rtos.bsp()` 报 `Air1603`） |
| 屏幕 | 1024×600 RGB，`exd_jd9165ba_rgb.setup`，pclk = 50MHz，pin_rst = GPIO15，时序 H(140+20+1024+160) V(20+3+600+12) |
| 触摸 | GT911（I2C1 轮询，**TP_RST = GPIO72** / TP_INT = GPIO51；Air8607 底板是 GPIO14） |
| 背光 | PWM3 @1kHz，上电占空比 0，首帧刷出后 `setDuty(3, 90)` |
| 供电轨 | 5V_EN = GPIO12，9V_EN = GPIO56，**12V_EN = GPIO44（背光升压的输入，不拉高屏就是黑的）**，5VOUT_EN = GPIO52 |
| 其他 GPIO | SD_EN = GPIO74（高），AUDIOPA_EN = GPIO73（Air1603 板上拉高常供电），TP_RST = GPIO72 复位脉冲（低 20ms → 高 60ms） |
| 字库 | `airui.font_load{ type="hzfont", size=20, cache_size=2048, antialias=1 }`，必须在 `airui.init` 之后 |

## 内核固件

- 固件：Air1603 版本（实测日志 `LuatOS@Air1603 base 26.04 bsp V1030 64bit`），Luatools 按 **air1603** 配置
- 必需库：`airui`、`display`、`tp`、`i2c`、`gpio`、`pwm`、`hzfont`；主题 / 名字记忆用 `fskv`，TF 卡用 `fatfs`
- 键盘改名需要固件编入 `airui.textarea` + `airui.keyboard`；缺这两个组件时点名字只提示「本机不支持改名」，界面照常
- 烧录时勾选 **“添加默认 lib”**

## 烧录

1. Type-C 数据线接开发板 USB 口，Luatools 选 Air1603 固件（需含 AirUI + hzfont）；
2. 脚本区加入 `code/` 下**全部 16 个 `.lua`** 与 **95 张 PNG**（保持文件名，会被拍平到 `/luadb/`）；
3. 烧录后看日志：`I/main 儿童房面板已启动` 即首帧完成，`I/user.hardware 背光已点亮（PWM3 duty=90）` 即背光打开；
4. 上电先暗、随即出画面是正常的（背光刻意晚于首帧）。

- **构建期拆格，不在运行期裁切**：960×640 的套图整张解码要 1.2MB，直接超真机 1MB 图片缓存；
  `gen_assets.py` 按格切 320×320 再降采样，运行时零裁切。
- **单 IDAT**：真机硬件 PNG 解码只认单个 IDAT 块，PIL 默认分块，脚本已重编码；
  缩放走预乘 alpha，避免透明边缘发黑。
- **预算是按 `w*h*2` 记账**：单主题同屏峰值 ≈ 角色 5×58KB + 装饰 8×18KB + 图标 8×10KB ≈ 500KB。
- 全量 95 张、1703 KB；`python docs/gen_assets.py --check` 可随时体检。
- 图标来自 [Twemoji](https://github.com/jdecked/twemoji)（Twitter/X，**CC-BY 4.0**），已下载为本地 72×72 PNG。

## 定制

- 改设备 / 场景 / 曲目 / 任务 / 闹钟默认值：只改 `app_state.lua`
- 改配色 / 字号 / 圆角：只改 `ui_theme.lua` 的 `P` 表，同时同步效果稿的 CSS 变量
- 加 / 换主题：`ui_theme.lua` 加一组 `key / name / suffix / reward / cast / songs / c`，
  再跑 `gen_assets.py` 生成对应的 12 张贴图
- 换角色贴图：只替换 `code/ch_<theme>_<i>_big|sm.png`（同名同尺寸即可），或放进 TF 卡 `kidsroom/`
- 改列宽：按上面「列边界」表改 `page_*.lua` 里的卡片 `x / w`，效果稿同步改（两边必须一起改）

## 已知限制

- 所有设备数据（温湿度、灯光、投影、播放、任务）均为本地模拟，没有真实串口 / 网络设备；
  接真设备只需替换 `app_state.lua` 里的读写函数。
- TF 卡贴图覆盖未在真机上实测（只验证了代码路径与降级）。
- 装饰贴纸从 96px 缩到 24px 是软件缩放，若真机帧率不足，优先给装饰贴纸单独出 48px 版本。
- fskv 只存主题 / 名字 / 每个主题的角色下标，设备开关状态不落盘（重开机回到默认：全开、投影 30 分）。

## 踩坑要点（务必遵守）

1. **`airui.screen` 只能挂一个直系子容器**：屏幕是 flex 容器，同级挂多个会被压缩（实测只剩顶栏，
   页面与 Tab 全消失）→ 先建一张 `scrollable=false` 的整屏 MAIN。
2. **require 必须字面量，且一行一个**：打包按静态依赖裁剪；依赖扫描又是**按行**抓 `require "xxx"`，
   四个写在一行会被拼成一个模块名，烧录报「缺少 page_room", require "page_light"…」。见 R11。
3. **不要用 `obj:is_destroyed()`**：本固件对活着的 container 也返回 true，会把点击全挡掉 → 用 epoch 代次。
4. **`airui.image` 的 `fit` 默认是 `center`**（不缩放、只居中裁剪），w/h 只是裁剪框：
   72px 图标塞进 28px 胶囊会变成一块纯色 → 统一传 `fit = "contain"`。
5. **减号必须写 ASCII `-`**：hzfont 没有 U+2212 的字形，真机上是方框（本次实测踩到，见 R12）。
6. **`exd_jd9165ba_rgb.setup` 可能只返回 `true`**（不带 info 表）：不能 `info.backend` 直接取，
   会 `attempt to index a boolean value` 并终止启动，表现为屏不亮。
7. **12V_EN（GPIO44）不拉高背光不亮**：背光升压的输入是 12V 轨，只配好 LCD 时序和 PWM3 也不亮。
8. **`E/pwm setup ch 3` 不是错误**：本固件 `pwm.setup` 里有句无条件的调试日志，成功也会打。
9. **切主题只重建当前页（懒页）**：真机建 4 页要 1.1s；其余页由 `fill_later()` 单链 `timerStart` 补
   （开机那次延 1.2s 别抢首帧）。代价是页面 `create()` 必须能“迟到创建”：只读 `app_state`、结尾 `refresh()`。
10. **中文按字符数算，不按字节**：`#s` 是字节（一个字 3 字节），`#name > 6` 会把「小星星12」截成「小星」。
11. **键盘要开 `preview = true`**：textarea 是离屏的（只借文本缓冲），没有预览框孩子就是盲打；
    键盘带预览后总高 344px，遮罩提示必须写在 y < 250。
12. **`airui.keyboard` 只能用 `show()/hide()`**（固件弹层，没有 alpha 通道），是 R2 的唯一例外。
13. **一行只写一个定时器/不写帧循环**：定时器延迟 ≥5ms，禁止 `timerLoopStart` 做帧循环；
    刷新统一走一条 `sys.wait(500)` 值守循环，每跳 `pcall`。
14. **销毁 / 重建必须在事件外**：点击回调里 `W.defer(fn, 30)`，并先 `KB.destroy()` + `W.clear_twinkle()` +
    `W.bump_epoch()`，否则旧热区的回弹定时器会打到已销毁控件上。
15. **模拟器连点要间隔 ≥0.3s**：`agent-ctl` 注入太密会丢事件（第二下必丢）。
