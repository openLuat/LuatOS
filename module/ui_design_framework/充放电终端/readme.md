# 充放电终端

基于 **LuatOS + AirUI（底层 LVGL9）** 的 10 寸充放电终端单屏界面：开机自检后直接进入主界面，
一屏同时表达「输入充电」与「对外放电」两条链路——电量、双向功率、四个输出端口的开关与状态，
顶栏一键切换暗色 / 亮色主题。

## 调试硬件环境

| 项目 | 说明 |
| --- | --- |
| 主控 | Air8607（SoC：Air1603），板级初始化集中在 `code/app/app_main.lua` |
| 屏幕 | 合宙官方 AirLCD_1100 10.1 寸 RGB 屏，1024x600，免初始化 IC（JD9165BA，无寄存器序列） |
| 触摸 | GT911 电容触摸（I2C1 轮询，TP_RST=GPIO14 / TP_INT=GPIO51），AirLCD_1100 自带 |
| 背光 | PWM3（1000Hz），界面搭好后再拉到 100% 点亮，防上电花屏 |
| 其他引脚 | GPIO17 = LCD 供电使能（低有效）；GPIO15 = 显示使能 / 复位 |
| 备选板级 | 本工程只适配 10 寸 Air8607，未内置 7 寸 HX8282（Air8601）板级 |
| 供电 | USB 供电即可，屏幕由开发板排线供电 |

## 内核固件

- 固件文件名：`LuatOS-SoC_V1030_Air1603_102.soc`（Air1603 / 1601 / 1602 同编号固件内容一致）
- 烧录工具：合宙 **Luatools**（选中上述 .soc 固件 + 本工程 `code/` 目录脚本，底层下载即可）
- 脚本区/文件系统：102 号固件为脚本区 4096KB / fs 1536KB，本工程远小于该预算
- 工程依赖的固件内置库：`airui`、`display`、`tp`、`i2c`、`gpio`、`pwm`、`hzfont`
  （中文矢量字库，字号 12~255 全覆盖，本工程最小字号 16 号）
- 主题偏好未做持久化（未使用 `fskv`），重启后回到暗色

## 功能与使用

### 顶栏

- 左侧品牌标识；右上角三态状态卡片（充电中 / 放电中 / 保持）显示当前充电功率，点击可切换充电开关
- 状态卡与时钟之间是**主题切换胶囊**：点击在暗色 / 亮色之间切换，整屏按新色板原地重建、立即生效（不重启）
- 最右为实时时钟（1Hz 刷新）

### 电池电量主卡（本项目重点）

- **充电气泡动画**：充电状态下电池图内部的液体会持续有气泡上浮，是「正在充电」最直观的表达
  - 14 个独立气泡，横坐标、半径（2~5px）、速度、横摆幅度与相位各不相同，不会排成队列
  - 速度按像素/秒恒定（r=2 → 38px/s，r=5 → 50px/s），电量高低都不会让气泡忽快忽慢，单帧位移稳定在 1.1~1.5px
  - 液面裁剪：气泡升到当前液面处逐渐淡出、底部淡入，无跳变；电量低时气泡存活路程自然更短
  - 只在充电时存在：放电中与保持（满电/待机）状态下气泡完全停止，并停止该区域逐帧重绘
- 电量百分比大字、可用容量、健康度环、循环次数与电芯温度

### 功率卡与端口卡

- **实时功率卡**：输入功率与输出总功率，下方功率曲线按 30fps 实时走动
- **输出端口卡**：USB-C1 / USB-C2 / USB-A1 / USB-A2，点击切换该口输出；主口整行展示，三个子口并排

### 底栏

- 多重保护标识与固定标签：过流 / 过压 / 过温 / 短路 / 过放

## 三态判定

| 状态 | 判定条件 | 气泡 | 输入功率 |
|------|---------|------|---------|
| 充电中 | 未满电且充电开关打开 | 有 | 显示实测值 |
| 放电中 | 未充电且存在端口输出 | 无 | 0W / 未连接输入 |
| 保持 | 电量已满，或无充电无输出 | 无 | 0W / 未连接输入 |

## 验收要点对照

1. UI 效果见 `docs/充放电终端UI效果稿.html`（浏览器打开即是 1024x600 舞台，可切暗/亮）；
2. HTML 与真机使用同一套视觉令牌（`ui/theme.lua` 的 `M.c` ↔ HTML CSS 变量），效果高度相符；
3. 功能克制：单屏、无多页轮询，仅功率曲线与气泡两处动画，主循环 30fps、文字 5Hz、时钟 1Hz，硬件无卡顿；
4. 零学习成本：所见即可点——状态卡片切充电、端口卡片切输出、主题胶囊切配色；
5. 最小字号 16 号（`theme.lua` 的 `M.f.sub / M.f.mini` 均为 16），中文字号覆盖 16/18/22/26/40/64；
6. 交互反馈全部即时到位，主题切换为原地重建、立即生效（不重启，不持久化）；
7. 三态与端口的联动逻辑见「三态判定」一节，气泡仅充电时存在；
8. 硬件环境与内核固件文件名见上文两节。

## 设计约束

- 所有控件经 `theme.lua` 封装创建（`box` / `label` / `text_mid` / `card` / `hot` / `shape`），不裸调 `airui.*` 做热区与显隐
- 容器默认 `border_width = 0`，内容区等于外框；确需描边时子控件按 `w - 2×bw`、`h - 2×bw` 摆放
- 中文字号不小于 16；hzfont 不含「·」「°」，单位与分隔一律用 ASCII，避免渲染成空心框
- 动画图元全部走 `fx` 图元池，每帧重建不产生 GC
- 事件回调内不得直接销毁控件，须经 `T.defer` 延迟到本帧渲染之后重建

## 定制

- 改配色：只改 `ui/theme.lua` 的 `PALETTES.dark / PALETTES.light`（色板键值原地覆盖，切主题不断引用）
- 改字号：`ui/theme.lua` 的 `M.f` 与 `M.font_sizes` 需同步（字号在 `app_main.lua` 中一次载齐）
- 改布局：`ui/theme.lua` 的 `M.l` 定义各区块外框，`ui_home.lua` 内为逐像素摆放
- 改节拍：`ui/theme.lua` 的 `M.perf`（`frame_ms / text_ms / clock_ms`）
- 接入真实数据：改 `ui_home.lua` 的 `S` 数据表与 `update_*` 函数（当前为模拟充放电曲线）
