# 共享储物柜中控（AirUI 真机工程）

把 `docs/共享储物柜中控UI.html` 原型移植成可在 **Air8607 + 10.1" RGB 屏** 上直接烧录运行的 Lua 工程。
视觉与原型同一套令牌：暖橙取件 / 青绿存件 / 米白底，屏幕基准 **1024×600（RGB565）**。

## 1. 目录

| 路径 | 作用 |
|---|---|
| `code/main.lua` | 入口：密度 → 硬件 → 建首页 → 开背光 |
| `code/hardware.lua` | 板级初始化（`M.profile` 选 8607 10.1" / 8601 7"），两个 profile 同为 1024×600 |
| `code/exd_jd9165ba_rgb.lua` | Air8607 屏驱动（JD9165BA，免初始化序列），官方扩展库原样复制 |
| `code/lcd_hx8282_10in.lua` | Air8601 7" 屏驱动，**只在 8601 profile 下才会被 require**（文件顶层有 `pins.setup(43,"GPIO13")`） |
| `code/tp_gt911.lua` | GT911 触摸，末尾 `airui.device_bind_touch()` 绑定到 AirUI |
| `code/ui_theme.lua` | 设计令牌：屏幕分区、色板、字号档、圆角 |
| `code/ui_widget.lua` | 安全原语：内容区登记 + 越界收敛 + 文本 / 热区 / 图元 / 等宽数字 |
| `code/page_locker.lua` | 页面框架：共享状态、延迟重建、顶栏 / 底注、路由分发 |
| `code/page_entry.lua` | 首页（取件 / 存件两张大卡）、取件码输入屏 |
| `code/page_flow.lua` | 存件流程三屏：选规格 / 开门 / 结果 |
| `docs/共享储物柜中控UI.html` | 视觉基准原型（含 `img/door-open.svg`） |

产物只有 `code/` 会被烧录，`docs/` 留在仓库里做设计存档。

## 2. 烧录

1. Luatools → 项目管理 → 新建项目，**代码目录选本工程的 `code/`**（不要把 `docs/` 选进去）。
2. 固件选 Air8607（Air1603）的 LuatOS-SoC 全功能固件，需带 `airui` + `display`(或 `lcd`) + `hzfont` + `tp` + `i2c` + `pwm`。
   `airui` 版本要求 ≥ 1.2.0（`airui.device_bind_touch`、`airui.container` 的 `scrollable` 键、`airui.shape`）。
3. 屏幕参数保持 1024×600、RGB；下载后自动执行 `main.lua`。
4. 换 Air8601 + 7 寸：只改 `code/hardware.lua` 顶部 `M.profile = "air8601_7i"`。

## 3. 交互路径

```
首页 ─┬─ 取件 → 输入 4 位取件码（演示期只校验位数，满 4 位自动提交，也可按「确认」）
      │            └ 开门屏（A6 号柜）→ 完成
      └─ 存件 → 选规格（S/M/L，卡片标"能装什么"+ 单价 + 余格）
                   └ 开门屏（A6 号柜）→ 完成
```

- **不做预付**：确认存件后直接开柜，费用按实际存放时长在取件时结算。
  因此既没有时长预选，也没有支付屏，更不显示预估金额——用户此刻无法预知要存多久。
- 每屏右上 / 底部都有返回或完成，`完成` 会复位规格与已输入码。
- 顶栏时钟每分钟更新一次，走独立 `sys.taskInit` 节拍（20s 轮询，只在分钟变化时写）。
- 顶栏主题钮（太阳 / 月牙图标 + 当前「亮色」/「暗色」）切换主题：只改色板键值 + 整页重建（不换表、不换结构），
  已输入的取件码与选中的规格都在 `M.S` 里，重建后自动恢复；选择存 `fskv` 的 `ui_mode`，重启保持。

## 4. 接真实业务要改的地方

| 位置 | 现状 | 替换为 |
|---|---|---|
| `page_locker.M.submit()` | 4 位输满就开门，不做码值比对 | 平台下发的取件码校验 + 开柜指令 |
| `page_locker.M.SPECS` | 三档规格：名称 / 能装什么 / 单价 / 余格 | 后台返回的柜格余量与规格文案 |
| `page_flow.lua` 规格屏「确认存件」 | 直接按演示值 `A6` 开门 | 下发开柜指令，等柜锁回读后置 `S.box_no` 并 `P.nav("open")` |
| 开门屏 `我已关好门` | 纯 UI 跳转 | 在这里下发柜锁开 / 关指令，并等待锁状态回读 |
| 取件码屏数字键盘 | 手输 4 位，`push()` 是唯一输入入口 | 需要时接扫码枪的码流，仍走 `push()` |

## 5. 布局约定（改界面前必读）

- 屏幕分区在 `ui_theme.LAYOUT`：顶栏 64、内容区 y=64 高 480、底注 y=544 高 56。所有页面只往 `body`（1024×480）里摆。
- `ui_widget` 建容器时即登记内容区 `cw/ch = 外框 − 2×border_width`，之后每个子控件按父登记值收敛；
  越界不会画滚动条，而是收缩尺寸并打一条 `[uiw] 越界已收敛 <tag> right=../.. bottom=../..`。
  **真机日志里出现这条就说明坐标写错了，要回头改数字，不要靠收敛兜着。**
- 容器一律 `scrollable = false`（第一道防线），且无描边时不传 `border_color`（防幽灵框）。
- 热区 = 透明 container + Lua 闭包，不用 `airui.button`；显隐不用 `hide()/open()`，切页是整页销毁重建（延迟 20ms，合并连续点击）。
- **会变的数字**（时钟、取件码）一律走 `W.num` 等宽格，禁止整串 `set_text`——真机 hzfont 数字不等宽，改值会左右跳。
  规格卡上的单价与余格是静态值，不进 `W.num`；若日后接后台余量刷新，要保持等宽就得换成 `W.num`。
- 中文最小字号 16；`label` 没有 `font_weight`，层级只靠字号 + 色阶。
