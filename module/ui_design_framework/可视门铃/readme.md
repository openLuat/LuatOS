# 可视门铃室内机 · AirUI 工程（Air8603）

与 `doorbell_ui/preview.html`（1024×600）**1:1 对应**的实机复刻：
浅蓝白底色 + 蓝色主调 + 橙色强调，六屏一机（首页 / 通话 / 监视 / 门口取景 / 消息 / 设置）
加全局弹层与 toast。**工程零 PNG 贴图**，全部图标用 shape 图元自绘。

- 硬件：合宙 Air8603（Air1603 主控，1024×600 RGB565 电容触摸屏）
- 底层固件：需含 **AirUI V1.1.6+ 与 hzfont 中文字库**
- 开发方式：LuatOS (Lua 5.3) + AirUI（基于 LVGL 9.4 封装）
- 数据：**虚拟演示数据**（时间取 `os.date`，其余为屏内状态对象 `S`）
- 字号：正文 16~20，标题 20~22，首页时钟 84（**最小 16**）

## 页面结构（与 preview.html 逐屏对应）

| 屏 | 内容 | 交互 |
|----|------|------|
| 首页 · 四宫格 | 通话 / 消息 / 监视 / 设置 四个大图标瓷贴 + 状态栏（时间、音量、用户）+ 分页圆点 | 点瓷贴进对应屏；**左右滑动**切到场景屏 |
| 首页 · 场景 | 一屏四宫格：在家 / 外出 / 睡眠 / 自定义（睡眠橙色） | 点场景 → 选中高亮 + toast 提示 |
| 通话 | 住户/房间号码显示 + 12 键数字键盘 + 功能轨（呼叫 / 挂断 / 静音等） | 按键写入号码、退格、发起呼叫 |
| 监视 | 摄像头画面占位 + 摄像头切换芯片（多路） | 点芯片切摄像头，画面与标签同步 |
| 门口取景 | 门口画面 + 开锁 / 对讲 / 麦克风 | 点开锁 → toast；麦克风可切静音 |
| 消息 | 消息列表（未读角标） | 进入即清未读、圆点联动刷新 |
| 设置 | 广播音量（slider）/ 屏幕亮度（slider，**真调背光 PWM3**）/ 显示主题 / 离家布防（switch）/ 电梯呼梯 / 关于本机 | 拖动即时生效，行点击进弹层或切主题 |

首页两屏用 `airui.tabview(switch_mode="swipe", tabbar_size=0)` 实现左右滑动，
分页圆点用两组 `set_hidden` 切换长短形态。

## 烧录步骤（Luatools）

1. 电脑安装 [Luatools](https://docs.openluat.com/) 及 Air8603 板载 USB 转串口驱动；
2. Type-C 数据线接 Air8603 的 **USB2** 口；
3. Luatools 新建项目，选择 Air1603 对应固件（Air8603 默认固件即可）；
4. 脚本区添加 `code/` 下全部 `.lua` 文件（本工程无 img 目录），并勾选 **"添加默认lib"**（exwin 是扩展库）；
5. 烧录运行：首页瓷贴进各屏，标题栏返回；首页左右滑动切场景屏。

## 实现说明

| 机制 | 做法 |
|------|------|
| 切屏 | **6 屏一次性建好，切屏只 `set_hidden`**，绝不 destroy + 重建（重建留残影、画面错位且慢） |
| 状态 | 文件级 `S` 对象，字段与 preview.html 的 `S` 一一对应（屏名 / 页码 / 音量 / 亮度 / 布防 / 场景 / 号码 / 麦克风 / 摄像头 / 未读 / 消息清除） |
| 局部刷新 | `R` 存各控件引用，状态变化只 `set_color / set_items / set_text / set_pos`，不重建子树 |
| 弹层 | 每次新建，挂在 root 上盖住所有屏；回调统一 `defer()`（`sys.timerStart(fn, 30)`）延迟一拍再关 |
| 背光 | 屏幕亮度 slider → `set_backlight(v)` 改 **PWM3 占空比**，60ms 节流避免高频刷 PWM 闪烁；`setDuty` 只在 start/open 态生效，兜底 setup + start |
| 图标 | `theme.icon` 按设计稿用 line / circle / rect 绘制，弧线一律多段折线 `ARC()` / `ELL()` 拼接，line 开 `round_start / round_end` |
| 主题切换 | `theme.cur` + `theme.PALETTES`，`toggle_theme()` 就地覆写字段，切完整页重建（首页左上角与设置页"显示主题"两处入口） |

## 踩坑要点（来自 theme.lua 头部，实机已验证）

1. `label` 文字在控件框内**顶部对齐** → `theme.txt` 统一下移 y、h 收紧到 `size*1.28`，调用方按"视觉块"给坐标；
2. 只有 `container` 有 `set_hidden / hide / open`，`label / shape / button` 没有 → 屏切换用"预建 + set_hidden"，**不要 destroy + 重建**（留残影、画面错位且慢）；
3. `shape` 的 line 支持 `round_start / round_end`（圆头），图标务必开启，方头又硬又糙；
4. `slider` 轨道粗细由控件高度和 `style.pad` 决定：`h=24 + pad=8` → 轨道 8px（等同 html 的 `.track`）；不设 pad 会变成 24px 粗黄油条；
5. 所有坐标 / 半径必须取整，小数坐标图元不显示；
6. 弧线一律多段折线 `ARC()` / `ELL()` 拼接（`arc` / `ellipse` 图元在本批固件上不可靠）；
7. 中文字宽 ≈ 3 字节/字，按 `#s` 估算会把元素撑开一倍（`text_w()` 按 utf8 码点折算）；
8. 字号下限 16（正文 16~20，标题 20~22，首页时钟 84）；
9. 子控件不能超出父容器（会被裁剪）→ 首页分页圆点每个都独立建在屏上；
10. 点击回调里销毁 / 重建子树有 use-after-free 风险 → 一律 `sys.timerStart(fn, 30)` 延迟到事件外执行。
