# AirUI 应用层开发规则（真机 UI）

> 本文件管「用 AirUI 写界面」，`components/airui/AGENTS.md` 管「改 AirUI 库本身」，互不覆盖。
> 这些规则全部来自 `home_control_demo`（1024×600 / Air8607 / LVGL9）在真机上逐条踩出来的坑，
> **不是风格偏好，是硬约束**：违反其中任何一条，画面就会出现框线、滚动条、点不动、拖尾。

## 0. 复用方式（新项目三步）

1. 复制三个文件作为基线：`ui_widget.lua`（安全原语）、`ui_theme.lua`（设计令牌）、`main.lua`（启动骨架）；
2. 把本文件放到新项目根目录，改名 `AGENTS.md`（AI 编码工具会自动读取）；
3. 新会话第一句话直接贴：

```
做一个 AirUI 界面项目，先读根目录 AGENTS.md（应用层 UI 规则）和 ui_widget.lua，
所有控件只能通过 ui_widget 的原语创建，禁止直接调用 airui.button 做热区、
禁止 hide/open 做显隐、禁止子控件超出父容器内容区。
```

## 1. 五条设计铁律

1. **层级靠明度**：浮起 = 白 + 低透明度（卡片 38 / 磁贴 26）；凹陷 = 深墨 + 高透明度（内嵌条 150）；
2. **焦点只给一种颜色**：主色（`C.pri`）只用于「选中项 / 当前数值 / 焦点竖条」三处，其余一律中性色；
3. **动作按钮不铺白底**：用幽灵按钮（透明底 + 彩色文字），白底块在暗色界面上等于灯箱；
4. **装饰只做信息增强**：趋势线、比例点阵、分隔虚线可以；纯纹理不加（低对比界面里就是噪声）；
5. **交互反馈不上动画**：按下由热区提亮即时反馈，状态一帧到位；动画只留给不响应用户的场景。

## 2. 十二条工程铁律

| # | 规则 | 反例（真机后果） |
|---|---|---|
| R1 | 热区一律用**透明 container + Lua 闭包开关**（`W.press_layer`），不用 `airui.button` | button 默认 2px 描边清不掉 → 屏幕上「透明容器框」 |
| R2 | **禁止 `hide()/open()` 做显隐**，只用 `set_color(color, 0)` + 清文字 + 关命中 | `open()` 真机恢复不回来 → 控件永久藏死、「调」点不开 |
| R3 | 复合控件显隐要**逐个子容器登记**（底板 / 竖条 / 轨道 / 按钮底 / 文字） | 父 alpha 归零不带走子容器 → 底部留一块幽灵圆角 |
| R4 | 不需要描边的容器**不传 `border_color`**，只传 `border_width = 0`；卡片框线由 `theme.glass.card_edge` 统一开关 | 描边不吃 opacity，背景透明后框线仍在（幽灵框） |
| R5 | 子控件坐标按**内容区**核算：`内容宽 = 外框宽 − 2×border_width` | 气候面板 296 当 356 用 → 立刻横向滚动条 |
| R6 | 文字一律走 `W.text`/`W.text_mid`：行高 = 字号×1.75+2，居中只取行高预算 | 声明 h 小于行高 → label 向下探出 → 滚动条 |
| R7 | 任何位移做**边界预算**：动画全程子控件不得探出父内容区；子控件**禁止 set_pos 到父容器内容区外暂存**。唯一例外：**`airui.screen` 直系整页根容器**可整体 `set_pos(-SW,0)` 移到屏外**负方向**做页面切换（screen 可滚动，正方向右/下会出滚动条，负方向左/上被裁剪且不产生滚动） | 屏外暂存让可滚动容器四向都出滚动条 |
| R8 | 定时器延迟 **≥5ms**；`sys.timerStart(fn, 0)` 会静默创建失败 | 第一个磁贴永远停在预备态、永不动画 |
| R9 | userdata 方法**一律冒号调用**；调试期先 `local ok, err = pcall(...)` 打印再包 | 点调用异常被 pcall 吞掉 → `set_disabled` 实际没执行 |
| R10 | 弱化底色必须显式 `set_color(color, opa)`；容器创建即满 alpha | 忘了设透明度 → 整块纯白（房间 Tab 曾是纯白块） |
| R11 | 图形按内容区定尺寸；`chart` 只吃整数；轴能关就关 | 宽 356 → 滚动条；`x_axis.enable=false` 无效 → 图表下方一条横线 |
| R12 | `airui.label` **没有 `font_weight`**；层级靠字号 + 颜色，粗体需 hzfont 粗体字库 | 传 `weight = 700` 是空转，全界面字重一样、层级发平 |
| R13 | 多页面切换走 `ui_page`：每个页面 `mod.create(root)` 挂到整页根容器上，显隐用整页根容器 `set_pos(0,0)/(-SW,0)` 推入/推出屏外**负方向**，**不要** hide/open/set_hidden 切页 | 用 hide/open 切页真机恢复不回来；推出屏外用正方向(右/下)会在可滚动 screen 上出滚动条 |

## 3. API 黑名单

| 禁用 | 原因 | 替身 |
|---|---|---|
| `airui.button` 做热区 | 2px 描边 / 有 hide 没 open / `set_disabled` 不稳 | `W.press_layer`（透明 container + 闭包） |
| `obj:hide()` `obj:open()` | 真机 `open()` 无法恢复 | `W.glass(obj, color, 0)` + 清文字 + 关命中 |
| `set_pos` 到**普通容器**外暂存 | 可滚动容器四向都出滚动条 | 原位 alpha 显隐；**整页切换例外**：screen 直系整页容器移到屏外**负方向**安全（见 R7/R13），正方向会出滚动条 |
| `airui.container{ border_color = ... }` 随手加 | 描边不透明，永远可见 | 只传 `border_width = 0` |
| `font_weight` | 参数表里不存在 | 字号 / 色阶 / hzfont 粗体字库 |
| `chart:set_values` 传小数 | 只接受整数 | 基准值 + 整数偏移 |
| 期望 `shape` 画弧 | 只有 line/circle/ellipse/rect | 环形进度用多段 line，或改点阵/条状 |

## 4. 必用原语（`ui_widget.lua`）

| 原语 | 用途 | 关键保证 |
|---|---|---|
| `W.glass(obj, color, opa)` | 唯一的底色/透明度入口 | 兼容 `set_color` 与 `color_opacity` 两套 |
| `W.text / W.text_mid` | 所有文字 | 行高兜底、居中不探出 |
| `W.glass_card` | 玻璃卡（卡片 + 假投影 + 反光条） | 投影层 +2px 防零余量贴合；描边走 `card_edge` |
| `W.press_layer` | 所有点击热区 | 零描边、闭包开关、90ms 提亮回弹、不依赖固件方法 |
| `W.chip` | 选项卡/档位 | 首次上色不会漏（`active = nil` 哨兵）、支持配色覆盖 |
| `W.shape / W.chart` | 图形/图表 | 组件缺失返回 `nil`，调用方须能回退 |
| `W.tween` | 补间（默认即时模式直落终态） | 一个开关控制全局动效 |

## 5. 烧录前自检（逐条打勾）

- [ ] 每个子控件 `x + w ≤ 内容宽`、`y + h + 位移 ≤ 内容高`（含动画峰值）
- [ ] 面板四边**没有任何**超出内容区的 1px（会变成滚动条细线）
- [ ] 需要隐藏的控件：显隐只改 alpha，且所有子容器都已登记
- [ ] 每个可点区域都能点中；隐藏态点它无效（不能吃掉下层触摸）
- [ ] 屏幕上看不到「四周一圈灰线」和「卡片底边一条长横线」
- [ ] 图表区域内没有多余的水平轴线
- [ ] 文字没有被裁切（行高 ≥ 字号×1.75）
- [ ] 点击后画面**在松手瞬间**就完成变化，没有排队拖尾
- [ ] 快速连点 20 次不死机、无残影、无累积偏移
- [ ] 切走再切回：所有隐藏元素重新出现时位置与配色正确

## 6. 线状伪影 30 秒判别

| 线在哪 | 根因 | 一键验证 |
|---|---|---|
| 控件四周（含底边） | 容器描边 | `border_width = 0` 再烧 |
| 容器底边极细线、随内容滚动 | 横向滚动条 | 内容缩 2px |
| 图表下方横线 | X 轴线未关 | 注释 chart |
| 卡片顶部 2px 亮线 | 反光条（设计元素） | `hl_opa = 0` |
| 文字下方短横线 | 2px 指示条 / label 被裁 | 加 4px 高度 |

## 7. 新项目骨架

```lua
-- main.lua：先有背景 → 再有卡片 → 最后填内容；每层都用 kit 创建
local W = require("ui_widget")
local T = require("ui_theme")

local function ui_main()
    airui.init()
    -- 1) 背景（静态深空 + 柔光斑，替代做不到的 backdrop blur）
    -- 2) 卡片：W.glass_card{...}，尺寸按内容区反推
    -- 3) 内容：W.text / W.press_layer / W.chip，禁止裸 airui.*
    -- 4) 数据刷新：paint() 只改文字与颜色，不做大面积位移
end
sys.taskInit(ui_main)
```

## 8. 排查顺序（出问题时）

1. 先看**是不是多了一条线**：走第 6 节判别表；
2. 再看**是不是点不动**：热区是不是 button、是不是被上层 alpha=0 容器盖住；
3. 再看**是不是没显示出来**：是不是被 hide 过、是不是 alpha 忘了设、子容器是否漏登记；
4. 最后看**是不是位置/尺寸算错**：按内容区（外框 − 2×border）复算，别按外框。
