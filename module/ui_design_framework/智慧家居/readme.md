# 玻璃之家 · 全屋智能中控（智能家居）

玻璃拟态（Glassmorphism）风格的全屋智能中控单页 Demo：开机直接进入主界面，
顶栏一键切换深色 / 浅色主题，房间 Tab + 气候 / 设备矩阵 / 安防三栏 + 底部场景 Dock。

## 调试硬件环境

| 项目 | 说明 |
| --- | --- |
| 主控 | Air8607（SoC：Air1603），默认板级 `hardware.lua` 顶部 `M.profile = "air8607_10i"` |
| 屏幕 | 合宙官方 AirLCD_1100 10.1 寸 RGB 屏，1024x600，驱动 IC JD9165BA（免初始化） |
| 触摸 | GT911 电容触摸（I2C1 轮询，TP_RST=GPIO14 / TP_INT=GPIO51），AirLCD_1100 自带 |
| 备选板级 | Air8601（Air1601）+ 7 寸 HX8282 1024x600：改 `M.profile = "air8601_7i"` |
| 背光 | Air8607 走 PWM3；Air8601 走 PIN43/GPIO13 |
| 供电 | USB 供电即可，屏幕由开发板排线供电 |

## 内核固件

- 固件文件名：`LuatOS-SoC_V1030_Air1603_102.soc`（Air1603 / 1601 / 1602 同编号固件内容一致）
- 烧录工具：合宙 **Luatools**（选中上述 .soc 固件 + 本工程 `code/` 目录脚本，底层下载即可）
- 脚本区/文件系统：102 号固件为脚本区 4096KB / fs 1536KB，本工程远小于该预算
- 工程依赖的固件内置库：`airui`、`display`、`tp`、`i2c`、`gpio`、`pwm`、`fskv`、`hzfont`
  （中文矢量字库，字号 12~255 全覆盖，本工程最小字号 16 号）

## 功能与使用（逻辑简单，上手即用）

- **顶栏**：安防 / 门锁 / 窗户状态一目了然；最右「主题」按钮点击在
  浅色 / 深色之间切换（页面原地重建、立即生效，不重启；偏好存 fskv，下次开机保持），旁边是时间。
- **房间 Tab**：客厅 / 卧室 / 厨房，点击切换设备矩阵。
- **设备磁贴**：点磁贴即开/关；点「调」弹出调档条（− 数值 +，步进 5%）。
- **气候栏**：温湿度实时读数 + 24h 趋势折线 + 空调温度 ± 快捷调节。
- **安防栏**：布防 / 门锁开关，与顶栏状态芯片双向同步。
- **底部场景 Dock**：回家 / 离家 / 睡眠 / 观影 / 起身 / 会客，一键联动
  灯光、窗帘与安防。

## 验收要点对照

1. UI 效果见 `docs/方案D_玻璃拟态.html`（浏览器打开即是 1024x600 舞台）；
2. 功能克制：单页 + 6 磁贴原地复用，无多页轮询、无逐帧大动画，硬件无卡顿；
3. 零学习成本：所见即可点，无隐藏操作；
4. HTML 与真机使用同一套视觉令牌（`ui_theme.lua` ↔ HTML CSS 变量），效果高度相符；
5. 最小字号 16 号（`ui_theme.lua` 的 `M.f.sub / M.f.mini` 均为 16）；
6. 交互反馈全部即时到位（默认 `motion.instant = true`），操作流畅；
7. 主题深色 / 浅色两种，顶栏按钮手动切换、原地重建即时生效（不重启），fskv 记忆；
8. 硬件环境与内核固件文件名见上文两节。

## 定制

- 改主题配色：只改 `ui_theme.lua`（`M.dark / M.light` 的 `c` 颜色 / `glass` 玻璃透明度 / `f` 字号）
- 关闭微动：`ui_theme.lua` 里 `M.motion.enabled = false`
- 接入真实设备：改 `app_state.lua` 的数据与模拟逻辑（`start_sim`），
  设备开关在 `page_glass.lua` 磁贴的 `on_click` 里直接改 `d.on`，空调用 `S.ac_delta`
