## 4.1 滚动条根因与坐标系约定（**改代码前必读**）

真机上容器边缘莫名多出两道浅灰细线，来源只有一个：**子控件右缘/下缘越过父容器内容区 1px**，
LVGL 就会在对应边画出滚动条（`scrollbar_mode` 默认 AUTO）。

固件文档写死的坐标约定：

- 子控件 `x/y` 原点是**父容器内容区左上角**；
- 内容区 = 外框 − 2×`border_width`（容器内边距恒为 0）；
- **不要**再往子控件起点上叠加 `border_width`。

本工程原先把 `bw` 叠加到了起点（`fit()` 的 `l,t = bw,bw`、`text_mid` 的 `ax = x+bw`），
等于把每个子控件整体右下移 1px，右缘正好压在内容区边界上，于是：

| 位置 | 现象 |
|---|---|
| 带描边卡片的说明文字（`text_mid`） | 卡片右缘一条竖滚动条 |
| 热区（`press`） | 卡片右下角两条滚动条 |
| 键帽 / 按钮成排 | 每个键帽各一条（4×3 键盘 = 12 条） |

修法（已落地）：

1. `ui_widget.fit()` 的边界改成 `[0, cw] × [0, ch]`，再内收 1px 作为安全边界；
2. `text_mid` / `press_box` 去掉 `+bw` 偏移，热区统一写 `1, 1, cw-2, ch-2`；

## 4.2 动画（真机节拍）

| 项 | 实现 | 判据 |
|---|---|---|
| 主循环节拍 | `sys.wait(budget − 本帧耗时)`，下限 4ms | 过渡期间 `budget = busy_ms(16)`，其余 `poll_ms(50)` |
| 动画步长 | `main` 传**实测周期**（`mcu.ticks` 差值）给 `ui.tick` | 不再用名义 50ms，负载变化时动画速度不变 |
| 扫描线 | 浮点位置按 `75px/s` 累加，取整后变化才 `set_pos` | 步进 ≤ 1px 时零下发；反弹处不夹值 |
| 切页过渡 | 新页面从 `−slide_px(48)` 滑到 `0`，`slide_ms(150)`，三次缓出 | 位移恒 ≤ 0，右缘永不越屏（G6） |
| 过渡打断 | `M.go` 里先 `trans_stop(true)` 收进隐藏位 | 不会先闪一帧 (0,0) |

## 5. 遗留项（真机前必须确认）

1. **金币位图 `img/coin_hero.png`**：240×240 = 57600 ≤ 262144 ✅，**单 IDAT 块已校验** ✅（解码 230KB）。
   发布版同时在 `code/coin_hero.png` 放一份（与 `main.lua` 同批进 luadb，落点 `/luadb/coin_hero.png`），
   代码按候选路径 `io.exists` 探测，探不到才退化成矢量金币。
2. **扫码登录的硬件侧**：效果稿用「模拟扫码成功」按钮代替；真机需接扫码头（串口/UART 读码回调）或摄像头解码。UI 层只等 `SCAN.ok(code)` 一个回调。
3. **支付二维码**：`airui.qrcode` 生成，内容为订单串；真机需接支付后端轮询。
4. **60 秒无操作登出**：会员态自动登出，防止公共设备串号。
