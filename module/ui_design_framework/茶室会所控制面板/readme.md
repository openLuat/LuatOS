# 松风阁 · 茶室会所控制面板

1024×600 会所包间控制面板 Demo：左侧竖轴导航 + 顶栏 + 场景墙 + 底部一键场景条，
单页常驻、点卡片就地展开详情，**两套主题（暖夜 / 宣纸）原地全量重建切换**，偏好落 fskv。

## 界面结构

| 区域 | 尺寸 | 内容 |
| --- | --- | --- |
| 左轴导航 | 88×600 | 场景（回场景墙）/ 服务（呼叫前台）/ 静音 / 主题（暖夜 ⇄ 宣纸） |
| 顶栏 | 936×58 | 房间名「松风阁」+ 包间信息 + 状态徽标 + 24 小时时钟 + 日期 |
| 舞台 | 936×412 | 场景墙或详情页，两者复用同一块区域，视觉上像卡片"展开" |
| 底部场景条 | 936×130 | 待客 / 静修 / 茶会 / 清场，一键联动 5 路设备 |

## 功能

- **场景墙**：茶台灯光 1 张大卡（420×376）+ 香薰 / 背景音乐 / 加湿 / 氛围 4 张小卡（216×180），
  卡上直接显示当前档位，点任意卡进入详情。
- **详情页**：左图与墙上大卡同位置同尺寸（同一张卡展开的错觉）；右侧面板含开关、
  10 段档位刻度、连续调节、3 个快捷档位（2 / 6 / 9 档）。
- **一键场景**：4 套预设档位组合，点一下同时下发 5 路；当前场景名显示在左轴。
- **主题切换**：暖夜（暗调照片满铺 + 浅色字）⇄ 宣纸（晨光浅调 + 深墨字 + 1px 描边卡），
  原地全量重建，偏好存 fskv，下次开机保持。
- **服务 / 静音**：呼叫前台 4 秒后自动复位；静音状态与徽标同步并落盘。
- **时钟**：系统时间有效时用真时间（24 小时制）；板上无时间源时走假时钟，
  从 20:00 起每秒推进、跨零点进位到天，只保证自洽不走回头路。

## 调试硬件环境

| 项目 | 说明 |
| --- | --- |
| 主控 | Air8607（SoC：Air1603） |
| 屏幕 | 合宙官方 10.1 寸 RGB 屏，1024×600，驱动 IC JD9165BA（`exd_jd9165ba_rgb.lua`） |
| 触摸 | GT911 电容触摸（I2C1 轮询，TP_RST=GPIO14 / TP_INT=GPIO51） |
| 背光 | PWM3（1000Hz），上电占空比 0，界面首帧刷出后才点亮 |
| 其他 GPIO | SD_EN=GPIO74 拉高、功放使能=GPIO73 拉低 |
| 供电 | USB 供电即可，屏幕由开发板排线供电 |

## 内核固件

- 固件文件名：`LuatOS-SoC_V1030_Air1603_102.soc`
- 烧录工具：合宙 **Luatools**（选中上述 .soc 固件 + 本工程 `code/` 目录脚本，底层下载即可）
- 工程依赖的固件内置库：`airui`、`display`、`tp`、`i2c`、`gpio`、`pwm`、`fskv`、`hzfont`
- 中文用 hzfont 矢量字库并 `load_to_psram`（2048 字上限 ≈ 200KB PSRAM）；
  拷不进 PSRAM 时自动退回按需读取，界面完整但重建页面会慢

## 几个实现要点

1. **图片 1:1，不做缩放**：卡片几何与素材尺寸严格对应（大卡 420×376 / 小卡 216×180），
   素材缺失时退回大图兜底（会缩放、会慢，但不会白屏）。
2. **用 JPG 不用 PNG**：真机硬件 PNG 解码只认单个 IDAT 块，PIL 存的图必然分块；
   JPG 素材由 `docs/tools/make_assets.py` 生成。
3. **背光延迟点亮**：RGB 屏上电就在扫帧缓冲，而 buffer 里是 PSRAM 未初始化内容，
   背光早于首帧打开会露出一屏雪花；改为建树完成后再等 800ms 点亮。
4. **切主题走全量重建**：控件数不到 100、结构简单且有整套图片要换，重建比就地重涂更划算，
   代价是丢当前选中态（本工程可接受），换主题闪一帧底色。
5. **落盘合并**：调档 / 静音都是连点操作，写 fskv 用 600ms 合并，避免点击回调里等 flash。

## 定制

- 改设备 / 场景 / 文案：只改 `app_config.lua`（`DEVICES`、`SCENES`、`txt`）
- 改配色：只改 `ui_theme.lua` 的两套色板，键必须完全一致
- 换素材：改 `docs/tools/make_assets.py` 里的尺寸常量后重新生成，同时同步 `app_config.lua`
- 改背光点亮时机：`ui.lua` 的 `BRIGHT_DELAY_MS`
