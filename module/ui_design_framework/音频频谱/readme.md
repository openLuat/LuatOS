# 音频频谱 · 音乐律动 · AirUI 工程（Air8603）

参考 `audio_spectrum_ui/preview.html`（1024×800 设计稿）复刻，实机按 **1024×600** 重排：
深海军蓝夜色底 + 紫青色谱，中央唱片 + 环形谱线，底部播放控制坞。

三种可视化模式（**环形 / 柱状 / 波形**）全部真实跳动，且每一块都可点击。
**工程零 PNG 贴图**，唱片、光谱、波形、图标全部用 shape 图元绘制。

- 硬件：合宙 Air8603（Air1603 主控，1024×600 RGB565 电容触摸屏）
- 开发方式：LuatOS (Lua 5.3) + AirUI（基于 LVGL 9.4 封装）+ exwin 页面管理
- 数据：**虚拟演示数据**（`mock.lua`，4 首曲目 / 3 档采样率 / 3 个频段）
- 字号：正文 16~18，标题 18~22，数值 20~30（**最小 16**）

## 页面结构与交互

| 区块 | 内容 | 交互 |
|------|------|------|
| 中央唱片 | 三层同心渐变模拟封面，中心唱盘随节拍呼吸 | 点 → **播放 / 暂停** |
| 环形谱线 | 唱片外圈 16 段扇形谱线 | 点某段 → 选中该谱线（加粗高亮 + 顶部读数） |
| 柱状谱线 | 12 根竖柱（`BBASE=452`，最高 118px） | 点某根 → 同上 |
| 波形 | 26 段折线 + 两条淡色辅助线（不透明度 140） | 点 → 定格 / 恢复实时 |
| 左右侧柱 | 各 16 根短柱（宽 6、步进 10） | 点 → 按位置锁定 低频 / 中频 / 高频 |
| 右侧频段行 | 低频 / 中频 / 高频 三行 | 点 → 锁定该频段（**其余谱线变暗**） |
| 实时 chip | 实时 / 已冻结 | 关 → 整块频谱定格 + 中央"已冻结"卡片 |
| 采样率 chip | 48 kHz / 44.1 kHz / 96 kHz | 切档同时改谱线数：**44 / 36 / 60 根**，读数同步刷新 |
| 声道 chip | 立体声 / 单声道 | 单声道时频谱左右镜像对称 |
| 深浅 chip | 深色 / 浅色 | 切换主题，**整页重建**后重新着色 |
| 底栏控坞 | 封面 / 上一首 / 播放 / 下一首 / 进度条 / 三个模式按钮 | 进度条可拖动（拖动期间暂停自动推进，松手恢复） |

曲库（`mock.TRACKS`）：霓虹地平线 / 深海暗流 / 余晖 / 玻璃雨。
每首歌带 `c1/c2/c3`（封面三层渐变）+ 独立 `accent`（进度条 / 播放键 / 中心唱盘），
**四首 accent 互不相同**，换曲后封面与强调色整体联动换色。

## 烧录步骤（Luatools）

1. 电脑安装 [Luatools](https://docs.openluat.com/) 及 Air8603 板载 USB 转串口驱动；
2. Type-C 数据线接 Air8603 的 **USB2** 口；
3. Luatools 新建项目，选择 Air1603 对应固件（需含 **AirUI V1.1.6+ 与 hzfont 中文字库**）；
4. 脚本区添加 `code/` 下全部 `.lua` 文件（本工程无 img 目录），并勾选 **"添加默认lib"**（exwin 是扩展库）；
5. 烧录运行：点芯片切模式/拖动进度条切歌曲、点谱线看读数、切采样率看谱线数变化。

## 实现说明

| 机制 | 做法 |
|------|------|
| 刷新驱动 | `build` 返回 `(update, interval)`，`theme.make_page` 内部用 `sys.taskInit + sys.wait` 起帧循环，**不用 `sys.timerLoopStart`** |
| 图元批量 | 每帧重建 items 表后统一走 `put()`：空图元 / 状态未变时**不调 `set_items`**（其内部无条件 invalidate，空 shape 全刷会打爆 LVGL 堆 → HardFault） |
| 模式切换 | 切柱状 / 波形 / 环形时**主动清零上一模式的 shape 图元**，避免残影 |
| 图元上限 | 单个 shape 最多 32 个图元，超出按批拆成多个 shape（环形谱线 / 波形折线均按此拆分） |
| 点击热点 | 谱线用透明热区（`theme.hit`）压在图形上接收触摸，回调里只改状态 + `set_color/set_text/set_hidden`，**绝不重建子树** |
| 进度条 | `seek_hold` 计数：拖动期间锁死自动推进，松手后恢复；程序回写 slider 时置 `sync` 位，避免回调误判为用户拖动 |
| 主题切换 | `theme.C` 就地覆写字段（不换表），切完 `theme.rerender_page()` 重建整页，且在 `sys.timerStart(fn, 30)` 里执行 |

性能实测（离线桩自测，1024×600）：

- 环形 / 柱状每帧 `set_items` ≈ **2.64 次**，波形 ≈ **3.61 次**
- 单 shape 图元峰值 **32**（即上限），谱线上限 60 根（96 kHz 档）已是流畅度与观感的上限
- 长跑 **6000 帧**后控件数量 `141 → 141`，无泄漏

## 踩坑要点（来自 theme.lua 头部，务必遵守）

1. `label` 文字在控件框内**顶部对齐** → `theme.txt` 统一下移 y 并收紧 h 到 `size*1.28`；
2. 只有 `container` 有 `set_hidden`，`label / shape / button` 没有 → 要隐藏就塞进容器隐藏容器；
3. **坐标 / 半径 / 线宽一律取整**，小数坐标会导致整批图元被丢弃；
4. 不用 `arc` / `ellipse` 图元（本批固件不渲染），弧线一律多段折线 `ARC()` 拼接；
5. 单个 shape 图元超 32 会吞掉后半段，需分批建；
6. `set_items` 用整表重建（复用同一张表不触发重绘），shape 容器范围必须盖住整块图形，否则被裁剪；
7. 深色界面无渐变能力 → 用"纯色 + 多层低透明度圆"近似光晕；
8. 点击回调里销毁 / 重建子树有 use-after-free 风险（错误被 pcall 吞掉，表现为"点了没反应"）→ 一律 `sys.timerStart(fn, 30)` 延迟；
9. 子 label / shape 会拦触摸（"要点两下"）→ 可点区域最后压一层 `theme.hit`；
10. 部分固件 `exwin` 没有 `bind_root` → 必须 `if exwin.bind_root then pcall(...) end`；
11. 切页必须"先 close 旧窗再 open 新窗"，反过来白屏；
12. **刷新循环禁用 `sys.timerLoopStart`**：固定周期投递事件，与回调耗时无关，帧一重就积压，几分钟后触发 `task event too much` 断言死机（复位原因 6）；
13. 深色配色下"色谱亮度"（`theme.C.lum`）与浅色需求不同，切主题时按 palette 区分；
14. 中文文案宽度不能按 `#txt` 算（UTF-8 一汉字 3 字节），否则胶囊 / 提示条会被撑开。
